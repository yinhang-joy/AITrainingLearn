## 二、知识点讲解

### ① 数据加载与检查（任务 1）

```python
# 加载时指定编码（医疗数据常含中文）
data = pd.read_csv('medical_data.csv', encoding='gbk')

# 三项基础检查
print(data.dtypes)           # 每列数据类型（int64/object/float64等）
print(data.info())           # 列名、非空值数量、内存占用
print(data.isnull().sum())   # 每列缺失值数量
```

**为什么要检查**：
- `dtypes`：确认日期是否被识别为 object（字符串），需要转换
- `info()`：快速了解数据规模和完整性
- `isnull().sum()`：定位缺失值位置，决定填充策略

> **考点**：`encoding='gbk'` 不写会报 `UnicodeDecodeError`；医疗数据文件常用 gbk 编码。

### ② 日期时间处理（任务 2）

```python
# 规范日期格式（从字符串 → datetime64）
data['就诊日期'] = pd.to_datetime(data['就诊日期'])
data['诊断日期'] = pd.to_datetime(data['诊断日期'])

# 修改列名
data.rename(columns={'病人ID': '患者ID'}, inplace=True)
```

**`pd.to_datetime` 机制**：
- 自动识别多种格式：`2023-4-4` / `2023/04/04` / `Apr 4, 2023` 等
- 转换后的类型是 `datetime64[ns]`，支持日期计算和 `.dt` 访问器
- `inplace=True`：原地修改，不返回新 DataFrame

### ③ 日期差值计算与异常数据清理（任务 3）

```python
from datetime import datetime

# 计算诊断延迟（单位：天）
data['诊断延迟'] = (data['诊断日期'] - data['就诊日期']).dt.days

# 计算病程（从诊断到当前日期）
data['病程'] = (datetime(2024, 9, 1) - data['诊断日期']).dt.days

# 删除不合理数据：多条件布尔索引
data = data[(data['诊断延迟'] >= 0) &      # 诊断不能早于就诊
            (data['病程'] > 0) &           # 病程必须为正
            (data['年龄'] < 120)]          # 年龄合理范围
```

**关键点**：
- `.dt.days`：从 Timedelta 对象提取天数（整数）
- `&` 连接多个条件：**必须每个条件加括号**（运算符优先级问题）
- 布尔索引自动丢弃 False 行，返回清洗后的 DataFrame

> **易错点**：`data['诊断延迟'] >= 0` 写成 `data['诊断延迟'] > 0` 会丢掉当天诊断的合理数据。

### ④ 重复值处理（任务 4）

```python
initial_rows = data.shape[0]              # 记录初始行数
data.drop_duplicates(inplace=True)        # 删除完全重复的行
deleted_rows = initial_rows - data.shape[0]

print(f'删除的重复行数: {deleted_rows}')
```

**`drop_duplicates` 默认行为**：
- 比较所有列，只要有一列不同就保留
- 默认保留第一次出现的行（`keep='first'`）
- `subset=[...]` 可指定只比较特定列

### ⑤ 数据归一化（任务 5）

```python
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()                        # 创建归一化器
columns_to_normalize = ['年龄', '体重', '身高']
data[columns_to_normalize] = scaler.fit_transform(data[columns_to_normalize])
```

**MinMaxScaler 原理**：
- 将每列数据缩放到 [0, 1] 区间
- 公式：`(x - min) / (max - min)`
- `fit_transform`：一步完成「学习最小/最大值」+「应用变换」

**为什么要归一化**：
- 消除量纲影响（年龄 0-100，体重 40-100，身高 150-190）
- 机器学习模型对数值范围敏感，归一化可加速收敛

> **考点**：归一化的列必须是数值型；如果有缺失值需先填充，否则结果为 NaN。

### ⑥ 分组统计与可视化（任务 6）

```python
# 统计：疾病类型 × 治疗结果 的分布
treatment_outcome_distribution = data.groupby('疾病类型')['治疗结果'].value_counts().unstack()

# 绘制堆叠柱状图
treatment_outcome_distribution.plot.bar(stacked=True)
plt.title('不同疾病类型的治疗结果分布', fontproperties=my_font)
plt.xlabel('疾病类型', fontproperties=my_font)
plt.ylabel('治疗结果数量', fontproperties=my_font)
plt.legend(prop=my_font)
plt.show()
```

**`groupby + value_counts + unstack` 组合拳**：
1. `groupby('疾病类型')`：按疾病分组
2. `['治疗结果'].value_counts()`：每组内统计治疗结果频次
3. `.unstack()`：把多级索引展开为透视表（行=疾病，列=治疗结果）

**中文显示处理**：
```python
import matplotlib.font_manager as fm
font_path = 'C:/Windows/Fonts/simhei.ttf'
my_font = fm.FontProperties(fname=font_path)
plt.title('标题', fontproperties=my_font)  # 每个中文文本都需指定
```

> **易错点**：忘记 `unstack()` 会导致数据格式不适合 `.plot.bar()`，报错 "No numeric data to plot"。

### ⑦ 散点图分析（任务 7）

```python
plt.scatter(data['年龄'], data['疾病严重程度'])
plt.title('年龄和疾病严重程度的关系', fontproperties=my_font)
plt.xlabel('年龄', fontproperties=my_font)
plt.ylabel('疾病严重程度', fontproperties=my_font)
plt.show()
```

**散点图特点**：
- 用于分析两个连续变量的关系
- X 轴：年龄（数值型）
- Y 轴：疾病严重程度（可能是数值编码：0=不严重、1=轻度、2=中度、3=严重）

**分析思路**：观察点的分布，判断是否存在正相关/负相关/无关系。

## 五、自测题（先自测，再对答案）

1. `pd.to_datetime()` 的作用是什么？为什么要把日期列从 object 转为 datetime64？
2. `(data['诊断日期'] - data['就诊日期']).dt.days` 中 `.dt.days` 的作用是什么？去掉会怎样？
3. `MinMaxScaler` 归一化后，原始数据的最小值和最大值分别变成多少？
4. `groupby('疾病类型')['治疗结果'].value_counts().unstack()` 最终返回的是什么结构？
5. 为什么绘图时每个中文文本都要加 `fontproperties=my_font`？

<details>
<summary>参考答案（先自测再看）</summary>

1. 将字符串格式的日期转换为 pandas 的 datetime64 类型。转换后才能进行日期计算（如相减得 Timedelta）、提取年/月/日等操作；object 类型只能当普通字符串处理。

2. `.dt.days` 从 Timedelta 对象中提取整数天数。去掉的话结果是 Timedelta 对象（如 `21 days`），无法直接用于数值计算和比较。

3. 最小值变为 0，最大值变为 1。公式 `(x - min) / (max - min)` 保证了这一点。

4. 返回一个 DataFrame（透视表）：行索引是疾病类型，列索引是治疗结果（如治愈/好转/未愈），单元格值是对应组合的数量。

5. matplotlib 默认不支持中文，会显示为方块。必须通过 `FontProperties` 加载中文字体文件（如黑体 simhei.ttf），并对每个中文元素（标题、标签、图例）单独指定字体。

## 六、数据清洗与标注规范（答题卷参考）

### 数据清洗规范示例（任选 2 点，每点 1 分）
1. **日期一致性**：就诊日期不得晚于诊断日期，诊断日期不得晚于当前日期
2. **年龄合理性**：年龄限制在 0-120 岁范围内
3. **重复记录**：删除患者ID、就诊日期、疾病类型完全相同的重复记录
4. **缺失值处理**：关键字段（患者ID、年龄、疾病类型）不允许缺失，缺失则删除该行
5. **数值范围**：体重 20-200 kg，身高 50-250 cm，超出范围视为异常数据

### 数据标注规范示例（任选 3 点，每点 1 分）
1. **疾病类型标准化**：统一疾病名称（如「感冒」与「流感」的区分），使用医学标准术语
2. **疾病严重程度分级**：采用三级分类（轻度/中度/严重）或数值编码（0/1/2）
3. **治疗结果分类**：统一为四类（治愈/好转/未愈/死亡），避免模糊描述
4. **地区编码规范**：统一为省级或市级行政区划，避免重复（如「北京」vs「北京市」）
5. **性别编码**：统一为「男/女」或数值编码（0/1），不接受空值或其他描述
