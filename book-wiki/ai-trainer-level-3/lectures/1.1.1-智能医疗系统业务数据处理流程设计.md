## 二、知识点讲解

### ① 读取数据 `pd.read_csv`

```python
df = pd.read_csv('patient_data.csv')
```

- 参数 1：文件路径（考试通常已给相对路径）
- 默认第一行作为列名
- 读入类型：`DataFrame`（表格对象），后续操作都挂在它后面

**验证读取**（新手必做）：
```python
df.head()     # 前 5 行
df.info()     # 列名 / 类型 / 缺失值
```

> 这就是「业务数据处理流程」第一环：**先看数据，再动手**。

### ② 条件筛选：`df[布尔序列]`（核心机制）

```python
df['DaysInHospital'] > 7    # ① 逐行比较 → 一列 True/False
df[布尔序列]                 # ② 只留下 True 的行
# 一行写法：
high_risk = df[df['DaysInHospital'] > 7]
```

**机制要点**：`df[ ]` 放字符串 = 取列；放布尔序列 = 筛行。所有筛选都是这个套路。

### ③ 数量与占比

```python
len(high_risk)               # 高风险患者数量
len(high_risk) / len(df)     # 占比
# 一行写法（布尔列求平均 = 占比）：
(df['DaysInHospital'] > 7).mean()
```

**原理**：True=1、False=0，布尔列的平均值 = True 的比例。

### ④ 区间切分 `pd.cut`（任务②关键）

```python
df['BMI_类别'] = pd.cut(df['BMI'],
                        bins=[0, 18.5, 24.0, 28.0, 100],   # 5 个边界 → 4 个区间
                        labels=['偏瘦', '正常', '超重', '肥胖'],
                        right=False)
```

三个参数：
- `bins`：区间边界列表，**n 个边界 → n-1 个区间**（考点）
- `labels`：区间名字，与 bins 一一对应
- `right=False`：**左闭右开** `[18.5, 24)`；默认是左开右闭 `(18.5, 24]`

**⚠️ 最容易丢分的坑**：题目「正常 18.5～23.9」要求 BMI=18.5 归「正常」，必须 `right=False`。不加则 18.5 被算进「偏瘦」。

### ⑤ 分组统计 `groupby`（任务②③核心）

```python
df['高风险'] = df['DaysInHospital'] > 7        # 先造布尔列
df.groupby('BMI_类别')['高风险'].agg(['count', 'sum'])
# count = 该区间患者总数，sum = 高风险人数，比例 = sum/count
# 直接得比例：
df.groupby('BMI_类别')['高风险'].mean()
```

三步走：`groupby('分组列')` → `['统计列']` → `.agg([...])` / `.mean()`。

## 三、完整解题流程演示（真实运行结果）

```python
df = pd.read_csv('patient_data.csv')
high_risk = df[df['DaysInHospital'] > 7]
print(len(high_risk))          # → 426
print((df['DaysInHospital'] > 7).mean())   # → 0.426

df['高风险'] = df['DaysInHospital'] > 7
df['BMI_类别'] = pd.cut(df['BMI'], bins=[0, 18.5, 24.0, 28.0, 100],
                        labels=['偏瘦', '正常', '超重', '肥胖'], right=False)
df.groupby('BMI_类别')['高风险'].agg(['count', 'sum'])
#           count  sum
# 偏瘦         15    5
# 正常        247   98
# 超重        376  173
# 肥胖        362  178
```

任务③同理：`pd.cut(df['Age'], bins=[0, 25, 35, 45, 55, 65, 200], right=False)` + groupby。

## 五、自测题（先自测，再对答案）

1. `df[df['Age'] > 30]` 里 `df['Age'] > 30` 是什么类型的数据？`df[...]` 收到它后做了什么？
2. `(df['DaysInHospital'] > 7).mean()` 为什么一行就得到占比？
3. `pd.cut` 的 `right=False` 改没改，BMI=18.5 分别落在哪？为什么必须 `right=False`？

<details>
<summary>参考答案（先自测再看）</summary>

1. 布尔 Series（一列 True/False，每行一个）；`df[...]` 收到布尔序列后**筛行**——留下 True 对应的行。
2. True=1、False=0，布尔列求平均值 = 1 的比例 = 条件成立占比。
3. 默认左开右闭 `(18.5, 24]`：18.5 落「偏瘦」；`right=False` 左闭右开 `[18.5, 24)`：18.5 落「正常」。题目定义「正常 18.5～23.9」，所以必须 `right=False` 让 18.5 归正常。
</details>
