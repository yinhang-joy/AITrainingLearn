## 二、核心知识点详解

### ① 异常值检测：箱线图可视化

```python
import matplotlib.pyplot as plt
import seaborn as sns

# 设置画布尺寸：12×8 英寸
plt.figure(figsize=(12, 8))

# 只对数值列绘制箱线图
numeric_cols = data.select_dtypes(include=['float64', 'int64']).columns

# 创建 3 行 4 列的子图网格
for i, col in enumerate(numeric_cols, 1):
    plt.subplot(3, 4, i)        # 第 i 个子图
    sns.boxplot(x=data[col])    # 横向箱线图
    plt.title(col)

plt.tight_layout()              # 自动调整子图间距
plt.show()
```

**知识点**：
- `.select_dtypes(include=['float64', 'int64'])`：只选数值列（字符串列不画箱线图）
- `enumerate(列表, 1)`：从 1 开始编号（subplot 索引从 1 开始）
- `plt.subplot(行, 列, 索引)`：在 3×4 网格的第 i 个位置画图

---

### ② 异常值处理：IQR 方法（考点）

**IQR 方法原理**：
- **IQR**（Interquartile Range，四分位距）= Q3 - Q1
- **下界** = Q1 - 1.5 × IQR
- **上界** = Q3 + 1.5 × IQR
- 超出上下界的值视为异常值

```python
# 计算四分位数
Q1 = data[numeric_cols].quantile(0.25)   # 每列的 25% 分位数
Q3 = data[numeric_cols].quantile(0.75)   # 每列的 75% 分位数
IQR = Q3 - Q1

# 定义异常值条件（任意列超出边界）
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# 过滤异常值：保留所有列都在边界内的行
data_cleaned = data[~((data[numeric_cols] < lower_bound) | 
                       (data[numeric_cols] > upper_bound)).any(axis=1)]
```

**易错点**：
- `~` 表示取反（保留**非**异常值的行）
- `.any(axis=1)`：每行只要有一列异常就标记为 True
- `[~(...)]`：最终保留所有列都正常的行

---

### ③ 重复值检测与删除

```python
# 检测重复行（返回布尔列，True=重复）
duplicates = data_cleaned.duplicated()
num_duplicates = duplicates.sum()

# 删除重复行（默认保留第一次出现的行）
data_cleaned = data_cleaned[~duplicates]
# 或者一行写法：
# data_cleaned = data_cleaned.drop_duplicates()

print(f'删除的重复行数: {num_duplicates}')
```

**注意**：`.duplicated()` 默认判断**所有列**完全相同才算重复。

---

### ④ 数据归一化：MinMaxScaler

**目的**：将不同量纲的特征缩放到 [0, 1] 区间，避免大数值特征主导模型。

```python
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()
data_cleaned[numeric_cols] = scaler.fit_transform(data_cleaned[numeric_cols])
```

**原理**：$x' = \frac{x - min}{max - min}$

**易错点**：只对数值列归一化，字符串列（如 ID）跳过。

## 四、易错点（考试陷阱）

### ⚠️ 陷阱 1：IQR 过滤条件写反

```python
# ❌ 错误（保留了异常值）
data_cleaned = data[(data[numeric_cols] < lower) | (data[numeric_cols] > upper)]

# ✅ 正确（过滤掉异常值，保留正常值）
data_cleaned = data[~((data[numeric_cols] < lower) | (data[numeric_cols] > upper)).any(axis=1)]
```

**记忆口诀**：`~` 取反 + `any(axis=1)` 任意列异常就删。

---

### ⚠️ 陷阱 2：`.quantile()` 只对数值列有效

```python
# ❌ 错误（全部列包括字符串列）
Q1 = data.quantile(0.25)   # 字符串列会报错

# ✅ 正确（只选数值列）
numeric_cols = data.select_dtypes(include=['float64', 'int64']).columns
Q1 = data[numeric_cols].quantile(0.25)
```

---

### ⚠️ 陷阱 3：归一化后覆盖原列

```python
# ❌ 错误（创建新 DataFrame，原列未更新）
scaler.fit_transform(data_cleaned[numeric_cols])

# ✅ 正确（结果赋值回原列）
data_cleaned[numeric_cols] = scaler.fit_transform(data_cleaned[numeric_cols])
```

---

### ⚠️ 陷阱 4：`train_test_split` 参数顺序

```python
# ❌ 错误（X 和 y 顺序颠倒）
X_train, X_test, y_train, y_test = train_test_split(y, X, test_size=0.2)

# ✅ 正确（先 X 后 y）
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
```

## 六、自测题

1. IQR 方法中，为什么要用 `1.5 × IQR` 而不是 `2 × IQR`？
2. `.any(axis=1)` 和 `.any(axis=0)` 的区别是什么？
3. `MinMaxScaler` 和标准化（Z-score）的区别是什么？各适用什么场景？

<details>
<summary>参考答案（先自测再看）</summary>

1. **1.5 × IQR 是统计学约定**：
   - 1.5 倍是经典的离群点判定标准（Tukey 箱线图规则）
   - 在正态分布下，约 99.3% 的数据在此范围内
   - 2 倍太宽松，会漏掉部分异常值；1 倍太严格，会误删正常值

2. **axis 参数方向**：
   - `axis=1`：横向（每行）操作，检查每行是否有任意列满足条件
   - `axis=0`：纵向（每列）操作，检查每列是否有任意行满足条件
   - IQR 异常值过滤用 `axis=1`，因为要删除「任意列异常」的行

3. **归一化 vs 标准化**：
   - **MinMaxScaler**（归一化）：缩放到 [0,1]，保留原始分布形状，适合神经网络（需要固定范围）
   - **StandardScaler**（标准化）：转为均值 0、标准差 1，适合线性回归（需要可比较的量纲）
   - 本题用 MinMaxScaler，因为是为机器学习模型准备数据

</details>
