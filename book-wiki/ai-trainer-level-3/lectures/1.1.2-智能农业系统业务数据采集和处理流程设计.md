**中文要求**：统计每种传感器的数据数量和平均值

**翻译成 pandas**：
```python
df.groupby('SensorType')['Value'].agg(['count', 'mean'])
```

**知识点**：`groupby` + `.agg()` 一次算多个统计量（count 数量 / mean 平均值）

### 任务②：按位置统计温度和湿度平均值

**中文要求**：每个位置（Location）的温度（Temperature）和湿度（Humidity）传感器数据的平均值

**翻译成 pandas**：
```python
# 1. 先筛选出温度和湿度两种传感器
temp_humidity = df[df['SensorType'].isin(['Temperature', 'Humidity'])]

# 2. 按位置 + 传感器类型分组，求平均值
temp_humidity.groupby(['Location', 'SensorType'])['Value'].mean()
```

**新知识点**：`.isin([列表])` 筛选多个值（比 `== 'Temperature' | == 'Humidity'` 简洁）

### 任务③：数据清洗（本单元核心）

**中文要求**：
1. 标记异常值：温度 > 50 或湿度 > 100
2. 缺失值填充：前向填充（ffill），前面没有就后向填充（bfill）
3. 保存为 `cleaned_sensor_data.csv`

**翻译成 pandas**：
```python
# 1. 标记异常值（新增一列）
df['Anomaly'] = ((df['SensorType'] == 'Temperature') & (df['Value'] > 50)) | \
                ((df['SensorType'] == 'Humidity') & (df['Value'] > 100))

# 2. 统计异常值数量
print(df['Anomaly'].sum())

# 3. 缺失值填充（虽然当前数据无缺失，但考试要写）

# 4. 保存清洗后的数据
df.to_csv('cleaned_sensor_data.csv', index=False)
```

## 三、新知识点详解

### ① `.isin()` —— 多值筛选

```python
# 笨办法（写两次条件）
df[(df['SensorType'] == 'Temperature') | (df['SensorType'] == 'Humidity')]

# 简洁写法
df[df['SensorType'].isin(['Temperature', 'Humidity'])]
```

**原理**：`.isin(['A', 'B'])` 检查每行是否在列表里，返回布尔列。

---

### ② `.fillna(method='ffill')` —— 前向填充

```python
# 假设 Value 列有缺失值：
# [10, NaN, NaN, 20, 30, NaN]

df['Value'].fillna(method='ffill')
# 结果：[10, 10, 10, 20, 30, 30]
# 每个 NaN 用它前面的值填充

df['Value'].fillna(method='bfill')
# 结果：[10, 20, 20, 20, 30, NaN]
# 每个 NaN 用它后面的值填充（最后一个 NaN 无后续值仍是 NaN）
```

**链式填充**（考试常用）：
```python
df['Value'].fillna(method='ffill').fillna(method='bfill')
# 先前向填充，还有剩余 NaN 再后向填充
```

**参数对照表**：

| method 参数 | 含义 | 别名 |
|---|---|---|
| `'ffill'` | forward fill（前向填充） | `'pad'` |
| `'bfill'` | backward fill（后向填充） | `'backfill'` |

---

### ③ 异常值标记 —— 布尔索引 + 新列赋值

```python
# 温度 > 50 是异常
df['Anomaly'] = (df['SensorType'] == 'Temperature') & (df['Value'] > 50)
# 每行是 True（异常）或 False（正常）

# 同时标记两种异常：温度 > 50 或湿度 > 100
df['Anomaly'] = ((df['SensorType'] == 'Temperature') & (df['Value'] > 50)) | \
                ((df['SensorType'] == 'Humidity') & (df['Value'] > 100))
# ⚠️ 注意：每个条件要加括号，因为 & 优先级高于 ==
```

**统计异常数量**：
```python
df['Anomaly'].sum()    # True=1、False=0，求和 = 异常行数
```

---

### ④ `.to_csv()` —— 保存 CSV

```python
df.to_csv('cleaned_sensor_data.csv', index=False)
```

**参数**：
- 第一个参数：文件名（相对路径，保存在工作目录）
- `index=False`：不保存行号列（考试必加，否则会多一列 0,1,2...）

## 五、易错点（考试陷阱）

### ⚠️ 陷阱 1：`.isin()` 里要用列表

```python
# ❌ 错误
df[df['SensorType'].isin('Temperature', 'Humidity')]  # isin() 只接受一个参数

# ✅ 正确
df[df['SensorType'].isin(['Temperature', 'Humidity'])]  # 必须用列表
```

---

### ⚠️ 陷阱 2：复杂条件必须加括号

```python
# ❌ 错误（运算符优先级导致逻辑错误）
df['Anomaly'] = df['SensorType'] == 'Temperature' & df['Value'] > 50

# ✅ 正确
df['Anomaly'] = (df['SensorType'] == 'Temperature') & (df['Value'] > 50)
```

**原因**：`&` 的优先级高于 `==`，不加括号相当于 `df['SensorType'] == (wrong expression)`

---

### ⚠️ 陷阱 3：`.to_csv()` 忘记 `index=False`

```python
# ❌ 错误（多一列行号）
df.to_csv('cleaned_sensor_data.csv')
# 结果 CSV 第一列是 0,1,2,3...

# ✅ 正确
df.to_csv('cleaned_sensor_data.csv', index=False)
```

## 六、自测题

1. `.isin(['A', 'B'])` 和 `== 'A' | == 'B'` 的结果相同吗？为什么 `.isin()` 更安全？
2. `.fillna(method='ffill').fillna(method='bfill')` 为什么要链式调用两次？单独用 `ffill` 会留下什么情况的 NaN？
3. `(df['A'] > 10) & (df['B'] < 5)` 里的括号能去掉吗？为什么？

<details>
<summary>参考答案（先自测再看）</summary>

1. **结果相同，但 `.isin()` 更安全**：
   - `== 'A' | == 'B'` 在 pandas 里语法错误（运算符优先级问题，需要写成 `(df['col'] == 'A') | (df['col'] == 'B')`）
   - `.isin(['A', 'B'])` 一行搞定，不会因括号漏写出错，且更易读

2. **链式调用处理首尾 NaN**：
   - `ffill` 只能填充「有前面值」的 NaN，**第一行如果是 NaN 无法填充**
   - `bfill` 只能填充「有后面值」的 NaN，**最后一行如果是 NaN 无法填充**
   - 链式：`ffill` 填中间，`bfill` 补首尾，覆盖所有情况

3. **不能去括号，会逻辑错误**：
   - `&` 优先级高于 `>`，不加括号相当于 `df['A'] > (10 & df['B']) < 5`（语义错误）
   - pandas 要求逻辑运算必须显式加括号

</details>
