### 核心业务场景

电商平台每天产生海量用户行为数据（浏览、点击、购买、评价），但原始数据存在：
1. **缺失值**：部分用户未填写年龄或评分
2. **数据类型错误**：年龄被读成浮点数，金额被读成字符串
3. **异常值**：年龄 200 岁、购买金额 -100 元、评分 10 分（满分 5 分）
4. **量纲不一致**：年龄 20-60、金额 0-10000、评分 1-5，需标准化才能比较

本单元任务：**从脏数据到干净数据的完整清洗流程**。

### 任务②：缺失值处理

```python
# 查看缺失值数量
print(data.isnull().sum())

# 删除包含缺失值的行
data_clean = data.dropna()
print(f"删除前: {len(data)} 行")
print(f"删除后: {len(data_clean)} 行")
```

**知识点**：
- `.isnull()` 返回布尔 DataFrame（True=缺失，False=非缺失）

### 任务③：数据类型转换

```python
# 年龄从浮点转整型
data_clean['Age'] = data_clean['Age'].astype(int)

# 购买金额从字符串转浮点
data_clean['Amount'] = data_clean['Amount'].astype(float)

# 验证转换结果
print(data_clean.dtypes)
```

**知识点**：
- `.astype(int)` 转整型（小数部分直接截断，不是四舍五入）
- `.astype(float)` 转浮点型
- 转换前确保数据合法（如字符串 `'100.5'` 可转 float，但 `'abc'` 会报错）

### 任务④：异常值检测与过滤

```python
# 定义合理范围
age_valid = data_clean['Age'].between(18, 80)           # 年龄 18-80
amount_valid = data_clean['Amount'].between(0, 10000)   # 金额 0-10000
rating_valid = data_clean['Rating'].between(1, 5)       # 评分 1-5

# 筛选所有条件都满足的行
data_clean = data_clean[age_valid & amount_valid & rating_valid]
print(f"异常值过滤后: {len(data_clean)} 行")
```

**知识点**：
- `.between(left, right)` 检查值是否在区间内（包含边界，即 `[left, right]`）
- 返回布尔 Series，配合 `&` 组合多个条件
- ⚠️ **多条件必须加括号**：`(cond1) & (cond2) & (cond3)`

---

### 任务⑤：数据标准化（Z-score 标准化）

```python
# 对年龄、金额、评分进行标准化
for col in ['Age', 'Amount', 'Rating']:
    mean = data_clean[col].mean()
    std = data_clean[col].std()
    data_clean[f'{col}_std'] = (data_clean[col] - mean) / std

# 查看标准化结果
print(data_clean[['Age', 'Age_std', 'Amount', 'Amount_std']].head())
```

**知识点**：
- **Z-score 公式**：`(x - μ) / σ`（每个值减去均值，再除以标准差）
- 标准化后：均值=0，标准差=1，不同量纲的数据变为同一尺度
- 应用场景：机器学习模型训练前的特征工程

---

### 任务⑥：分组统计与数据分箱

```python
# 按年龄段分组
age_bins = pd.cut(data_clean['Age'], 
                  bins=[0, 25, 35, 45, 55, 100],
                  labels=['18-25', '26-35', '36-45', '46-55', '56+'])
data_clean['AgeGroup'] = age_bins

# 统计各年龄段的购买金额
age_stats = data_clean.groupby('AgeGroup')['Amount'].agg(['count', 'mean', 'sum'])
print(age_stats)
```

**知识点**：
- `pd.cut()` 将连续变量切分为离散区间（复用 1.1.1 知识）
- `groupby().agg([...])` 一次计算多个统计量

## 三、新知识点详解

### ① 数据类型转换 `.astype()`

```python
# 示例数据
df = pd.DataFrame({'A': [1.5, 2.8, 3.2], 'B': ['10', '20', '30']})

# 浮点转整型（截断小数，不是四舍五入）
df['A'] = df['A'].astype(int)    # [1.5, 2.8, 3.2] → [1, 2, 3]

# 字符串转浮点
df['B'] = df['B'].astype(float)  # ['10', '20', '30'] → [10.0, 20.0, 30.0]
```

**常用类型**：
- `int` / `'int64'`：整型
- `float` / `'float64'`：浮点型
- `str` / `'object'`：字符串

**⚠️ 易错点**：
- 转换前检查数据合法性：`'abc'.astype(float)` 会报错
- 浮点转整型直接截断：`2.9 → 2`（不是 3）

---

### ② 异常值检测 `.between()`

```python
# between(left, right) 检查值是否在区间内
df = pd.DataFrame({'score': [50, 75, 120, -10, 85]})

valid = df['score'].between(0, 100)
# 结果：[True, True, False, False, True]

df_clean = df[valid]
# 结果：[50, 75, 85]（删除了 120 和 -10）
```

**参数**：
- `left`：左边界（默认包含）
- `right`：右边界（默认包含）
- `inclusive='both'`：默认包含两端，可改为 `'left'` / `'right'` / `'neither'`

**对比 1.1.1 的 `pd.cut()`**：
- `between()` 用于**过滤**：保留范围内的行
- `pd.cut()` 用于**分类**：给每行打上区间标签

---

### ③ Z-score 标准化

**公式**：
```
z = (x - μ) / σ
```
- `x`：原始值
- `μ`：均值（mean）
- `σ`：标准差（std）

**代码实现**：
```python
mean = df['Age'].mean()
std = df['Age'].std()
df['Age_std'] = (df['Age'] - mean) / std
```

**标准化后的特征**：
- 均值 = 0
- 标准差 = 1
- 解释：z=2 表示「比均值高 2 个标准差」，z=-1 表示「比均值低 1 个标准差」

**应用场景**：
1. 机器学习特征工程（不同量纲的特征需统一尺度）
2. 异常值检测（|z| > 3 通常认为是异常值）
3. 数据可视化（不同指标在同一图表对比）

---

### ④ 数据分箱 `pd.cut()` 深化

```python
# 连续变量 → 离散区间
ages = [22, 35, 45, 58, 70]
age_groups = pd.cut(ages, 
                    bins=[0, 30, 50, 100], 
                    labels=['青年', '中年', '老年'])
# 结果：['青年', '中年', '中年', '老年', '老年']
```

**参数详解**：
- `bins`：边界列表（n 个边界 → n-1 个区间）
- `labels`：区间名称（长度 = len(bins) - 1）
- `right=True`（默认）：左开右闭 `(a, b]`
- `right=False`：左闭右开 `[a, b)`

**⚠️ 考点（1.1.1 已学）**：
- 题目「18-25 岁」是否包含 18？需要 `right=False`
- 不加 `right=False` 则 18 会落到上一个区间

## 四、完整解题流程演示

```python
import pandas as pd
import numpy as np

# ① 读取数据
data = pd.read_csv('user_behavior_data.csv')
print(f"原始数据: {len(data)} 行")
print(data.info())

# ② 删除缺失值
data = data.dropna()
print(f"删除缺失值后: {len(data)} 行")

# ③ 数据类型转换
data['Age'] = data['Age'].astype(int)
data['Amount'] = data['Amount'].astype(float)

# ④ 异常值过滤
age_valid = data['Age'].between(18, 80)
amount_valid = data['Amount'].between(0, 10000)
rating_valid = data['Rating'].between(1, 5)
data = data[age_valid & amount_valid & rating_valid]
print(f"异常值过滤后: {len(data)} 行")

# ⑤ 数据标准化
for col in ['Age', 'Amount', 'Rating']:
    mean = data[col].mean()
    std = data[col].std()
    data[f'{col}_std'] = (data[col] - mean) / std

# ⑥ 分组统计
data['AgeGroup'] = pd.cut(data['Age'], 
                          bins=[0, 25, 35, 45, 55, 100],
                          labels=['18-25', '26-35', '36-45', '46-55', '56+'])
result = data.groupby('AgeGroup')['Amount'].agg(['count', 'mean', 'sum'])
print(result)
```

## 五、易错点（考试陷阱）

### ⚠️ 陷阱 1：`.astype(int)` 截断小数，不是四舍五入

```python
df = pd.DataFrame({'score': [89.9, 90.1, 85.5]})

# ❌ 错误理解：以为 89.9 → 90
df['score'].astype(int)    # 结果：[89, 90, 85]

# ✅ 四舍五入需要先 round()
df['score'].round().astype(int)    # 结果：[90, 90, 86]
```

---

### ⚠️ 陷阱 2：多条件筛选忘记括号

```python
# ❌ 错误（运算符优先级导致逻辑错误）
data[(data['Age'] > 18) & data['Amount'] < 1000]   # 第二个条件没括号

# ✅ 正确
data[(data['Age'] > 18) & (data['Amount'] < 1000)]
```

---

### ⚠️ 陷阱 3：`.between()` 默认包含边界

```python
df = pd.DataFrame({'age': [18, 25, 30]})

# between(18, 25) 默认包含 18 和 25
df[df['age'].between(18, 25)]    # 结果：[18, 25]

# 如果题目要求「18 < age < 25」（不含边界）
df[df['age'].between(18, 25, inclusive='neither')]    # 结果：[]
```

---

### ⚠️ 陷阱 4：Z-score 标准化后原列被覆盖

```python
# ❌ 错误（原始数据丢失）
data['Age'] = (data['Age'] - data['Age'].mean()) / data['Age'].std()

# ✅ 正确（新建列保留原始数据）
data['Age_std'] = (data['Age'] - data['Age'].mean()) / data['Age'].std()
```

## 七、自测题（先自测，再对答案）

1. `.astype(int)` 和 `.round().astype(int)` 有什么区别？什么时候用哪个？
2. `.between(18, 80)` 是否包含 18 和 80？如何排除边界值？
3. Z-score 标准化后，均值和标准差分别是多少？为什么需要标准化？
4. `pd.cut()` 和 `.between()` 都涉及区间，它们有什么区别？

<details>
<summary>参考答案（先自测再看）</summary>

1. **区别**：
   - `.astype(int)` 直接截断小数：`89.9 → 89`
   - `.round().astype(int)` 先四舍五入再转：`89.9 → 90.0 → 90`
   - **使用场景**：题目明确说「取整」用 astype，说「四舍五入」用 round

2. **between() 默认包含边界**：
   - `.between(18, 80)` 等价于 `18 ≤ x ≤ 80`（包含 18 和 80）
   - 排除边界：`.between(18, 80, inclusive='neither')` 等价于 `18 < x < 80`
   - 其他选项：`inclusive='left'`（只含左边界）/ `'right'`（只含右边界）

3. **标准化后的特征**：
   - 均值 = 0，标准差 = 1
   - **原因**：不同量纲的特征（年龄 20-60、金额 0-10000）变为同一尺度，机器学习模型才能公平比较

4. **区别**：
   - `pd.cut()`：**分类工具**，给每个值打上区间标签（如「青年」/「中年」/「老年」）
   - `.between()`：**过滤工具**，返回布尔 Series，用于筛选行（保留 True 的行）
   - 记忆：cut=切分分类，between=范围过滤

</details>
