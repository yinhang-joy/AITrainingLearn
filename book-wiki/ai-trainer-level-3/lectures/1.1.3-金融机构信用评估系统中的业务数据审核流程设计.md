## 二、任务拆解

### 任务①：数据完整性审核

**中文要求**：检查缺失值和重复值

**翻译成 pandas**：
```python
# 缺失值统计：每列有多少个 NaN
missing_values = data.isnull().sum()

# 重复值统计：有多少行完全重复
duplicate_values = data.duplicated().sum()
```

**知识点**：
- `.isnull()` 返回布尔表（每个单元格是 True/False）
- `.sum()` 统计 True 的数量（True=1, False=0）
- `.duplicated()` 标记重复行（第一次出现是 False，后续重复是 True）

---

### 任务②：数据合理性审核（本单元核心）

**中文要求**：
- 年龄应在 18 到 70 岁之间
- 收入应大于 2000
- 贷款金额应小于收入的 5 倍
- 信用评分应在 300 到 850 之间

**翻译成 pandas**：
```python
# 年龄合理性（新方法：between）
data['is_age_valid'] = data['Age'].between(18, 70)

# 收入合理性（简单比较）
data['is_income_valid'] = data['Income'] > 2000

# 贷款金额合理性（跨列比较）
data['is_loan_amount_valid'] = data['LoanAmount'] < (data['Income'] * 5)

# 信用评分合理性（between）
data['is_credit_score_valid'] = data['CreditScore'].between(300, 850)

# 综合判断：四个条件都满足才算合理
data['is_valid'] = data[['is_age_valid', 'is_income_valid', 
                          'is_loan_amount_valid', 'is_credit_score_valid']].all(axis=1)
```

**新知识点**：
- `.between(a, b)` 等价于 `(df['col'] >= a) & (df['col'] <= b)`，但更简洁
- `.all(axis=1)` 检查每行是否全为 True（axis=1 表示横向比较）

### 任务③：数据清洗和异常值处理

**中文要求**：
1. 删除不合理的数据行
2. 删除标记列
3. 保存为 `cleaned_credit_data.csv`

**翻译成 pandas**：
```python
# 1. 筛选合理数据（保留 is_valid=True 的行）
cleaned_data = data[data['is_valid']]

# 2. 删除临时标记列
cleaned_data = cleaned_data.drop(columns=['is_age_valid', 'is_income_valid', 
                                           'is_loan_amount_valid', 'is_credit_score_valid', 'is_valid'])

# 3. 保存清洗后的数据
cleaned_data.to_csv('cleaned_credit_data.csv', index=False)
```

**新知识点**：
- `~布尔列` 取反（`~data['is_valid']` = 找出不合理的数据）
- `.drop(columns=[列表])` 删除指定列
- 清洗流程：标记 → 筛选 → 删除标记 → 保存

## 三、新知识点详解

### ① `.between()` —— 区间合理性检查

```python
# 笨办法（写两次比较）
(data['Age'] >= 18) & (data['Age'] <= 70)

# 简洁写法
data['Age'].between(18, 70)
```

**注意事项**：
- **默认包含边界**：`between(18, 70)` 等价于 `18 ≤ Age ≤ 70`
- 如需开区间：`between(18, 70, inclusive='neither')` → `18 < Age < 70`
- 如需左开右闭：`between(18, 70, inclusive='right')` → `18 < Age ≤ 70`

**考试默认**：题目说「18 到 70 岁之间」通常指闭区间，直接用 `.between(18, 70)` 即可。

---

### ② 跨列比较 —— 关联字段验证

```python
# 贷款金额应小于收入的 5 倍
data['LoanAmount'] < (data['Income'] * 5)
```

**原理**：pandas 列运算是逐行计算的
- `data['Income'] * 5`：每行的收入乘以 5，返回新列
- `data['LoanAmount'] < ...`：逐行比较，返回布尔列

**常见关联验证**：
```python
# 收入应大于支出
data['Income'] > data['Expense']

# 总价应等于单价×数量
data['Total'] == data['Price'] * data['Quantity']

# 年龄应大于注册时长
data['Age'] > data['MemberYears']
```

---

### ③ `.all(axis=1)` —— 多条件综合判断

```python
# 四个条件列
validity_checks = data[['is_age_valid', 'is_income_valid', 
                        'is_loan_amount_valid', 'is_credit_score_valid']]

# 每行全为 True 才返回 True
data['is_valid'] = validity_checks.all(axis=1)
```

**参数对照**：
| axis 参数 | 比较方向 | 含义 |
|---|---|---|
| `axis=1` | 横向（每行） | 该行所有值都是 True 才返回 True |
| `axis=0` | 纵向（每列） | 该列所有值都是 True 才返回 True |

**等价写法**（考试更常见）：
```python
data['is_valid'] = (data['is_age_valid']) & (data['is_income_valid']) & \
                   (data['is_loan_amount_valid']) & (data['is_credit_score_valid'])
```

---

### ④ 布尔取反 `~` —— 找出不合理数据

```python
# 找出合理数据
valid_data = data[data['is_valid']]

# 找出不合理数据（取反）
invalid_data = data[~data['is_valid']]
```

**原理**：`~` 是按位取反运算符，对布尔列每个值取反
- True → False
- False → True

**常见用法**：
```python
# 不在列表中
data[~data['City'].isin(['北京', '上海'])]

# 没有缺失值的行
data[~data['Age'].isnull()]

# 不重复的行（保留所有首次出现）
data[~data.duplicated()]
```

---

### ⑤ `.drop(columns=[...])` —— 删除列

```python
# 删除单列
data.drop(columns=['is_valid'])

# 删除多列
data.drop(columns=['is_age_valid', 'is_income_valid', 'is_loan_amount_valid'])
```

**注意事项**：
- **参数名必须是 `columns=`**（不能写成 `drop(['列名'])`，那是删除行的语法）
- 默认返回新 DataFrame，原数据不变
- 如需就地修改：`data.drop(columns=[...], inplace=True)`（考试不推荐，容易丢数据）

## 四、完整解题流程演示

```python
import pandas as pd

# 读取数据集
data = pd.read_csv('credit_data.csv')

# 任务①：数据完整性审核
missing_values = data.isnull().sum()
duplicate_values = data.duplicated().sum()
print("缺失值统计:")
print(missing_values)
print("重复值统计:")
print(duplicate_values)
# 输出：
# CustomerID         0
# Name               0
# Age                5    ← 有 5 个缺失值
# Income             0
# ...
# 重复值统计: 0

# 任务②：数据合理性审核
data['is_age_valid'] = data['Age'].between(18, 70)
data['is_income_valid'] = data['Income'] > 2000
data['is_loan_amount_valid'] = data['LoanAmount'] < (data['Income'] * 5)
data['is_credit_score_valid'] = data['CreditScore'].between(300, 850)

# 综合判断
data['is_valid'] = data[['is_age_valid', 'is_income_valid', 
                          'is_loan_amount_valid', 'is_credit_score_valid']].all(axis=1)

print("数据合理性检查:")
print(data[['is_age_valid', 'is_income_valid', 'is_loan_amount_valid', 
            'is_credit_score_valid', 'is_valid']].describe())

# 任务③：数据清洗
# 删除不合理数据行
cleaned_data = data[data['is_valid']]

# 删除标记列
cleaned_data = cleaned_data.drop(columns=['is_age_valid', 'is_income_valid', 
                                           'is_loan_amount_valid', 'is_credit_score_valid', 'is_valid'])

# 保存清洗后的数据
cleaned_data.to_csv('cleaned_credit_data.csv', index=False)
print("数据清洗完成，已保存为 'cleaned_credit_data.csv'")
```

## 五、易错点（考试陷阱）

### ⚠️ 陷阱 1：`.between()` 忘记赋值到新列

```python
# ❌ 错误（只计算不保存）
data['Age'].between(18, 70)    # 计算完就丢了

# ✅ 正确
data['is_age_valid'] = data['Age'].between(18, 70)
```

---

### ⚠️ 陷阱 2：跨列比较括号丢失

```python
# ❌ 错误（运算符优先级错误）
data['LoanAmount'] < data['Income'] * 5
# 相当于 (data['LoanAmount'] < data['Income']) * 5，逻辑错误

# ✅ 正确
data['LoanAmount'] < (data['Income'] * 5)
```

---

### ⚠️ 陷阱 3：`.drop()` 参数错误

```python
# ❌ 错误（缺少 columns= 参数）
data.drop(['is_valid'])    # 这是删除行号为 'is_valid' 的行，不是删除列

# ✅ 正确
data.drop(columns=['is_valid'])
```

---

### ⚠️ 陷阱 4：缺失值导致 `.between()` 返回 NaN

```python
# 如果 Age 列有缺失值（NaN）
data['Age'].between(18, 70)
# 结果：[True, True, NaN, False, ...]  ← NaN 位置返回 NaN，不是 False

# 解决方法：填充缺失值或单独处理
data['is_age_valid'] = data['Age'].between(18, 70).fillna(False)
# 或者
data['is_age_valid'] = data['Age'].between(18, 70) & data['Age'].notnull()
```

**本题数据特点**：Age 有缺失值，`.between()` 会返回 NaN，最终 `.all(axis=1)` 会把 NaN 视为 False，所以有缺失值的行会被标记为不合理（符合业务逻辑）。

## 六、自测题

1. `.between(18, 70)` 和 `(df['Age'] >= 18) & (df['Age'] <= 70)` 完全等价吗？遇到 NaN 时结果有什么区别？
2. 为什么要先筛选 `data[data['is_valid']]` 再删除标记列，而不是先删除列再筛选？
3. `~data['is_valid']` 和 `data['is_valid'] == False` 的结果相同吗？遇到 NaN 时有什么区别？

<details>
<summary>参考答案（先自测再看）</summary>

1. **遇到 NaN 时行为不同**：
   - `.between(18, 70)` 遇到 NaN 返回 NaN
   - `(df['Age'] >= 18) & (df['Age'] <= 70)` 遇到 NaN 返回 False
   - 本题中差异不大，因为 `.all(axis=1)` 会把 NaN 视为 False

2. **顺序很重要**：
   - 先筛选：基于 `is_valid` 列判断哪些行保留
   - 再删除：标记列已完成使命，删除避免污染最终数据
   - 如果先删除 `is_valid` 列，就无法筛选了

3. **遇到 NaN 时不同**：
   - `~data['is_valid']`：True → False，False → True，**NaN → NaN**
   - `data['is_valid'] == False`：True → False，False → True，**NaN → False**
   - 如果数据有缺失值导致 `is_valid` 为 NaN，两种写法会产生不同结果

</details>
