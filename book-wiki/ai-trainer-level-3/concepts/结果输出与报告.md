# 结果输出与报告

## 概念定义

结果输出与报告是机器学习工程的最后一步，将模型预测结果、评估指标、测试报告保存为文件，便于后续分析、归档和交付。

## 核心方法

### 1. 保存 DataFrame 到 CSV/TXT

```python
import pandas as pd

# 创建结果 DataFrame
results = pd.DataFrame({
    '实际值': y_test,
    '预测值': y_pred
})

# 保存为 CSV
results.to_csv('results.csv', index=False)

# 保存为 TXT（Tab 分隔）
results.to_csv('results.txt', index=False, sep='\t')
```

**参数说明**：

| 参数 | 含义 | 默认值 |
|---|---|---|
| `index` | 是否保存行号 | True |
| `sep` | 列分隔符 | `','`（CSV） |
| `encoding` | 文件编码 | `'utf-8'` |
| `float_format` | 浮点数格式 | None |

### 2. 写入文本文件

```python
# 方法 1：基础写入
with open('report.txt', 'w') as f:
    f.write('均方误差: 1234.56\n')
    f.write('平均绝对误差: 987.65\n')
    f.write('决定系数: 0.754\n')

# 方法 2：格式化字符串
with open('report.txt', 'w') as f:
    f.write(f'均方误差: {mse:.2f}\n')
    f.write(f'平均绝对误差: {mae:.2f}\n')
    f.write(f'决定系数: {r2:.3f}\n')
```

**文件模式**：
- `'w'`：写入（覆盖已有文件）
- `'a'`：追加（保留原内容）
- `'r'`：读取

### 3. 格式化输出

```python
# f-string 格式化（推荐）
mse = 1234567.89
print(f'MSE: {mse:.2f}')      # MSE: 1234567.89
print(f'MSE: {mse:,.2f}')     # MSE: 1,234,567.89（千分位）
print(f'MSE: {mse:.2e}')      # MSE: 1.23e+06（科学计数法）

# 百分比格式
r2 = 0.7543
print(f'R²: {r2:.1%}')        # R²: 75.4%

# 对齐
print(f'{"指标":<10}{"值":>10}')  # 左对齐 10 字符，右对齐 10 字符
print(f'{"MSE":<10}{mse:>10.2f}')
```

## 实际应用场景

### 场景 1：步数预测结果（2.2.5 任务）

```python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

# 预测
y_pred = model.predict(X_test)

# 1. 保存预测结果
results = pd.DataFrame({'实际值': y_test, '预测值': y_pred})
results.to_csv('2.2.5_results.txt', index=False, sep='\t')

# 2. 保存评估指标
mse = mean_squared_error(y_test, y_pred)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

with open('2.2.5_report.txt', 'w') as f:
    f.write(f'均方误差: {mse}\n')
    f.write(f'平均绝对误差: {mae}\n')
    f.write(f'决定系数: {r2}\n')

# 输出示例（2.2.5_report.txt）：
# 均方误差: 1234567.89
# 平均绝对误差: 987.65
# 决定系数: 0.7543
```

## 最佳实践

### ✅ 正确做法

```python
# 1. 使用 with 语句（自动关闭文件）
with open('report.txt', 'w') as f:
    f.write('结果\n')

# 2. 明确编码（避免中文乱码）
with open('report.txt', 'w', encoding='utf-8') as f:
    f.write('中文内容\n')

# 3. to_csv() 必须加 index=False
results.to_csv('results.txt', index=False, sep='\t')

# 4. 格式化数值（提高可读性）
f.write(f'MSE: {mse:,.2f}\n')  # 千分位 + 2 位小数

# 5. 保存前验证数据
assert len(y_test) == len(y_pred), "长度不一致"
assert not pd.isna(y_pred).any(), "预测值包含 NaN"
```

### ❌ 常见错误

```python
# 错误 1：忘记 index=False
results.to_csv('results.txt', sep='\t')  # ❌ 多一列行号 0,1,2...

# 错误 2：忘记换行符
with open('report.txt', 'w') as f:
    f.write('MSE: 1234')
    f.write('MAE: 987')  # ❌ 两行内容连在一起
# 正确：f.write('MSE: 1234\n')

# 错误 3：路径错误
results.to_csv('results/predictions.txt')  # ❌ results/ 目录不存在

# 错误 4：覆盖重要文件
with open('2.2.5_model.pkl', 'w') as f:  # ❌ 用文本模式打开二进制文件
    f.write('结果')  # 模型文件被损坏
```

## 易错点

### ⚠️ 陷阱 1：sep 参数

```python
# CSV 文件用逗号分隔
results.to_csv('results.csv', index=False)  # sep=',' 默认

# TXT 文件通常用 Tab 分隔
results.to_csv('results.txt', index=False, sep='\t')  # ✅ 更易读

# 对比输出
# CSV: 10000,9500
# TXT: 10000    9500（Tab 分隔，列对齐更清晰）
```

### ⚠️ 陷阱 2：浮点数精度

```python
mse = 1234567.89012345

# ❌ 默认输出（过多小数）
f.write(f'MSE: {mse}\n')  # MSE: 1234567.89012345

# ✅ 限制精度
f.write(f'MSE: {mse:.2f}\n')  # MSE: 1234567.89
```

### ⚠️ 陷阱 3：文件编码

```python
# Windows 中文可能乱码
with open('report.txt', 'w') as f:  # 默认编码可能是 GBK
    f.write('中文内容')

# ✅ 明确 UTF-8 编码
with open('report.txt', 'w', encoding='utf-8') as f:
    f.write('中文内容')
```

### ⚠️ 陷阱 4：DataFrame 索引问题

```python
# y_test 是 Series，有索引
y_test.index  # Int64Index([52, 103, 7, ...])

# DataFrame 行号与 y_test 索引不一致
results = pd.DataFrame({
    '实际值': y_test,      # 索引 [52, 103, 7, ...]
    '预测值': y_pred       # 普通数组，索引 [0, 1, 2, ...]
})
# ❌ 可能导致行对不上

# ✅ 重置索引或使用 .values
results = pd.DataFrame({
    '实际值': y_test.values,  # 转为普通数组
    '预测值': y_pred
})
```

3. TXT 文件用 `sep='\t'`
4. 文本文件模式用 `'w'`（不是 `'wb'`）
