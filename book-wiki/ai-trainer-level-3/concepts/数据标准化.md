# 数据标准化

- **来源章节**: 2.1.3
- **定义**: 将不同量纲的数值特征缩放到统一范围，消除量纲影响，提升模型训练效果
- **MinMaxScaler（归一化）**:
  - **公式**: $x' = \frac{x - min}{max - min}$
  - **范围**: [0, 1]
  - **用法**:
    ```python
    from sklearn.preprocessing import MinMaxScaler
    
    scaler = MinMaxScaler()
    # 只对数值列归一化
    numeric_cols = df.select_dtypes(include=['float64', 'int64']).columns
    df[numeric_cols] = scaler.fit_transform(df[numeric_cols])
    ```
  - **适用场景**: 神经网络、图像处理（需要固定 [0,1] 范围）
- **StandardScaler（标准化）**:
  - **公式**: $z = \frac{x - \mu}{\sigma}$（转为均值 0、标准差 1）
  - **适用场景**: 线性回归、逻辑回归（需要可比较的量纲）
- **选择原则**:
  - 数据分布接近正态 → StandardScaler
  - 数据有明确边界（如年龄、评分）→ MinMaxScaler
  - 神经网络通常用 MinMaxScaler
- **易错点**:
  - 归一化后必须赋值回原列：`df[cols] = scaler.fit_transform(df[cols])`
  - 只对数值列操作，字符串列（如 ID）跳过
  - `fit_transform()` 用于训练集，测试集只用 `transform()`（避免数据泄漏）
