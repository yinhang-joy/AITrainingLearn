# 模型评估指标

## 概念定义

模型评估指标用于量化机器学习模型的性能。对于回归任务，常用三大指标：均方误差（MSE）、平均绝对误差（MAE）和决定系数（R²）。

## 核心指标

### 1. 均方误差（MSE）

```python
from sklearn.metrics import mean_squared_error

mse = mean_squared_error(y_test, y_pred)
```

**定义**：预测误差的平方平均值

$$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

**特点**：
- 单位是目标变量的平方（如步数² = 步²）
- **放大大误差**的影响（因为平方）
- 越小越好，0 表示完美预测

**示例**：
```python
y_test = [10000, 8000, 9000]
y_pred = [9500, 8200, 9100]

# 误差: [-500, 200, 100]
# 平方: [250000, 40000, 10000]
# MSE = (250000 + 40000 + 10000) / 3 = 100000
```

### 2. 平均绝对误差（MAE）

```python
from sklearn.metrics import mean_absolute_error

mae = mean_absolute_error(y_test, y_pred)
```

**定义**：预测误差绝对值的平均值

$$MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

**特点**：
- 单位与目标变量一致（如步数）
- **直观易解释**：平均预测偏差多少步
- 对离群点不敏感（相比 MSE）
- 越小越好，0 表示完美预测

**示例**：
```python
y_test = [10000, 8000, 9000]
y_pred = [9500, 8200, 9100]

# 误差绝对值: [500, 200, 100]
# MAE = (500 + 200 + 100) / 3 = 266.67 步
```

### 3. 决定系数（R²）

```python
from sklearn.metrics import r2_score

r2 = r2_score(y_test, y_pred)
```

**定义**：模型解释目标变量变异的比例

$$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

其中 $\bar{y}$ 是真实值的平均值。

**特点**：
- 取值范围：**-∞ 到 1**
- **越大越好**，1 表示完美预测
- R² = 0：模型预测 = 随机猜（总是预测平均值）
- R² < 0：模型比随机猜还差

**解读**：
| R² 值 | 含义 |
|---|---|
| 1.0 | 完美预测（所有点都在拟合线上） |
| 0.9 | 优秀（模型解释 90% 的变异） |
| 0.7-0.8 | 良好 |
| 0.5-0.6 | 一般 |
| 0.3 以下 | 较差 |
| 0 | 模型无效（等同于预测平均值） |
| 负数 | 模型失败（比平均值还差） |

## 指标对比

### MSE vs MAE

```python
y_test = [100, 100, 100, 100, 100]
y_pred = [110, 105, 100, 95, 50]  # 最后一个是离群预测

mae = mean_absolute_error(y_test, y_pred)
# |10| + |5| + |0| + |5| + |50| = 70 / 5 = 14

mse = mean_squared_error(y_test, y_pred)
# 10² + 5² + 0² + 5² + 50² = 2650 / 5 = 530
```

**观察**：
- MAE = 14（平均偏差 14）
- MSE = 530（被离群点 50 主导）
- MSE 对异常值更敏感

**选择建议**：
- **MAE**：关注平均误差，希望指标直观（如「平均偏差 100 步」）
- **MSE**：希望惩罚大误差，离群预测后果严重（如医疗诊断）

### R² 的优势

```python
# 场景 1：步数预测（单位：步）
y_test = [10000, 8000, 9000]
y_pred = [9500, 8200, 9100]
mae = 266.67 步
r2 = 0.85

# 场景 2：房价预测（单位：万元）
y_test = [100, 80, 90]  # 万元
y_pred = [95, 82, 91]
mae = 2.67 万元
r2 = 0.85
```

**观察**：
- MAE 有单位，不同任务无法比较（266 步 vs 2.67 万元）
- R² 无单位，可以跨任务比较模型性能

## 实际应用场景

### 场景 1：评估步数预测模型（2.2.5 任务）

```python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

# 预测
y_pred = model.predict(X_test)

# 计算三大指标
mse = mean_squared_error(y_test, y_pred)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

# 输出报告
print(f'均方误差（MSE）: {mse:.2f}')
print(f'平均绝对误差（MAE）: {mae:.2f} 步')
print(f'决定系数（R²）: {r2:.3f}')

# 示例输出：
# 均方误差（MSE）: 1234567.89
# 平均绝对误差（MAE）: 987.65 步  ← 平均偏差约 1000 步
# 决定系数（R²）: 0.754           ← 模型解释 75.4% 的变异
```

### 场景 2：对比不同模型

```python
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import RandomForestRegressor
from sklearn.linear_model import LinearRegression

models = {
    '决策树': DecisionTreeRegressor(random_state=42),
    '随机森林': RandomForestRegressor(random_state=42),
    '线性回归': LinearRegression()
}

for name, model in models.items():
    model.fit(X_train, y_train)
    y_pred = model.predict(X_test)
    r2 = r2_score(y_test, y_pred)
    mae = mean_absolute_error(y_test, y_pred)
    print(f'{name}: R²={r2:.3f}, MAE={mae:.1f}')

# 输出：
# 决策树: R²=0.754, MAE=987.6
# 随机森林: R²=0.821, MAE=823.4  ← 最优
# 线性回归: R²=0.698, MAE=1102.3
```

## 最佳实践

### ✅ 正确做法

```python
# 1. 同时计算三大指标（全面评估）
mse = mean_squared_error(y_test, y_pred)
mae = mean_absolute_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

# 2. 计算 RMSE（MSE 的平方根，恢复原始单位）
rmse = np.sqrt(mse)
print(f'RMSE: {rmse:.2f} 步')  # 更直观

# 3. 检查评估输入
assert len(y_test) == len(y_pred), "长度不一致"
assert not np.isnan(y_pred).any(), "预测值包含 NaN"
```

### ❌ 常见错误

```python
# 错误 1：参数顺序反了
mean_squared_error(y_pred, y_test)  # ❌ 应该 (y_true, y_pred)

# 错误 2：用训练集评估
y_pred_train = model.predict(X_train)
r2 = r2_score(y_train, y_pred_train)  # ❌ 应该用测试集

# 错误 3：误解 R² 取值范围
if r2 < 0:
    print("模型失败")  # ✅ R² 可以为负
elif r2 > 1:
    print("完美模型")  # ❌ R² 不会超过 1
```

## 易错点

### ⚠️ 陷阱 1：MSE 单位不直观

```python
# 步数预测
y_test = [10000, 8000]
y_pred = [9000, 8500]

mse = mean_squared_error(y_test, y_pred)
# MSE = ((10000-9000)² + (8000-8500)²) / 2 = 625000 步²

# ❌ 容易误读为"平均误差 625000 步"（实际是步的平方）
# ✅ 应该计算 RMSE = √625000 ≈ 791 步
```

### ⚠️ 陷阱 2：R² 为负不是错误

```python
# 极差的模型可能 R² < 0
y_test = [100, 200, 300]
y_pred = [50, 50, 50]  # 总是预测 50

r2 = r2_score(y_test, y_pred)  # R² ≈ -3.5

# 解读：模型比"总是预测平均值"还差，应该放弃此模型
```

### ⚠️ 陷阱 3：单一指标不够全面

```python
# 只看 R² 可能忽略实际误差大小
# 模型 A: R²=0.90, MAE=50 步
# 模型 B: R²=0.85, MAE=30 步

# 如果业务要求预测误差 < 40 步，模型 B 更合适（尽管 R² 稍低）
```
