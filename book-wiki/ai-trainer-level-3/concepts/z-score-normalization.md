# z-score-normalization（数据标准化）

- **来源章节**: 1.1.4
- **定义**: 使用 Z-score 公式 `(x - μ) / σ` 对数值型特征进行标准化处理
- **用法**:
  ```python
  mean = df['Age'].mean()
  std = df['Age'].std()
  df['Age_std'] = (df['Age'] - mean) / std
  ```
- **公式**: `z = (x - μ) / σ`
  - `x`：原始值
  - `μ`：均值（mean）
  - `σ`：标准差（std）
- **标准化后的特征**:
  - 均值 = 0，标准差 = 1
  - z = 2 表示「比均值高 2 个标准差」
  - z = -1 表示「比均值低 1 个标准差」
- **应用场景**:
  1. 机器学习特征工程（不同量纲的特征统一尺度）
  2. 异常值检测（|z| > 3 通常认为是异常值）
  3. 数据可视化（不同指标在同一图表对比）
- **⚠️ 易错点**: 
  - 新建列保留原始数据：`df['Age_std']` 而非覆盖 `df['Age']`
  - 标准差为 0 时会除零错误（所有值相同的列）
