# Logistic回归模型

- **来源章节**: 2.2.1
- **定义**: 用于二分类问题的经典机器学习算法，通过 Sigmoid 函数把线性结果压缩到 0~1 概率值，输出预测类别
- **核心方法**:
  ```python
  from sklearn.linear_model import LogisticRegression
  
  # 1. 创建模型
  model = LogisticRegression(max_iter=1000)
  
  # 2. 训练模型
  model.fit(X_train, y_train)
  
  # 3. 预测
  y_pred = model.predict(X_test)           # 输出类别（0 或 1）
  y_prob = model.predict_proba(X_test)     # 输出概率（0~1）
  ```
- **数学原理**（面试可能问）:
  ```
  线性组合：z = w1·x1 + w2·x2 + ... + wn·xn + b
  Sigmoid 函数：P(y=1) = 1 / (1 + e^(-z))
  决策规则：P(y=1) ≥ 0.5 → 预测为 1（正类）
            P(y=1) < 0.5 → 预测为 0（负类）
  ```
  **关键特点**：
  - z → +∞ 时，P(y=1) → 1（肯定是正类）
  - z → -∞ 时，P(y=1) → 0（肯定是负类）
  - z = 0 时，P(y=1) = 0.5（不确定）
- **为什么叫「回归」却是分类算法？**
  - **历史原因**：最早用于回归问题（预测连续值），后来发现 Sigmoid 函数能把结果压缩到 0~1，适合二分类
  - **本质**：通过回归（线性组合）得到 z，再通过 Sigmoid 转成概率，最终分类
- **主要参数**:
  - `max_iter=1000`: **最大迭代次数**（默认 100，可能不够导致「未收敛」警告）
    - 考试建议：固定设为 1000，保险
  - `C=1.0`: **正则化强度**（默认 1.0，值越小正则化越强，防止过拟合）
    - 考试通常不调，用默认值
  - `class_weight='balanced'`: **类别权重**（处理数据不平衡，自动给少数类更高权重）
    - 2.2.1 不用这个参数，而是用 SMOTE 过采样
- **适用场景**:
  | 场景 | 为什么适合 Logistic 回归 |
  |---|---|
  | **信用评分** | 输出概率（80% 违约风险），可设不同阈值决策 |
  | **垃圾邮件检测** | 二分类（垃圾 / 正常），可解释性强 |
  | **疾病诊断** | 输出患病概率，医生可根据概率做决策 |
  | **广告点击预测** | 预测点击率（0~1），优化广告投放 |
- **优势 vs 劣势**:
  | 优势 | 劣势 |
  |---|---|
  | ✅ 输出概率值，业务可解释性强 | ❌ 只能处理线性可分问题 |
  | ✅ 训练速度快，适合大数据集 | ❌ 特征间复杂关系捕捉能力弱 |
  | ✅ 不需要特征缩放（相比 SVM） | ❌ 对异常值敏感 |
  | ✅ 金融/医疗行业认可（可向监管解释） | ❌ 多分类需改用 Softmax（One-vs-Rest） |
- **为什么 2.2.1 选 Logistic 回归？**
  1. **二分类问题**：预测「是否严重拖欠」（0 或 1）
  2. **可解释性要求**：金融行业需要向监管部门说明「为什么拒绝这个客户的贷款」
     - Logistic 回归：每个特征有权重系数（如「月收入低 -0.3」「逾期次数 +0.5」），可量化解释
     - 黑盒模型（神经网络）：虽然准确率高，但无法解释决策依据
  3. **输出概率值**：可根据业务需求调整阈值（如「概率 >0.3 即判高风险」，宁可误伤也不放过）
- **预测方法对比**:
  ```python
  # 方法 1：predict() 输出类别
  y_pred = model.predict(X_test)
  # 结果：[0, 1, 0, 1, ...] 直接给类别
  
  # 方法 2：predict_proba() 输出概率
  y_prob = model.predict_proba(X_test)
  # 结果：[[0.8, 0.2], [0.3, 0.7], ...] 
  # 第一列是 P(y=0)，第二列是 P(y=1)
  
  # 业务应用：根据概率调整决策
  # 例：银行设阈值 0.3（比默认 0.5 更严格）
  y_pred_strict = (y_prob[:, 1] > 0.3).astype(int)
  ```
- **常见问题**:
  **Q1: 为什么设 `max_iter=1000`？**
  A: 默认 100 次迭代可能不够，模型未收敛会报警告：
  ```
  ConvergenceWarning: lbfgs failed to converge (status=1):
  STOP: TOTAL NO. of ITERATIONS REACHED LIMIT.
  ```
  设 1000 保险（训练时间只多几毫秒）。
  
  **Q2: 训练集准确率 95%，测试集 85%，正常吗？**
  A: 正常。训练集见过数据，准确率高；测试集是新数据，有泛化损失。差距 <10% 可接受；差距 >20% 说明过拟合。
  
  **Q3: 什么时候用 Logistic 回归，什么时候用随机森林？**
  A: 
  - **Logistic 回归**：数据线性可分 + 需要可解释性（金融、医疗）
  - **随机森林**：特征间关系复杂 + 数据有噪声 + 不要求解释（推荐系统）
- **易错点**:
  - ❌ 不设 `max_iter`，模型未收敛 → 设 `max_iter=1000`
  - ❌ 用训练集评估 → 准确率虚高 → 用测试集评估
  - ❌ 忘记特征和目标变量已分离 → `model.fit(X_train, y_train)` 不是 `model.fit(data)`
  - ✅ 固定流程：创建模型 → fit 训练 → predict 预测 → 评估
