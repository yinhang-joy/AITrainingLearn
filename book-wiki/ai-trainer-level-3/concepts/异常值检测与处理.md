# 异常值检测与处理

- **来源章节**: 2.1.3
- **定义**: 使用统计方法识别并过滤数据中偏离正常范围的极端值
- **检测方法**:
  - **箱线图可视化**: `plt.boxplot()` 或 `sns.boxplot()` 直观展示异常值分布
  - **IQR 方法**: 四分位距（IQR = Q3 - Q1）判定边界
    - 下界 = Q1 - 1.5 × IQR
    - 上界 = Q3 + 1.5 × IQR
    - 超出边界视为异常值
- **处理步骤**:
  ```python
  # 1. 计算分位数
  Q1 = data[numeric_cols].quantile(0.25)
  Q3 = data[numeric_cols].quantile(0.75)
  IQR = Q3 - Q1
  
  # 2. 定义边界
  lower = Q1 - 1.5 * IQR
  upper = Q3 + 1.5 * IQR
  
  # 3. 过滤异常值（保留正常值）
  data_cleaned = data[~((data[numeric_cols] < lower) | 
                         (data[numeric_cols] > upper)).any(axis=1)]
  ```
- **易错点**:
  - `~` 表示取反，保留非异常值
  - `.any(axis=1)` 表示每行只要有一列异常就标记为 True
  - `quantile()` 只对数值列有效，需要先用 `.select_dtypes()` 筛选
