# 模型持久化与预测

- **来源章节**: 2.2.1
- **定义**: 将训练好的模型保存为文件（持久化），下次直接加载使用，无需重新训练；并对新数据进行预测
- **核心方法**:
  ```python
  import pickle
  
  # 1. 保存模型（序列化）
  with open('2.2.1_model.pkl', 'wb') as file:
      pickle.dump(model, file)
  
  # 2. 加载模型（反序列化）
  with open('2.2.1_model.pkl', 'rb') as file:
      loaded_model = pickle.load(file)
  
  # 3. 预测
  y_pred = loaded_model.predict(X_test)
  
  # 4. 保存预测结果
  pd.DataFrame(y_pred, columns=['预测结果']).to_csv('2.2.1_results.txt', index=False)
  ```
- **为什么要持久化？**
  | 场景 | 不持久化的问题 | 持久化后的好处 |
  |---|---|---|
  | **生产环境** | 每次预测都训练一遍（慢） | 训练一次，加载秒级预测 |
  | **模型交付** | 客户无法复现你的模型 | 交付 `.pkl` 文件，客户直接用 |
  | **版本管理** | 无法回退到旧版本模型 | 保存多个版本（`model_v1.pkl` / `model_v2.pkl`） |
  | **考试提交** | 无法证明模型训练成功 | 提交 `.pkl` 文件作为交付物 |
- **pickle 模块详解**:
  - **作用**：Python 对象序列化（转成二进制）和反序列化（二进制转回对象）
  - **支持对象**：几乎所有 Python 对象（模型、DataFrame、字典、列表等）
  - **文件扩展名**：`.pkl`（pickle 的缩写），也可用 `.pickle`
  - **文件特性**：
    - 二进制格式，直接打开是乱码
    - 只能用 `pickle.load()` 加载
    - 跨平台（Windows 训练，Linux 加载）
- **关键参数**:
  ```python
  # 保存模型
  with open('文件路径', 'wb') as file:  # 'wb' = write binary（写二进制）
      pickle.dump(对象, file)
  
  # 加载模型
  with open('文件路径', 'rb') as file:  # 'rb' = read binary（读二进制）
      对象 = pickle.load(file)
  ```
  **⚠️ 文件模式必须是二进制（'wb' / 'rb'）**，不能用文本模式（'w' / 'r'），否则报错：
  ```
  TypeError: write() argument must be str, not bytes
  ```
- **预测结果保存**:
  ```python
  # y_pred 是 NumPy 数组：[0, 1, 0, 1, ...]
  # 转成 DataFrame 保存为 CSV
  pd.DataFrame(y_pred, columns=['预测结果']).to_csv('2.2.1_results.txt', index=False)
  
  # index=False 的作用：不保存行索引
  # ✅ 有 index=False：
  # 预测结果
  # 0
  # 1
  # 0
  # ❌ 没有 index=False：
  # ,预测结果
  # 0,0
  # 1,1
  # 2,0  ← 多了一列无意义的行号
  ```
- **完整流程示例**:
  ```python
  # === 第一次运行：训练并保存 ===
  model = LogisticRegression(max_iter=1000)
  model.fit(X_train, y_train)
  
  with open('2.2.1_model.pkl', 'wb') as file:
      pickle.dump(model, file)
  
  # === 第二次运行：加载并预测（无需重新训练）===
  with open('2.2.1_model.pkl', 'rb') as file:
      model = pickle.load(file)
  
  y_pred = model.predict(X_test)
  pd.DataFrame(y_pred, columns=['预测结果']).to_csv('2.2.1_results.txt', index=False)
  ```
- **其他序列化方法**（拓展，考试不涉及）:
  | 方法 | 适用场景 | 优劣 |
  |---|---|---|
  | **pickle** | sklearn 模型、通用 Python 对象 | ✅ 通用性强 ❌ 只支持 Python |
  | **joblib** | 大型 NumPy 数组、sklearn 模型 | ✅ 压缩率高、速度快 ❌ 只支持 Python |
  | **ONNX** | 跨语言部署（Python 训练 → C++/Java 部署）| ✅ 跨平台 ❌ 转换复杂 |
  | **TensorFlow SavedModel** | TensorFlow/Keras 模型 | ✅ 官方推荐 ❌ 只支持 TF 模型 |
  
  **考试只用 pickle**，其他了解即可。
- **常见问题**:
  **Q1: `.pkl` 文件可以直接打开看吗？**
  A: 不行。它是二进制格式，记事本打开是乱码。只能用 `pickle.load()` 加载后操作。
  
  **Q2: 保存模型时报错 `AttributeError: Can't pickle local object`？**
  A: 模型中有 lambda 函数或局部对象，pickle 无法序列化。解决方法：
  - 改用 `joblib` 或 `dill`
  - 避免在模型中使用 lambda
  
  **Q3: 不同版本的 sklearn，`.pkl` 文件能通用吗？**
  A: 不保证。sklearn 1.0 训练的模型，sklearn 0.24 可能加载失败。建议：
  - 记录训练时的 sklearn 版本（`sklearn.__version__`）
  - 部署环境安装相同版本
  
  **Q4: 为什么不直接保存预测代码，每次重新预测？**
  A: 训练慢（2.2.1 是秒级，但复杂模型可能几小时），且训练有随机性（即使 `random_state` 固定，不同环境结果也可能微调）。
- **考试注意事项**:
  - 文件命名严格按要求：`2.2.1_model.pkl`（不能是 `model.pkl` / `2.2.1.pkl`）
  - 预测结果保存为 `.txt`（虽然是 CSV 格式，但考试要求后缀 `.txt`）
  - `index=False` 必加（否则多一列行号，考试可能扣分）
  - 文件保存路径：考生文件夹（桌面「准考证号+身份证后6位」）
- **易错点**:
  - ❌ 文件模式写成 `'w'` / `'r'` → 应为 `'wb'` / `'rb'`（二进制）
  - ❌ 忘记 `index=False` → 预测结果多一列行号
  - ❌ 文件命名不规范 → 严格按考试要求命名
  - ✅ 固定模板：`with open(..., 'wb') as file: pickle.dump(model, file)`
