# 线性回归模型（Linear Regression）

**适用场景**：预测连续数值型目标变量（如房价、温度、分数）

---

## 核心概念

**线性回归**：假设目标变量 y 与特征 X 之间存在线性关系，通过找到最佳拟合直线（或超平面）来预测新数据。

---

## 数学原理

### 一元线性回归（一个特征）
```
y = wx + b
```
- `w`：权重（斜率）
- `b`：偏置（截距）
- 目标：找到最佳的 w 和 b，使预测值接近真实值

### 多元线性回归（多个特征）
```
y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

### 目标函数：最小化均方误差
```
损失 = (1/n) × Σ(真实值 - 预测值)²
```

---

## sklearn 实现

### 基本流程
```python
from sklearn.linear_model import LinearRegression

# 1. 初始化模型
model = LinearRegression()

# 2. 训练模型
model.fit(X_train, y_train)

# 3. 预测
y_pred = model.predict(X_test)

# 4. 评估
from sklearn.metrics import mean_squared_error, r2_score
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)
```

### 查看模型参数
```python
# 权重（系数）
print(model.coef_)        # 每个特征的权重 w
print(model.intercept_)   # 偏置 b

# 解释性示例
# 如果 model.coef_ = [0.5, -0.3]，model.intercept_ = 2.0
# 则预测公式为：y = 0.5*x₁ - 0.3*x₂ + 2.0
```

---

## 优点与缺点

### 优点
1. **简单易懂**：公式直观，参数可解释
2. **训练快速**：计算复杂度低，适合大数据集
3. **可解释性强**：可以看到每个特征的贡献（权重 w）

### 缺点
1. **只能拟合线性关系**：对非线性数据效果差
2. **对异常值敏感**：极端值会严重影响拟合结果
3. **假设独立性**：要求特征之间不高度相关（多重共线性问题）

---

## 适用场景判断

### 适合用线性回归
- 目标变量是**连续数值**（不是分类）
- 特征与目标呈**线性关系**
- 数据**无严重异常值**
- 需要**模型可解释性**

### 不适合用线性回归（考虑其他模型）
- 关系明显非线性 → **多项式回归** / **决策树** / **神经网络**
- 目标是分类变量 → **逻辑回归** / **SVM** / **随机森林**
- 数据有大量异常值 → **鲁棒回归** / **树模型**

---

## 线性回归变种

### 1. 岭回归（Ridge Regression）
```python
from sklearn.linear_model import Ridge
model = Ridge(alpha=1.0)  # alpha 控制正则化强度
```
- 添加 L2 正则化，防止过拟合
- 适用于特征高度相关的情况

### 2. Lasso 回归
```python
from sklearn.linear_model import Lasso
model = Lasso(alpha=1.0)
```
- 添加 L1 正则化，可以进行**特征选择**（部分权重会变为 0）

### 3. 多项式回归
```python
from sklearn.preprocessing import PolynomialFeatures
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(X)
model = LinearRegression()
model.fit(X_poly, y)
```
- 将特征扩展为多项式（如 x₁² + x₁x₂），再用线性回归拟合
- 可以拟合非线性关系

## 实际应用示例（2.2.4 原题）

```python
from sklearn.linear_model import LinearRegression

# 初始化模型
model = LinearRegression()

# 训练模型
model.fit(X_train, y_train)

# 预测测试集
y_pred = model.predict(X_test)

# 查看模型参数
print(f"特征数量: {len(model.coef_)}")
print(f"截距: {model.intercept_:.4f}")

# 保存模型
import joblib
joblib.dump(model, '2.2.4_model.pkl')
```

## 考试常见错误

### 错误 1：混淆分类和回归
```python
# 错误：用线性回归做分类
y = [0, 1, 0, 1]  # 类别标签
model = LinearRegression()  # 应该用 LogisticRegression

# 正确：用逻辑回归做分类
from sklearn.linear_model import LogisticRegression
model = LogisticRegression()
```

### 错误 2：忘记 fit 就 predict
```python
model = LinearRegression()
y_pred = model.predict(X_test)  # 报错：模型未训练

# 正确：先 fit 再 predict
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

### 错误 3：X 和 y 形状错误
```python
# 错误：X 必须是二维，y 必须是一维
X = [1, 2, 3]        # 一维列表
y = [[1], [2], [3]]  # 二维数组

# 正确
X = [[1], [2], [3]]  # 二维：n_samples × n_features
y = [1, 2, 3]        # 一维：n_samples
```

## 可视化理解

### 一元线性回归
```python
import matplotlib.pyplot as plt

# 绘制拟合直线
plt.scatter(X, y, label='真实数据')
plt.plot(X, model.predict(X), color='red', label='拟合直线')
plt.legend()
plt.show()
```

### 残差图（诊断拟合质量）
```python
residuals = y_test - y_pred
plt.scatter(y_pred, residuals)
plt.axhline(y=0, color='red', linestyle='--')
plt.xlabel('预测值')
plt.ylabel('残差')
plt.show()
```
- 残差应该随机分布在 0 附近
- 如果有明显模式（如U形），说明模型未捕捉非线性关系
