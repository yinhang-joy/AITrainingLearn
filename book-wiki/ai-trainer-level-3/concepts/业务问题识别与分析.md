# 业务问题识别与分析

- **来源章节**: 1.2.5
- **定义**: 从用户反馈、数据监控、业务流程中，发现影响用户体验和业务目标的痛点，并分析其影响机制
- **方法**:
  - **用户反馈收集**: 工单、投诉、用户评价、问卷调查
  - **问题分类**: 按模块分类（如 ASR / NLU / TTS），按影响分类（体验 / 效率 / 成本）
  - **影响分析**: 问题 → 用户感受 → 业务损失路径分析
- **应用场景**: 数智人系统、智能客服、推荐系统等 AI 业务系统的问题诊断
- **答题模板**:
  ```
  问题 X：[具体表现]
  ↓
  用户感受：[为什么不满？]
  ↓
  影响：[对用户体验 / 服务质量的具体影响]
  ```
- **常见问题类型**:
  - 响应不准确：答非所问、理解错误 → 沟通困难 → 流失用户
  - 缺乏个性化：千篇一律 → 冷冰冰 → 满意度低
  - 响应速度慢：等待时间长 → 不耐烦 → 放弃使用
  - 情感理解差：无法识别情绪 → 不被理解 → 负面情绪加剧
- **易错点**: 只描述问题表面现象，不分析用户感受和业务影响；问题太泛化，缺乏具体案例
