# 特征编码

- **来源章节**: 2.2.3
- **定义**: 将分类变量（如性别、评价等文本）转换为数值变量，使机器学习算法能够处理
- **用法**:
  ```python
  # 选择分类特征列
  X = df[['Your gender', 'How important is exercise to you ?', 
          'How healthy do you consider yourself?']]
  
  # 独热编码（One-Hot Encoding）
  X = pd.get_dummies(X)
  
  # 目标变量：年龄段文本转数值
  y = df['Your age'].apply(lambda x: int(x.split(' ')[0]))
  ```
- **核心方法**:
  - `pd.get_dummies()`: 独热编码，每个类别变成一列（0/1）
  - `df['列'].apply(lambda x: ...)`: 对每行应用自定义函数
  - `str.split(' ')[0]`: 按空格切分取第一个元素
- **独热编码原理**:
  ```
  原始数据:        编码后:
  性别              性别_Female  性别_Male
  Female           1           0
  Male             0           1
  ```
- **为什么要编码**: 机器学习算法只能处理数值，不能直接处理 "Female"、"Male" 这样的文本
- **易错点**: 
  - 年龄段 "19 to 25" 需要提取数字部分（取下界 19）
  - `get_dummies()` 会自动为每个类别创建新列，原列消失
