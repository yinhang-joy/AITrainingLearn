# 模型持久化

## 概念定义

模型持久化（Model Persistence）是将训练好的机器学习模型保存到磁盘，以便后续加载使用，避免重复训练。Python 中常用 `pickle` 模块进行序列化。

## 核心方法

### 1. 保存模型（pickle.dump）

```python
import pickle

# 训练模型
model = DecisionTreeRegressor(random_state=42)
model.fit(X_train, y_train)

# 保存模型
with open('model.pkl', 'wb') as file:
    pickle.dump(model, file)
```

**参数说明**：
- `'wb'`：**w**rite **b**inary（二进制写入模式）
- `pickle.dump(obj, file)`：将对象 `obj` 序列化到文件 `file`

### 2. 加载模型（pickle.load）

```python
import pickle

# 加载模型
with open('model.pkl', 'rb') as file:
    loaded_model = pickle.load(file)

# 直接使用
y_pred = loaded_model.predict(X_test)
```

**参数说明**：
- `'rb'`：**r**ead **b**inary（二进制读取模式）
- `pickle.load(file)`：从文件反序列化对象

### 3. 文件命名规范

```python
# 2.2.5 任务要求
with open('2.2.5_model.pkl', 'wb') as model_file:
    pickle.dump(model, model_file)

# 推荐命名方式
# 格式：<任务编号>_<描述>_<版本>.pkl
# 示例：
# - step_prediction_v1.pkl
# - decision_tree_2024_08_20.pkl
# - model_final.pkl
```

## 为什么需要持久化？

### 场景 1：避免重复训练

```python
# ❌ 不持久化：每次重启程序都要重新训练
model = DecisionTreeRegressor(random_state=42)
model.fit(X_train, y_train)  # 可能耗时几分钟到几小时

# ✅ 持久化：训练一次，永久使用
# 第一次训练
model.fit(X_train, y_train)
pickle.dump(model, open('model.pkl', 'wb'))

# 后续使用
model = pickle.load(open('model.pkl', 'rb'))
y_pred = model.predict(X_new)  # 秒级响应
```

### 场景 2：模型部署

```python
# 开发环境：训练模型
model = train_model(X_train, y_train)
pickle.dump(model, open('production_model.pkl', 'wb'))

# 生产环境（服务器/App）：只需加载
model = pickle.load(open('production_model.pkl', 'rb'))

@app.route('/predict')
def predict():
    user_data = get_user_input()
    prediction = model.predict(user_data)
    return jsonify({'steps': prediction})
```

### 场景 3：版本管理

```python
# 训练多个版本
models = {
    'v1': DecisionTreeRegressor(max_depth=5),
    'v2': DecisionTreeRegressor(max_depth=10),
    'v3': RandomForestRegressor(n_estimators=100)
}

for name, model in models.items():
    model.fit(X_train, y_train)
    pickle.dump(model, open(f'model_{name}.pkl', 'wb'))

# A/B 测试：加载不同版本对比性能
model_v1 = pickle.load(open('model_v1.pkl', 'rb'))
model_v2 = pickle.load(open('model_v2.pkl', 'rb'))
```

## 实际应用场景

### 场景 1：步数预测（2.2.5 任务）

```python
import pickle
from sklearn.tree import DecisionTreeRegressor

# 训练模型
model = DecisionTreeRegressor(random_state=42)
model.fit(X_train, y_train)

# 保存模型（题目要求）
with open('2.2.5_model.pkl', 'wb') as model_file:
    pickle.dump(model, model_file)

# 后续加载使用
with open('2.2.5_model.pkl', 'rb') as model_file:
    loaded_model = pickle.load(model_file)

# 验证加载正确
y_pred_original = model.predict(X_test)
y_pred_loaded = loaded_model.predict(X_test)
assert (y_pred_original == y_pred_loaded).all(), "加载的模型预测不一致"
```

### 场景 2：保存多个对象

```python
import pickle

# 同时保存模型、标准化器、特征名
model_package = {
    'model': model,
    'scaler': scaler,
    'feature_names': X.columns.tolist(),
    'training_date': '2024-08-20',
    'metrics': {'r2': 0.85, 'mae': 987.65}
}

with open('model_package.pkl', 'wb') as f:
    pickle.dump(model_package, f)

# 加载
with open('model_package.pkl', 'rb') as f:
    package = pickle.load(f)
    
model = package['model']
scaler = package['scaler']
print(f"训练日期: {package['training_date']}")
print(f"R²: {package['metrics']['r2']}")
```

### ✅ 正确做法

```python
# 1. 使用 with 语句（自动关闭文件）
with open('model.pkl', 'wb') as f:
    pickle.dump(model, f)

# 2. 添加错误处理
try:
    with open('model.pkl', 'rb') as f:
        model = pickle.load(f)
except FileNotFoundError:
    print("模型文件不存在，开始训练...")
    model = train_new_model()

# 3. 验证加载成功
with open('model.pkl', 'rb') as f:
    model = pickle.load(f)
    assert hasattr(model, 'predict'), "加载的对象不是模型"

# 4. 记录元数据
metadata = {
    'model': model,
    'version': '1.0',
    'date': '2024-08-20',
    'features': X.columns.tolist()
}
with open('model_with_metadata.pkl', 'wb') as f:

```

### ❌ 常见错误

```python
# 错误 1：忘记 'b' 模式
with open('model.pkl', 'w') as f:  # ❌ 应该是 'wb'
    pickle.dump(model, f)  # 报错：write() argument must be str, not bytes

# 错误 2：不用 with 语句（忘记关闭文件）
f = open('model.pkl', 'wb')
pickle.dump(model, f)
# ❌ 忘记 f.close()，文件可能损坏

# 错误 3：覆盖原模型文件
pickle.dump(new_model, open('model.pkl', 'wb'))  # ❌ 没有备份，旧模型丢失
# ✅ 应该先备份或用新文件名

# 错误 4：跨版本加载
# Python 3.9 训练并保存的模型
pickle.dump(model, open('model.pkl', 'wb'))

# Python 3.7 加载可能失败
model = pickle.load(open('model.pkl', 'rb'))  # ❌ 可能报错
```

## 易错点

### ⚠️ 陷阱 1：文件模式错误

```python
# ❌ 错误（文本模式）
with open('model.pkl', 'w') as f:
    pickle.dump(model, f)
# TypeError: write() argument must be str, not bytes

# ✅ 正确（二进制模式）
with open('model.pkl', 'wb') as f:
    pickle.dump(model, f)
```

**记忆方法**：pickle 处理**二进制**数据，必须用 `'wb'` / `'rb'`

### ⚠️ 陷阱 2：变量名混淆

```python
# ❌ 错误（pickle.dump 第二个参数是文件对象）
pickle.dump(model)  # TypeError: dump() missing 1 required positional argument

# ❌ 错误（参数顺序反了）
with open('model.pkl', 'wb') as f:
    pickle.dump(f, model)  # 第一个参数应该是要保存的对象

# ✅ 正确
with open('model.pkl', 'wb') as f:
    pickle.dump(model, f)  # 对象在前，文件在后
```

### ⚠️ 陷阱 3：路径问题

```python
# ❌ 错误（相对路径，保存位置不确定）
pickle.dump(model, open('model.pkl', 'wb'))
# 可能保存在当前工作目录，不是脚本所在目录

# ✅ 正确（使用绝对路径或明确相对路径）
import os
save_dir = os.path.dirname(__file__)  # 脚本所在目录
save_path = os.path.join(save_dir, 'model.pkl')
pickle.dump(model, open(save_path, 'wb'))
```

### ⚠️ 陷阱 4：sklearn 版本兼容性

```python
# sklearn 1.0 训练的模型
# Python 3.9, sklearn 1.0
pickle.dump(model, open('model.pkl', 'wb'))

# sklearn 0.24 加载可能失败
# Python 3.7, sklearn 0.24
model = pickle.load(open('model.pkl', 'rb'))
# ModuleNotFoundError: No module named 'sklearn.tree._classes'

# ✅ 解决方法：保持 sklearn 版本一致
```

## 安全注意事项

### ⚠️ pickle 安全风险

```python
# pickle 可以执行任意 Python 代码，不要加载不可信的 .pkl 文件
model = pickle.load(open('untrusted_model.pkl', 'rb'))
# ❌ 如果文件被恶意篡改，可能执行危险代码

# ✅ 生产环境建议：
# 1. 只加载可信来源的模型
# 2. 使用 joblib（更安全）
# 3. 或使用模型格式如 ONNX、PMML
```

### 使用 joblib（推荐替代方案）

```python
from joblib import dump, load

# 保存（速度更快，压缩更好）
dump(model, 'model.joblib')

# 加载
model = load('model.joblib')

# 优势：
# - 处理大型 numpy 数组更高效
# - 更好的压缩（文件更小）
# - 更安全（相对 pickle）
```

## pickle vs joblib vs ONNX

| 方法 | 优势 | 劣势 | 适用场景 |
|---|---|---|---|
| **pickle** | 简单、内置、通用 | 不安全、跨版本差、文件大 | 小型项目、临时保存 |
| **joblib** | 快速、压缩好、适合 numpy | 仅 Python 环境 | sklearn 模型、大数据 |
| **ONNX** | 跨平台、跨语言、生产级 | 学习成本高、转换复杂 | 生产部署、移动端 |
