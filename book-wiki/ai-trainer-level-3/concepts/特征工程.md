# 特征工程

- **来源章节**: 2.1.3
- **定义**: 基于原始数据创建、选择、转换特征，提升模型性能
- **核心操作**:
  - **特征创建**（Feature Creation）:
    ```python
    # 示例：创建收入负债比特征
    df['IncomeToDebtRatio'] = df['MonthlyIncome'] / df['DebtRatio']
    
    # 示例：年龄分段
    df['AgeGroup'] = pd.cut(df['Age'], bins=[0, 30, 50, 100], 
                             labels=['青年', '中年', '老年'])
    ```
  - **特征选择**（Feature Selection）:
    ```python
    # 分离特征变量 X 和目标变量 y
    target = 'SeriousDlqin2yrs'
    X = df.drop(columns=[target])   # 特征矩阵
    y = df[target]                   # 目标变量
    ```
  - **特征转换**: 见 [[数据标准化]]（归一化、标准化）
- **常见衍生特征**:
  - 比值特征：收入/支出、点击率、转化率
  - 交叉特征：年龄×收入、城市×职业
  - 时间特征：星期几、是否节假日、时间间隔
  - 统计特征：历史平均值、最大值、方差
- **特征工程规范**（答题卷参考）:
  1. 根据业务逻辑创建衍生特征，提升模型表达能力
  2. 分离特征变量 X 和目标变量 y，为模型训练做准备
  3. 删除无关特征（如 ID、时间戳），避免模型过拟合
- **易错点**:
  - `drop(columns=[...])` 不修改原 DataFrame，需要赋值 `X = df.drop(...)`
  - 创建新特征前要先清洗数据（处理缺失值、异常值）
  - 测试集的特征工程要与训练集保持一致
