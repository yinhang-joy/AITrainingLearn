# 数据集划分

- **来源章节**: 2.1.3
- **定义**: 将数据按比例分为训练集和测试集，用于模型训练和评估
- **用法**:
  ```python
  from sklearn.model_selection import train_test_split
  
  # 划分数据（训练集 80%，测试集 20%）
  X_train, X_test, y_train, y_test = train_test_split(
      X, y, 
      test_size=0.2,      # 测试集占比
      random_state=42     # 随机种子（保证可复现）
  )
  
  print(f'训练数据形状: {X_train.shape}')
  print(f'测试数据形状: {X_test.shape}')
  ```
- **参数说明**:
  - `test_size`：测试集比例（0.2 表示 20%，训练集自动为 80%）
  - `random_state`：随机种子，固定后每次划分结果相同（可复现实验）
  - `stratify`：分层采样参数（分类任务中保证各类别比例，本题未用）
- **返回值顺序**（易错点）:
  ```python
  # ✅ 正确顺序：X_train, X_test, y_train, y_test
  X_train, X_test, y_train, y_test = train_test_split(X, y, ...)
  
  # ❌ 错误（X 和 y 顺序颠倒）
  X_train, X_test, y_train, y_test = train_test_split(y, X, ...)
  ```
- **训练集 vs 测试集**:
  - **训练集**：用于训练模型参数
  - **测试集**：用于评估模型泛化能力（模型从未见过的数据）
  - **验证集**（本题未用）：用于调参（从训练集再划分或交叉验证）
- **易错点**:
  - 先做特征工程（创建特征、分离 X/y），再划分数据集
  - `test_size=0.2` 不是 `test_size=20`（是比例不是百分比）
  - 归一化在划分后分别对训练集和测试集操作（避免数据泄漏）
