# feature-engineering（特征工程）

- **来源章节**: 2.1.2
- **定义**: 从原始数据中选择、提取、构造有效特征（X）和目标变量（y），为机器学习模型准备输入
- **用法**:
  ```python
  # 特征选择
  selected_features = ['性别', '年级', '生源地', '月生活费', '低碳问题1', ...]
  X = data[selected_features]       # 特征矩阵（输入）
  y = data['低碳行为积极性']         # 目标变量（输出）
  ```
- **核心概念**:
  - **X（特征/自变量）**: 用于预测的输入，可以是人口统计特征、行为特征、问卷得分等
  - **y（目标/因变量）**: 要预测的输出，如分类标签、回归数值
- **选择标准**:
  1. **相关性强**：与目标变量有统计相关性
  2. **业务意义明确**：符合领域知识和因果逻辑
  3. **数据质量好**：缺失率低、区分度高
- **常见操作**:
  - 特征选择：从 41 列中挑出 8 列
  - 特征构造：组合已有特征（如 BMI = 体重/身高²）
  - 特征编码：类别变量转数值（独热编码、标签编码）
- **易错点**: 选择特征时不要包含目标变量本身；避免数据泄露（未来信息）
