# 数据加载与预处理

- **来源章节**: 2.2.1
- **定义**: 读取原始数据集，进行初步检查和清理，选择有效特征，准备模型训练的输入数据
- **核心方法**:
  - **数据读取**: `pd.read_csv('文件路径')` 加载 CSV 格式数据集
  - **数据查看**: `data.head()` 显示前 5 行，`data.info()` 查看列类型和缺失值
  - **特征选择**: `data.drop(['列名'], axis=1)` 删除无关列（索引号、目标变量等）
- **操作流程**:
  ```python
  # 1. 加载数据
  data = pd.read_csv('finance数据集.csv')
  
  # 2. 验证数据（新手必做）
  print(data.head())        # 查看前 5 行
  print(data.info())        # 列名、类型、缺失值
  print(data.describe())    # 数值列统计量
  
  # 3. 特征工程：分离 X（特征）和 y（目标）
  X = data.drop(['SeriousDlqin2yrs', 'Unnamed: 0'], axis=1)
  y = data['SeriousDlqin2yrs']
  ```
- **关键参数**:
  - `axis=1`: 删除**列**（`axis=0` 删行）
  - `drop()` 删除的列：
    - **目标变量**（如 `SeriousDlqin2yrs`）：需要单独拎出来作为 y
    - **无意义列**（如 `Unnamed: 0` 索引号）：对预测无帮助
- **常见数据问题及处理**:
  | 问题 | 检测方法 | 处理方案 |
  |---|---|---|
  | 缺失值 | `data.isnull().sum()` | 删除 `dropna()` / 填充 `fillna()` |
  | 重复行 | `data.duplicated().sum()` | `drop_duplicates()` |
  | 异常值 | `data.describe()` 看极值 | 箱线图法 / Z-score 过滤 |
  | 类型错误 | `data.info()` | `astype()` 转换 |
- **业务理解**（以 2.2.1 信用评分为例）:
  - **保留特征**：年龄、月收入、逾期次数、债务比率 → 与信用直接相关
  - **删除特征**：`Unnamed: 0`（行索引编号）→ 类似身份证号，与信用无关
  - **目标变量**：`SeriousDlqin2yrs`（是否严重拖欠）→ 需要单独作为 y
- **易错点**:
  - ❌ 忘记查看数据就直接训练（数据可能有缺失值、格式错误）
  - ❌ 把目标变量也放进 X（模型会「偷看答案」，准确率虚高）
  - ❌ `axis` 参数搞反（`axis=0` 删行，`axis=1` 删列）
  - ✅ 先 `head()` / `info()` 检查 → 再 `drop()` 删除无关列 → 最后分离 X 和 y
- **验证清单**（提交前必查）:
  - [ ] X 的列数 = 原始数据列数 - 2（目标变量 + 索引列）
  - [ ] X 中没有目标变量（`'SeriousDlqin2yrs' in X.columns` 应为 `False`）
  - [ ] y 的类型是 Series，值只有 0 和 1
  - [ ] X 和 y 的行数相同（`len(X) == len(y)`）
