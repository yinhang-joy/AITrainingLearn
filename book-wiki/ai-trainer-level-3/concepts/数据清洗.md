# 数据清洗

- **来源章节**: 2.1.3
- **定义**: 检测并处理数据质量问题（缺失值、重复值、异常值），确保数据可用于模型训练
- **核心操作**:
  - **加载数据**: `pd.read_csv('file.csv')`
  - **数据探索**: `df.head()`、`df.info()`、`df.describe()`
  - **重复值处理**:
    ```python
    duplicates = df.duplicated()           # 检测重复行
    num_duplicates = duplicates.sum()      # 统计数量
    df = df.drop_duplicates()              # 删除重复行（保留首次出现）
    # 或布尔索引：df = df[~duplicates]
    ```
  - **异常值处理**: 见 [[异常值检测与处理]]
  - **缺失值处理**: `df.dropna()` 删除 / `df.fillna()` 填充（1.1.2 已学）
- **检查步骤**:
  1. 查看数据前几行 `head()`
  2. 统计缺失值 `isnull().sum()`
  3. 检测重复行 `duplicated().sum()`
  4. 可视化异常值（箱线图）
- **易错点**:
  - `.duplicated()` 默认判断所有列完全相同才算重复
  - `.drop_duplicates()` 默认保留第一次出现的行
  - 布尔索引过滤用 `df[~duplicates]`，`~` 表示取反
