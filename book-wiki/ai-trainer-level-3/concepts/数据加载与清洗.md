# 数据加载与清洗

- **来源章节**: 2.2.3
- **定义**: 读取 CSV 数据集，去除字符串字段和列名的空格，确保数据格式一致
- **用法**:
  ```python
  df = pd.read_csv('fitness analysis.csv')
  df.head()  # 显示前 5 行
  
  # 去除所有字符串字段的空格
  df = df.applymap(lambda x: x.strip() if isinstance(x, str) else x)
  
  # 清理列名空格
  df.columns = df.columns.str.strip()
  ```
- **核心方法**:
  - `pd.read_csv()`: 读取 CSV 文件为 DataFrame
  - `df.applymap()`: 对每个单元格应用函数（pandas 2.x 改名为 `df.map()`）
  - `isinstance(x, str)`: 判断是否为字符串类型
  - `str.strip()`: 去除字符串首尾空格
  - `df.columns.str.strip()`: 去除列名空格
- **易错点**: 
  - 原始数据可能是 `"Female "` 而非 `"Female"`，导致后续编码失败
  - 列名带空格会导致 `df['列名']` 选列报错
  - `applymap()` 必须加类型判断，否则对数字调用 `strip()` 会报错
