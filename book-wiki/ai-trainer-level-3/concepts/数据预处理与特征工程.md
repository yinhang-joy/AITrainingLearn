# 数据预处理与特征工程

**适用场景**：任何机器学习项目的第一步，将原始数据转换为模型可用的格式

---

## 核心概念

**数据预处理**：清洗和转换原始数据的过程
**特征工程**：从原始数据中提取、构造、选择对模型有用的特征

---

## 常见操作

### 1. 删除无关列
```python
data_cleaned = data.drop(columns=['序号', '所用时间'])
```
- 删除对预测无帮助的列（如ID、时间戳）
- 减少噪声，提高模型性能

### 2. 处理分类变量（独热编码）
```python
data_cleaned = pd.get_dummies(data_cleaned, drop_first=True)
```
- 将分类变量转换为数值格式
- 详见 [[concepts/独热编码]]

### 3. 处理缺失值
```python
data.dropna()              # 删除含缺失值的行
data.fillna(0)             # 用0填充
data.fillna(data.mean())   # 用均值填充
```

### 4. 特征缩放
```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```
- 将不同量级的特征统一到相同尺度
- 对距离敏感的模型（如KNN、SVM）尤为重要

---

## 为什么重要？

**"垃圾进，垃圾出"原则**：
- 数据质量直接决定模型上限
- 再好的算法也无法从脏数据中学到有用的规律
- 实际项目中，80% 的时间花在数据预处理上

---

## 考试要点

- 根据题目要求识别需要删除的列
- 识别分类变量并正确使用 `pd.get_dummies()`
- 注意 `drop_first=True` 避免多重共线性
- 检查数据形状：`data.shape` / `data.info()`
