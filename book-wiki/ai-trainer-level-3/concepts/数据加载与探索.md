# 数据加载与探索

## 概念定义

数据加载与探索是机器学习项目的第一步，使用 pandas 读取数据集文件并进行初步观察，了解数据的结构、列名、数据类型和样本分布。

## 核心方法

### 1. `pd.read_csv()`
```python
import pandas as pd

df = pd.read_csv('fitness analysis.csv')
```

**参数说明**：
- 第一个参数：文件路径（相对路径或绝对路径）
- 默认第一行作为列名
- 返回 DataFrame 对象（表格数据结构）

### 2. `df.head()`
```python
print(df.head())    # 显示前 5 行（默认）
print(df.head(10))  # 显示前 10 行
```

**作用**：快速预览数据，了解：
- 列名（特征名称）
- 数据类型（数值 / 字符串 / 日期）
- 样本格式（数据结构）

### 3. 其他常用探索方法

```python
df.info()           # 列名、数据类型、非空值数量
df.describe()       # 数值列的统计摘要（均值、标准差等）
df.shape            # 数据维度（行数, 列数）
df.columns          # 所有列名列表
df.isnull().sum()   # 每列缺失值数量
```

## 实际应用场景

### 场景 1：健康数据预测（2.2.5 任务）
```python
df = pd.read_csv('fitness analysis.csv')
print(df.head())

# 输出示例：
#   Your gender   Your age  How important is exercise to you?  daily_steps
# 0     Female    19 to 25                                  2         8500
# 1     Female    19 to 25                                  4         9200
# 2     Female    15 to 18                                  3         7800
```

**探索目标**：
- 确认目标变量 `daily_steps` 存在
- 检查特征列名（注意空格）
- 观察分类变量的取值范围

### 场景 2：检查数据质量
```python
df = pd.read_csv('patient_data.csv')

# 检查缺失值
print(df.isnull().sum())
# PatientID         0
# Age               0
# BMI               5  ← 有 5 个缺失值
# DaysInHospital    0

# 检查数据类型
print(df.info())
# Age            int64   ← 数值型
# BMI            float64
# Gender         object  ← 字符串型（需编码）
```

## 最佳实践

### ✅ 正确做法
```python
# 1. 先加载
df = pd.read_csv('data.csv')

# 2. 立即查看
print(df.head())
print(df.info())

# 3. 确认关键列存在
assert 'daily_steps' in df.columns, "目标变量缺失"
```

### ❌ 常见错误
```python
# 错误 1：不检查就开始操作
df = pd.read_csv('data.csv')
y = df['daily_step']  # ❌ 列名拼写错误（少了 s）

# 错误 2：忘记打印前几行
df = pd.read_csv('data.csv')
X = df[['Your gender']]  # ❌ 列名末尾有空格，应为 'Your gender '
```

## 考试注意事项

1. **列名精确匹配**：原始 CSV 列名可能包含空格、特殊字符，用 `df.columns` 查看准确名称
2. **编码问题**：中文数据集注意 `encoding='utf-8'` 或 `encoding='gbk'`
3. **路径问题**：确保工作目录正确，或使用绝对路径
