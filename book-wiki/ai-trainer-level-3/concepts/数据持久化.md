# 数据持久化

- **来源章节**: 2.1.3
- **定义**: 将处理后的数据保存到文件，便于后续使用或提交
- **用法**:
  ```python
  # 保存为 CSV 文件
  df.to_csv('cleaned_data.csv', index=False)
  ```
- **参数说明**:
  - 第一个参数：文件路径（相对路径，保存在当前工作目录）
  - `index=False`：**不保存行号列**（考试必加，否则会多一列 0,1,2...）
  - `encoding='utf-8'`：指定编码（中文数据推荐，默认已是 utf-8）
- **其他常用保存格式**:
  ```python
  # Excel 格式（需要 openpyxl）
  df.to_excel('data.xlsx', index=False)
  
  # JSON 格式
  df.to_json('data.json', orient='records')
  
  # Pickle 格式（保留数据类型，仅 Python 使用）
  df.to_pickle('data.pkl')
  ```
- **读取对应格式**:
  ```python
  df = pd.read_csv('cleaned_data.csv')
  df = pd.read_excel('data.xlsx')
  df = pd.read_json('data.json')
  df = pd.read_pickle('data.pkl')
  ```
- **易错点**:
  - ❌ 忘记 `index=False`，导致 CSV 第一列是无意义的行号
  - ❌ 文件名写错（如 `2.1.3_cleaned_data.csv` 写成 `213_cleaned_data.csv`）
  - ❌ 保存前未检查数据形状（`df.shape`），可能保存了错误的中间结果
- **考试要求**:
  - 文件名按题目要求命名（如 `2.1.3_cleaned_data.csv`）
  - 保存到指定目录（考生文件夹：桌面「准考证号+身份证后6位」）
  - 保存前确认数据已完成所有清洗步骤
