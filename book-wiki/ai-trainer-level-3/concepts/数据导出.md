# 数据导出（to_csv）

- **来源章节**: 2.1.5
- **定义**: 将清洗、处理后的 DataFrame 保存为 CSV 文件
- **核心方法**:
  ```python
  # 1. 清理列名空格（避免后续使用出错）
  df.columns = df.columns.str.strip()
  
  # 2. 保存为 CSV
  df.to_csv('cleaned_data.csv', index=False)
  ```
- **参数详解**:
  - `index=False`：不保存行号列（默认会多一列 0, 1, 2...）
  - `encoding='utf-8-sig'`：保存中文内容（避免 Excel 打开乱码）
  - `sep=','`：分隔符（默认逗号，可改为 `\t` 制表符）
- **列名清理**:
  ```python
  df.columns = df.columns.str.strip()   # 去除首尾空格
  df.columns = df.columns.str.lower()   # 转小写
  df.columns = df.columns.str.replace(' ', '_')  # 空格改下划线
  ```
- **使用场景**: 
  - 数据预处理完成后保存中间结果
  - 导出清洗后的数据供其他工具使用
  - 提交作业时保存最终结果
- **⚠️ 易错点**: 
  - 不加 `index=False` 会多一列行号，下次读取时被当成数据列
  - Excel 导出的 CSV 列名可能有隐藏空格，必须 `str.strip()` 清理
  - 中文列名保存后 Excel 打开乱码 → 加 `encoding='utf-8-sig'`
- **完整示例**:
  ```python
  # 保存训练集和测试集
  train_df = pd.concat([X_train, y_train], axis=1)
  test_df = pd.concat([X_test, y_test], axis=1)
  
  train_df.to_csv('train_data.csv', index=False, encoding='utf-8-sig')
  test_df.to_csv('test_data.csv', index=False, encoding='utf-8-sig')
  ```
