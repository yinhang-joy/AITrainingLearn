# 数据可视化（分布统计与饼图）

- **来源章节**: 2.1.5
- **定义**: 使用统计和图表方法展示数据分布，帮助理解数据特征
- **核心方法**:
  ```python
  import matplotlib.pyplot as plt
  
  # 1. 统计分类变量分布
  counts = df['Workout_Frequency'].value_counts()
  # 输出: Daily 120, Weekly 85, Monthly 45
  
  # 2. 绘制饼图
  plt.figure(figsize=(6, 6))
  counts.plot.pie(autopct='%1.1f%%', startangle=90)
  plt.title('健身频率分布')
  plt.ylabel('')  # 移除默认 y 轴标签
  plt.show()
  ```
- **参数详解**:
  - `value_counts()`：统计每个类别的出现次数（降序排列）
  - `autopct='%1.1f%%'`：饼图显示百分比（保留 1 位小数）
  - `startangle=90`：从 12 点钟方向开始绘制
  - `figsize=(宽, 高)`：图表尺寸（单位：英寸）
- **使用场景**: 
  - 分类变量分布分析（如性别、职业、等级）
  - 数据探索阶段了解数据结构
  - 报告和展示中可视化结果
- **⚠️ 易错点**: 
  - 饼图只适合分类变量，不适合连续数值
  - 类别过多（>7）时饼图难以阅读，应改用柱状图
