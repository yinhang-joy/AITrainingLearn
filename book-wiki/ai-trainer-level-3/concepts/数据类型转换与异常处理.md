# 数据类型转换与异常处理

- **来源章节**: 2.1.5
- **定义**: 将字符串列强制转为数值类型，处理转换错误和异常值
- **核心方法**:
  ```python
  df['列名'] = pd.to_numeric(df['列名'], errors='coerce')  # 强制转数值
  df = df.dropna(subset=['列名'])                         # 删除转换失败的行
  df = df[(df['列名'] >= 下限) & (df['列名'] <= 上限)]     # 过滤异常值
  ```
- **参数详解**:
  - `pd.to_numeric(列, errors='coerce')`：无法转换的值 → `NaN`
  - `errors='ignore'`：转换失败保持原值（不推荐，后续计算会报错）
  - `errors='raise'`：转换失败直接报错（默认行为）
- **使用场景**: 
  - Excel 导出的数值列被当成字符串（如 '1200 kcal'）
  - 数据中混入非数值内容（如 '无效'、'--'）
- **⚠️ 易错点**: 转换后会产生新缺失值（`NaN`），必须用 `dropna()` 或 `fillna()` 处理
