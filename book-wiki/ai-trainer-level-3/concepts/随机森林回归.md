# 随机森林回归

- **来源章节**: 2.2.3
- **定义**: 构建多棵决策树并行训练，预测时取所有树的平均值（回归）或投票（分类）
- **用法**:
  ```python
  from sklearn.ensemble import RandomForestRegressor
  
  # 创建模型（100 棵决策树）
  rf_model = RandomForestRegressor(n_estimators=100, random_state=42)
  
  # 训练模型
  rf_model.fit(X_train, y_train)
  
  # 预测
  y_pred = rf_model.predict(X_test)
  
  # 评估
  train_score = rf_model.score(X_train, y_train)
  test_score = rf_model.score(X_test, y_test)
  ```
- **核心参数**:
  - `n_estimators=100`: 决策树数量，越多越准但越慢（通常 100～500）
  - `random_state=42`: 随机种子，保证结果可复现
- **工作原理**:
  1. 从训练数据中**随机抽样**（有放回抽样）
  2. 对每个抽样数据集构建一棵决策树
  3. 预测时，所有树的预测值取**平均**（回归）或**投票**（分类）
- **优点**:
  - 准确性高，性能稳定
  - 抗过拟合能力强
  - 不易受异常值影响
  - 可以处理高维数据
- **核心方法**:
  - `fit(X_train, y_train)`: 训练模型
  - `predict(X_test)`: 预测
  - `score(X, y)`: 计算 R²（决定系数）
- **与 XGBoost 对比**:
  - **随机森林**: 并行构建独立树，速度快
  - **XGBoost**: 串行构建树（后树修正前树错误），更准但更慢
