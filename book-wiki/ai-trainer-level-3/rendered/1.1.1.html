一、任务解读与填空对应

本题要在 1.1.1.ipynb 的既有代码中填空。以下讲解统一使用模板中的变量 data，以及新列 RiskLevel、BMIRange、AgeRange，可直接对应每处填空。

三个子任务：

1. 根据住院天数生成风险标签，统计高、低风险患者数量和各自占比。DaysInHospital > 7 为 高风险患者，其余为 低风险患者；住院正好 7 天属于低风险。

2. 将 BMI 分为偏瘦、正常、超重、肥胖，分别计算各区间内高风险患者占比及该区间患者总数。

3. 将年龄分为 ≤25 岁、26–35 岁、36–45 岁、46–55 岁、56–65 岁、＞65 岁，分别计算各区间内高风险患者占比及该区间患者总数。

二、知识点讲解

① 读取数据与变量名
import pandas as pd
import numpy as np

data = pd.read_csv('patient_data.csv')

pd 是 pandas 的简称，np 是 NumPy 的简称，data 是读入的 DataFrame。本单元后续代码都使用 data，填写时应保持一致。

学习时可用 data.head()、data.info() 检查数据。正式填写保留原框架，只替换下划线。

② 创建风险标签：np.where

模板中这一行的作用是为每一位患者写入风险标签：

data['RiskLevel'] = np.where(data['DaysInHospital'] > 7, '高风险患者', '低风险患者')

np.where(条件, 条件成立时的值, 条件不成立时的值) 会逐行判断。住院 8 天得到 高风险患者，住院 7 天得到 低风险患者；左侧把这些标签保存到新列 RiskLevel。

RiskLevel 是列名，高风险患者、低风险患者 是这一列里的字符串取值。后面代码按这些原样取值统计，因此不能自行缩写为“高风险”“低风险”。

条件筛选 data[data['DaysInHospital'] > 7] 可以取出高风险患者的行，但这处填空需要生成风险标签列，应使用 np.where。

③ 统计不同风险等级的患者数量：value_counts()
risk_counts = data['RiskLevel'].value_counts()

拆成三步：data['RiskLevel'] 取风险列，.value_counts() 统计每种标签出现的次数，risk_counts 保存统计结果。它是以标签为索引、以人数为值的 Series。

risk_counts['高风险患者']  # 413
risk_counts['低风险患者']  # 587

value_counts() 默认按数量从多到少显示，本数据会先显示低风险。读取人数时按标签取值，不要假定第一项就是高风险。

④ 计算高、低风险患者各自占比
high_risk_ratio = risk_counts['高风险患者'] / len(data)
low_risk_ratio = risk_counts['低风险患者'] / len(data)

len(data) 是全部患者人数，即 1000。两项分母相同：高风险为 413 / 1000 = 0.413（41.3%），低风险为 587 / 1000 = 0.587（58.7%）。

不要把分母写成整个 risk_counts：它是一组分类计数，会产生多个除法结果。此处要得到单个比例。risk_counts.sum() 在本题也等于总人数，但用 len(data) 更直接对应“全部患者”。

⑤ 按 BMI 划分区间：pd.cut
bmi_bins = [0, 18.5, 24, 28, np.inf]
bmi_labels = ['偏瘦', '正常', '超重', '肥胖']
data['BMIRange'] = pd.cut(data['BMI'], bins=bmi_bins, labels=bmi_labels, right=False)
  • bins 是区间边界，5 个边界划出 4 个区间。
  • labels 是对应的 4 个类别名。
  • right=False 表示左闭右开；np.inf 是正无穷，使最后一组覆盖 28 及以上的有限 BMI 值。
BMI 区间类别边界举例
[0, 18.5)偏瘦18.4 属于偏瘦
[18.5, 24)正常18.5、23.9 属于正常
[24, 28)超重24.0、27.9 属于超重
[28, +∞)肥胖28.0 属于肥胖

这些边界与模板一致，也对应题目对本 CSV 中一位小数 BMI 的分类要求。若改用默认的 right=True，BMI=18.5 会落入偏瘦，24 会落入正常，28 会落入超重，均不符合本题要求。

⑥ 各区间内高风险比例：groupby + apply + 布尔均值
bmi_risk_rate = data.groupby('BMIRange')['RiskLevel'].apply(lambda x: (x == '高风险患者').mean())

从左到右理解：

1. data.groupby('BMIRange') 按 BMI 类别分组。

2. ['RiskLevel'] 选取每组中的风险标签。

3. apply(...) 对每组执行同一个计算；x 是这一组患者的风险标签 Series。

4. x == '高风险患者' 把字符串标签转换为 True/False。.mean() 把 True 当作 1、False 当作 0，得到该组内高风险患者占比。

例如偏瘦组有 144 人，其中 64 人为高风险，布尔均值就是 64 / 144 ≈ 0.444444。这里的分母是偏瘦组人数 144，不是全部患者人数 1000。

不能直接对字符串列 RiskLevel 求 .mean()。模板已经提供字符串比较和 apply，只需填写前面的分组操作和分组列。

⑦ 各区间患者总数：groupby(...).size()
bmi_patient_count = data.groupby('BMIRange').size()

.size() 统计每组的行数，即该组所有患者人数，包含高风险和低风险。它不需要先筛选高风险患者，也不需要选择某个统计列。

注意区别：value_counts() 用于本题的风险标签计数，groupby(...).size() 用于 BMI、年龄分组人数；布尔均值用于各组内的高风险比例。

⑧ 年龄区间与边界
age_bins = [0, 26, 36, 46, 56, 66, np.inf]
age_labels = ['≤25岁', '26-35岁', '36-45岁', '46-55岁', '56-65岁', '＞65岁']
data['AgeRange'] = pd.cut(data['Age'], bins=age_bins, labels=age_labels, right=False)
age_risk_rate = data.groupby('AgeRange')['RiskLevel'].apply(lambda x: (x == '高风险患者').mean())
age_patient_count = data.groupby('AgeRange').size()

本 CSV 的年龄是整数，right=False 时区间应为 [0, 26)、[26, 36)、[36, 46)、[46, 56)、[56, 66)、[66, +∞)。因此 25 岁属于第一组，26 岁属于第二组，65 岁属于第五组，66 岁属于第六组。

不能把模板边界改为 [0, 25, 35, 45, 55, 65, ...] 并仍用 right=False，否则 25、35、45、55、65 岁都会被提前分到下一组。

参考填写后的完整流程（按原模板顺序） 
import pandas as pd
import numpy as np

# 读取数据集
data = pd.read_csv('patient_data.csv')

# 1. 统计不同风险等级的患者数量及其占比
data['RiskLevel'] = np.where(data['DaysInHospital'] > 7, '高风险患者', '低风险患者')
risk_counts = data['RiskLevel'].value_counts()
high_risk_ratio = risk_counts['高风险患者'] / len(data)
low_risk_ratio = risk_counts['低风险患者'] / len(data)

print("高风险患者数量:", risk_counts['高风险患者'])
print("低风险患者数量:", risk_counts['低风险患者'])
print("高风险患者占比:", high_risk_ratio)
print("低风险患者占比:", low_risk_ratio)

# 2. 统计各 BMI 区间内高风险比例和患者总数
bmi_bins = [0, 18.5, 24, 28, np.inf]
bmi_labels = ['偏瘦', '正常', '超重', '肥胖']
data['BMIRange'] = pd.cut(data['BMI'], bins=bmi_bins, labels=bmi_labels, right=False)
bmi_risk_rate = data.groupby('BMIRange')['RiskLevel'].apply(lambda x: (x == '高风险患者').mean())
bmi_patient_count = data.groupby('BMIRange').size()

print("BMI区间中高风险患者的比例和患者数:")
print(bmi_risk_rate)
print(bmi_patient_count)

# 3. 统计各年龄区间内高风险比例和患者总数
age_bins = [0, 26, 36, 46, 56, 66, np.inf]
age_labels = ['≤25岁', '26-35岁', '36-45岁', '46-55岁', '56-65岁', '＞65岁']
data['AgeRange'] = pd.cut(data['Age'], bins=age_bins, labels=age_labels, right=False)
age_risk_rate = data.groupby('AgeRange')['RiskLevel'].apply(lambda x: (x == '高风险患者').mean())
age_patient_count = data.groupby('AgeRange').size()

print("年龄区间中高风险患者的比例和患者数:")
print(age_risk_rate)
print(age_patient_count)

五、自测题

1. np.where(条件, '高风险患者', '低风险患者') 的第二、第三个参数分别在什么情况下生效？住院正好 7 天属于哪类？

2. RiskLevel 与 高风险患者 分别是列名还是列中的值？如何统计每类患者人数？

3. risk_counts['高风险患者'] / len(data) 的分母是什么？为什么不能直接除以整个 risk_counts？

4. lambda x: (x == '高风险患者').mean() 中的 x 是什么？偏瘦组有 144 人、其中 64 人高风险，分母应为 144 还是 1000？

5. data.groupby('BMIRange').size() 得到的是所有患者数还是高风险患者数？

6. BMI=18.5、24、28 分别属于哪类？年龄=25、26、65、66 分别属于哪组？

参考答案（先自测再看）

1. 条件成立使用第二个参数，否则使用第三个参数。判断条件为 > 7，正好 7 天属于低风险。

2. RiskLevel 是列名，高风险患者 是该列中的字符串值；用 data['RiskLevel'].value_counts() 统计各标签人数。

3. 分母是全部患者人数 1000；risk_counts 是包含多个计数的 Series，直接相除会得到多个结果，而非一个总体占比。

4. x 是当前分组的风险标签 Series；比较产生布尔值，均值得到该组内高风险占比。偏瘦组应为 64 / 144。

5. 得到每个 BMI 区间的所有患者数，包括高、低风险患者。

6. BMI 分别为正常、超重、肥胖；年龄分别为 ≤25 岁、26–35 岁、56–65 岁、＞65 岁。
