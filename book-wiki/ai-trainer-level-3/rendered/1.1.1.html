1.1.1 讲义：智能医疗系统中的业务数据处理流程设计

  • 日期: 2026-08-19
  • 状态: 已讲解，待自测 → 待做题（ipynb）
  • 数据: patient_data.csv（1000 行 × 6 列：PatientID / Age / BMI / BloodPressure / Cholesterol / DaysInHospital，无缺失值）

一、任务解读（拆题：中文 → pandas 翻译表）

核心思维：考试不是编程题，是翻译题。 每句中文对应一个 pandas 操作，ipynb 填空考的就是函数名、列名、参数。

题目里的中文翻译成 pandas
读取患者数据集pd.read_csv(...)
统计住院超过 7 天的患者条件筛选 df[df['DaysInHospital'] > 7]
数量 / 占比len(...) / 布尔列 .mean()
按 BMI 区间分类pd.cut(...)（区间切分）
不同区间中的高风险比例groupby(...)['高风险'].mean()
不同区间中的患者数groupby(...)['高风险'].count()

三个子任务：

1. 住院 >7 天（高风险）患者数量 + 占比

2. 各 BMI 区间（偏瘦 <18.5 / 正常 18.5~23.9 / 超重 24.0~27.9 / 肥胖 ≥28）的高风险比例 + 人数

3. 各年龄区间（≤25 / 26-35 / 36-45 / 46-55 / 56-65 / >65）的高风险比例 + 人数

二、知识点讲解

① 读取数据 pd.read_csv
df = pd.read_csv('patient_data.csv')
  • 参数 1：文件路径（考试通常已给相对路径）
  • 默认第一行作为列名
  • 读入类型：DataFrame（表格对象），后续操作都挂在它后面

验证读取（新手必做）：

df.head()     # 前 5 行
df.info()     # 列名 / 类型 / 缺失值
这就是「业务数据处理流程」第一环：先看数据，再动手。
② 条件筛选：df[布尔序列]（核心机制）
df['DaysInHospital'] > 7    # ① 逐行比较 → 一列 True/False
df[布尔序列]                 # ② 只留下 True 的行
# 一行写法：
high_risk = df[df['DaysInHospital'] > 7]

机制要点：df[ ] 放字符串 = 取列；放布尔序列 = 筛行。所有筛选都是这个套路。

③ 数量与占比
len(high_risk)               # 高风险患者数量
len(high_risk) / len(df)     # 占比
# 一行写法（布尔列求平均 = 占比）：
(df['DaysInHospital'] > 7).mean()

原理：True=1、False=0，布尔列的平均值 = True 的比例。

④ 区间切分 pd.cut（任务②关键）
df['BMI_类别'] = pd.cut(df['BMI'],
                        bins=[0, 18.5, 24.0, 28.0, 100],   # 5 个边界 → 4 个区间
                        labels=['偏瘦', '正常', '超重', '肥胖'],
                        right=False)

三个参数：

  • bins：区间边界列表，n 个边界 → n-1 个区间（考点）
  • labels：区间名字，与 bins 一一对应
  • right=False：左闭右开 [18.5, 24)；默认是左开右闭 (18.5, 24]

⚠️ 最容易丢分的坑：题目「正常 18.5～23.9」要求 BMI=18.5 归「正常」，必须 right=False。不加则 18.5 被算进「偏瘦」。

⑤ 分组统计 groupby（任务②③核心）
df['高风险'] = df['DaysInHospital'] > 7        # 先造布尔列
df.groupby('BMI_类别')['高风险'].agg(['count', 'sum'])
# count = 该区间患者总数，sum = 高风险人数，比例 = sum/count
# 直接得比例：
df.groupby('BMI_类别')['高风险'].mean()

三步走：groupby('分组列') → ['统计列'] → .agg([...]) / .mean()。

三、完整解题流程演示（真实运行结果）

df = pd.read_csv('patient_data.csv')
high_risk = df[df['DaysInHospital'] > 7]
print(len(high_risk))          # → 426
print((df['DaysInHospital'] > 7).mean())   # → 0.426

df['高风险'] = df['DaysInHospital'] > 7
df['BMI_类别'] = pd.cut(df['BMI'], bins=[0, 18.5, 24.0, 28.0, 100],
                        labels=['偏瘦', '正常', '超重', '肥胖'], right=False)
df.groupby('BMI_类别')['高风险'].agg(['count', 'sum'])
#           count  sum
# 偏瘦         15    5
# 正常        247   98
# 超重        376  173
# 肥胖        362  178

任务③同理：pd.cut(df['Age'], bins=[0, 25, 35, 45, 55, 65, 200], right=False) + groupby。

五、自测题（先自测，再对答案）

1. df[df['Age'] > 30] 里 df['Age'] > 30 是什么类型的数据？df[...] 收到它后做了什么？

2. (df['DaysInHospital'] > 7).mean() 为什么一行就得到占比？

3. pd.cut 的 right=False 改没改，BMI=18.5 分别落在哪？为什么必须 right=False？

参考答案（先自测再看）

1. 布尔 Series（一列 True/False，每行一个）；df[...] 收到布尔序列后筛行——留下 True 对应的行。

2. True=1、False=0，布尔列求平均值 = 1 的比例 = 条件成立占比。

3. 默认左开右闭 (18.5, 24]：18.5 落「偏瘦」；right=False 左闭右开 [18.5, 24)：18.5 落「正常」。题目定义「正常 18.5～23.9」，所以必须 right=False 让 18.5 归正常。

知识点卡片

boolean-indexing

boolean-indexing（布尔索引筛选）

  • 来源章节: 1.1.1
  • 定义: 用布尔序列（True/False）筛选 DataFrame 的行 —— df[布尔序列] 只留下 True 的行
  • 用法:
    •   df[df['DaysInHospital'] > 7]   # 留住院>7天的行
  • 机制: df['列'] > 7 先逐行比较生成布尔列；df[...] 里放字符串=取列，放布尔序列=筛行
  • 易错点: 比较运算的括号；筛选变量可复用（如 high_risk）
  • 关联: boolean-mean-ratio · pandas-read-csv

boolean-mean-ratio

boolean-mean-ratio（布尔列求平均 = 占比）

  • 来源章节: 1.1.1
  • 定义: 对布尔列取 .mean()，因 True=1 / False=0，平均值即条件成立的比例
  • 用法:
    •   (df['DaysInHospital'] > 7).mean()   # → 0.426，即 42.6%
  • 易错点: 比较表达式外面要加括号再 .mean()；与 len(筛选)/len(df) 等价
  • 关联: boolean-indexing · groupby-aggregation

groupby-aggregation

groupby-aggregation（分组统计）

  • 来源章节: 1.1.1
  • 定义: 按某列分组后，对其他列做汇总统计（数量/求和/平均）
  • 用法:
    •   df.groupby('BMI_类别')['高风险'].agg(['count', 'sum'])   # 每组人数 + 高风险人数
  df.groupby('BMI_类别')['高风险'].mean()                  # 每组高风险比例
  • 三步: groupby('分组列') → ['统计列'] → .agg([...]) 或 .mean()
  • 易错点: 统计布尔列时 sum=True 的个数（高风险人数），mean=比例；count=行数（患者数）
  • 关联: pd-cut-binning · boolean-mean-ratio

np-where

np-where（条件赋值）

  • 来源章节: 1.1.1, 1.1.2
  • 定义: 根据条件返回不同的值（类似三元运算符 条件 ? 值1 : 值2）
  • 用法:
    •   np.where(条件, 条件为True时的值, 条件为False时的值)
  
  # 1.1.1 示例：字符串分类
  df['RiskLevel'] = np.where(df['DaysInHospital'] > 7, '高风险患者', '低风险患者')
  
  # 1.1.2 示例：布尔标记
  df['is_abnormal'] = np.where(
      (df['SensorType'] == 'Temperature') & (df['Value'] > 50),
      True, False
  )
  • 与直接布尔赋值的区别:
    •   # 方式1：np.where（更明确）
  df['Anomaly'] = np.where(df['Value'] > 50, True, False)
  
  # 方式2：直接布尔表达式（结果相同，更简洁）
  df['Anomaly'] = df['Value'] > 50
  • 当结果是 字符串/数字 时，必须用 np.where
  • 当结果是 True/False 时，两种都可以，布尔表达式更简洁
  • 多条件嵌套:
    •   # 三种情况：高/中/低
  df['Level'] = np.where(df['Value'] > 80, '高',
                np.where(df['Value'] > 50, '中', '低'))
  • ⚠️ 易错点: 复杂条件必须加括号（和布尔索引一样）
  • 关联: boolean-column-assignment · boolean-indexing

pandas-read-csv

pandas-read-csv

  • 来源章节: 1.1.1
  • 定义: 用 pandas 把 CSV 文件读成 DataFrame（表格对象），所有分析的第一步
  • 用法:
    •   df = pd.read_csv('patient_data.csv')
  df.head()   # 前 5 行
  df.info()   # 列名/类型/缺失值
  • 易错点: 读入后先看数据再动手；文件路径考试已给
  • 关联: boolean-indexing · groupby-aggregation

pd-cut-binning

pd-cut-binning（区间切分）

  • 来源章节: 1.1.1
  • 定义: 把连续数值（如 BMI）按边界切成多个区间类别
  • 用法:
    •   df['BMI_类别'] = pd.cut(df['BMI'], bins=[0, 18.5, 24.0, 28.0, 100],
                          labels=['偏瘦', '正常', '超重', '肥胖'], right=False)
  • 参数: bins 边界列表（n 个边界 → n-1 个区间）；labels 区间名；right=False 左闭右开 [a, b)
  • ⚠️ 易错点（考点）: 默认是左开右闭 (a, b]，边界值 18.5 会被算进前一个区间「偏瘦」；题目定义「正常 18.5～23.9」必须 right=False 才让 18.5 归「正常」
  • 关联: groupby-aggregation · boolean-mean-ratio
