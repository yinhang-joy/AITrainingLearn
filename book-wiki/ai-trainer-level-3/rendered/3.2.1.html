一、先分清本章在做什么

第二章主要使用 model.fit(X_train, y_train) 训练模型。本题的 resnet.onnx 已经训练完成，不需要再次训练，也不需要划分训练集、计算 MSE 或保存新的 pkl。

本题流程是：加载模型和标签 → 读取图片 → 按模型要求整理图片 → 推理 → 将输出转为概率 → 输出 Top 5。

题干介绍了模型训练所用框架，但实际填空使用的是 ONNX Runtime；不必为了这段代码另外导入 PyTorch。

labels.txt类别索引对应的名称1000 行，顺序必须保持不变

模型输入是 float32、(N, 3, 224, 224)；本题只处理一张图片，因此实际输入形状为 (1, 3, 224, 224)。输出形状为 (1, 1000)。

二、加载模型和图像

session = ort.InferenceSession('resnet.onnx')
image = Image.open('img_test.jpg').convert('RGB')
processed_image = preprocess_image(image)
  • ort 是 onnxruntime 的导入别名，InferenceSession 创建加载模型的推理会话。
  • Image.open(...) 打开文件；convert('RGB') 保证三个颜色通道。
  • preprocess_image(image) 调用原题已经给出的预处理函数，不是重新定义函数。

预处理中的形状变化要会看：

步骤数据形状或含义
缩放、中心裁剪先变为 256×256，再裁剪为 224×224
np.array(224, 224, 3)，顺序是高度、宽度、通道
除以 255，减均值、除标准差按原题的 RGB 参数进行数值归一化
np.transpose(image, (2, 0, 1))(3, 224, 224)，把通道移到最前面
reshape((1,) + image.shape)(1, 3, 224, 224)，增加一张图片的批次维度

原题在预处理之后还执行了 processed_image.astype(np.float32)。不能因为函数内曾转过 float32 就忽略这一行：后续与均值、标准差运算时，数组可能发生类型提升。

三、session.run 的两个参数怎么记

input_name = session.get_inputs()[0].name
output_name = session.get_outputs()[0].name
output = session.run([output_name], {input_name: processed_image})[0]
  • 第一个参数 [output_name]：要求返回哪些模型输出，是一个名称列表。
  • 第二个参数 {input_name: processed_image}：字典的键是模型输入名，值是准备好的图片数组。
  • run(...) 返回输出列表；最后的 [0] 是取第一个输出张量，不是取第一个预测类别。
  • get_inputs() 和 get_outputs() 返回输入、输出信息列表。名称不要凭经验硬猜。

可以记为：run(要取的输出, 按名字提供的输入)。这里没有 y_test；图片识别时只把待识别图片交给模型。

四、softmax、argsort 与 Top 5

probabilities = scipy.special.softmax(output, axis=-1)
top5_idx = np.argsort(probabilities[0])[-5:][::-1]
top5_prob = probabilities[0][top5_idx]

softmax 将本题的类别分数转为概率；axis=-1 表示沿最后一个维度，也就是 1000 个类别的方向计算。probabilities[0] 才是第一张图片对应的一维概率数组。

  • np.argmax(...)：只取最大值所在位置，适合找 Top 1。
  • np.argsort(...)：返回从小到大排列的索引，不是排序后的概率值。
  • [-5:]：取最大的 5 个索引。
  • [::-1]：反转顺序，变成概率从高到低。
  • labels[top5_idx[i]]：用类别索引查名称。

注意两次 [0] 的区别：run(...)[0] 选第一个输出，probabilities[0] 选第一张图片。

import onnxruntime as ort
import numpy as np
import scipy.special
from PIL import Image


# 预处理图像
def preprocess_image(image, resize_size=256, crop_size=224, mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]):
  image = image.resize((resize_size, resize_size), Image.BILINEAR)
  w, h = image.size
  left = (w - crop_size) / 2
  top = (h - crop_size) / 2
  image = image.crop((left, top, left + crop_size, top + crop_size))
  image = np.array(image).astype(np.float32)
  image = image / 255.0
  image = (image - mean) / std
  image = np.transpose(image, (2, 0, 1))
  image = image.reshape((1,) + image.shape)
  return image


# 模型加载 2分
session = ort.InferenceSession('resnet.onnx')


# 加载类别标签
labels_path = 'labels.txt'
with open(labels_path) as f:
  labels = [line.strip() for line in f.readlines()]


# 获取模型输入和输出的名称
input_name = session.get_inputs()[0].name
output_name = session.get_outputs()[0].name


# 加载图片 2分
image = Image.open('img_test.jpg').convert('RGB')


# 预处理图片 2分
processed_image = preprocess_image(image)


# 确保输入数据是 float32 类型
processed_image = processed_image.astype(np.float32)


# 进行图片识别 2分
output = session.run([output_name], {input_name: processed_image})[0]


# 应用 softmax 函数获取概率 2分
probabilities = scipy.special.softmax(output, axis=-1)


# 获取最高的5个概率和对应的类别索引 3分
top5_idx = np.argsort(probabilities[0])[-5:][::-1]
top5_prob = probabilities[0][top5_idx]


# 打印结果
print("Top 5 predicted classes:")
for i in range(5):
  print(f"{i+1}: {labels[top5_idx[i]]} - Probability: {top5_prob[i]}")

六、如何检查结果和完成答题卷

当前图片实测 Top 1 为 tusker，概率约 93.12%；之后依次为 Indian elephant、African elephant、gorilla、water buffalo。不同运行环境可能有很小的浮点差异，不要把这些结果硬编码进答案。

概率表示模型对当前图片某类别的置信程度，不代表在整套数据上测得的准确率。

答题卷要求可行的人机交互方式，可结合本题写出至少三项具体措施：

  • 提供图片上传、缩略图预览和重新选择，避免识别错文件。
  • 同时展示 Top 5 名称和概率，由用户确认或纠正，而不只显示单一结论。
  • 对模糊图片、低置信度结果提示重新拍摄或转人工判断。
  • 识别过程中显示状态；文件格式或模型加载失败时给出明确原因和重试入口。
  • 允许用户查看原图并修改结果，确认后再提交。

提交时核对：附带运行结果的 3.2.1.html、填写后的 3.2.1.docx、仅截取识别输出区域的 3.2.1-1.jpg。截图不是把原始测试图片另存一次。

常见问题：FileNotFoundError 先查工作目录；类型报错查 float32；维度报错查 NCHW；Top 5 顺序反了查 [::-1]；标签对不上查是否误排了 labels.txt。
