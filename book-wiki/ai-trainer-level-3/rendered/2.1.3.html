二、核心知识点详解

① 异常值检测：箱线图可视化
import matplotlib.pyplot as plt
import seaborn as sns

# 设置画布尺寸：12×8 英寸
plt.figure(figsize=(12, 8))

# 只对数值列绘制箱线图
numeric_cols = data.select_dtypes(include=['float64', 'int64']).columns

# 创建 3 行 4 列的子图网格
for i, col in enumerate(numeric_cols, 1):
    plt.subplot(3, 4, i)        # 第 i 个子图
    sns.boxplot(x=data[col])    # 横向箱线图
    plt.title(col)

plt.tight_layout()              # 自动调整子图间距
plt.show()

知识点：

  • .select_dtypes(include=['float64', 'int64'])：只选数值列（字符串列不画箱线图）
  • enumerate(列表, 1)：从 1 开始编号（subplot 索引从 1 开始）
  • plt.subplot(行, 列, 索引)：在 3×4 网格的第 i 个位置画图
② 异常值处理：IQR 方法（考点）

IQR 方法原理：

  • IQR（Interquartile Range，四分位距）= Q3 - Q1
  • 下界 = Q1 - 1.5 × IQR
  • 上界 = Q3 + 1.5 × IQR
  • 超出上下界的值视为异常值
# 计算四分位数
Q1 = data[numeric_cols].quantile(0.25)   # 每列的 25% 分位数
Q3 = data[numeric_cols].quantile(0.75)   # 每列的 75% 分位数
IQR = Q3 - Q1

# 定义异常值条件（任意列超出边界）
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# 过滤异常值：保留所有列都在边界内的行
data_cleaned = data[~((data[numeric_cols] < lower_bound) | 
                       (data[numeric_cols] > upper_bound)).any(axis=1)]

易错点：

  • ~ 表示取反（保留非异常值的行）
  • .any(axis=1)：每行只要有一列异常就标记为 True
  • [~(...)]：最终保留所有列都正常的行
③ 重复值检测与删除
# 检测重复行（返回布尔列，True=重复）
duplicates = data_cleaned.duplicated()
num_duplicates = duplicates.sum()

# 删除重复行（默认保留第一次出现的行）
data_cleaned = data_cleaned[~duplicates]
# 或者一行写法：
# data_cleaned = data_cleaned.drop_duplicates()

print(f'删除的重复行数: {num_duplicates}')

注意：.duplicated() 默认判断所有列完全相同才算重复。

④ 数据归一化：MinMaxScaler

目的：将不同量纲的特征缩放到 [0, 1] 区间，避免大数值特征主导模型。

from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()
data_cleaned[numeric_cols] = scaler.fit_transform(data_cleaned[numeric_cols])

原理：$x' = \frac{x - min}{max - min}$

易错点：只对数值列归一化，字符串列（如 ID）跳过。

⑤ 特征工程：创建新特征
# 示例：创建收入负债比特征
data_cleaned['IncomeToDebtRatio'] = (

四、易错点（考试陷阱）

⚠️ 陷阱 1：IQR 过滤条件写反
# ❌ 错误（保留了异常值）
data_cleaned = data[(data[numeric_cols] < lower) | (data[numeric_cols] > upper)]

# ✅ 正确（过滤掉异常值，保留正常值）
data_cleaned = data[~((data[numeric_cols] < lower) | (data[numeric_cols] > upper)).any(axis=1)]

记忆口诀：~ 取反 + any(axis=1) 任意列异常就删。

⚠️ 陷阱 2：.quantile() 只对数值列有效
# ❌ 错误（全部列包括字符串列）
Q1 = data.quantile(0.25)   # 字符串列会报错

# ✅ 正确（只选数值列）
numeric_cols = data.select_dtypes(include=['float64', 'int64']).columns
Q1 = data[numeric_cols].quantile(0.25)
⚠️ 陷阱 3：归一化后覆盖原列
# ❌ 错误（创建新 DataFrame，原列未更新）
scaler.fit_transform(data_cleaned[numeric_cols])

# ✅ 正确（结果赋值回原列）
data_cleaned[numeric_cols] = scaler.fit_transform(data_cleaned[numeric_cols])
⚠️ 陷阱 4：train_test_split 参数顺序
# ❌ 错误（X 和 y 顺序颠倒）
X_train, X_test, y_train, y_test = train_test_split(y, X, test_size=0.2)

# ✅ 正确（先 X 后 y）
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

五、答题卷参考答案

数据清洗规范（3 分，每点 1 分）

1. 异常值处理：使用 IQR 方法检测并删除超出 Q1-1.5×IQR 和 Q3+1.5×IQR 边界的数据

2. 重复值处理：使用 .duplicated() 检测重复行，使用 .drop_duplicates() 删除（保留首次出现）

3. 数据标准化：使用 MinMaxScaler 对数值型特征进行归一化，缩放到 [0,1] 区间

特征工程规范（2 分，每点 1 分）

1. 特征创建：根据业务逻辑创建衍生特征（如收入负债比 IncomeToDebtRatio），提升模型表达能力

2. 特征选择：分离特征变量 X（去除目标变量）和目标变量 y，为模型训练做准备

六、自测题

1. IQR 方法中，为什么要用 1.5 × IQR 而不是 2 × IQR？

2. .any(axis=1) 和 .any(axis=0) 的区别是什么？

3. MinMaxScaler 和标准化（Z-score）的区别是什么？各适用什么场景？

参考答案（先自测再看）

1. 1.5 × IQR 是统计学约定：

  • 1.5 倍是经典的离群点判定标准（Tukey 箱线图规则）
  • 在正态分布下，约 99.3% 的数据在此范围内
  • 2 倍太宽松，会漏掉部分异常值；1 倍太严格，会误删正常值

2. axis 参数方向：

  • axis=1：横向（每行）操作，检查每行是否有任意列满足条件
  • axis=0：纵向（每列）操作，检查每列是否有任意行满足条件
  • IQR 异常值过滤用 axis=1，因为要删除「任意列异常」的行

3. 归一化 vs 标准化：

  • MinMaxScaler（归一化）：缩放到 [0,1]，保留原始分布形状，适合神经网络（需要固定范围）
  • StandardScaler（标准化）：转为均值 0、标准差 1，适合线性回归（需要可比较的量纲）
  • 本题用 MinMaxScaler，因为是为机器学习模型准备数据

异常值检测与处理

异常值检测与处理

  • 来源章节: 2.1.3
  • 定义: 使用统计方法识别并过滤数据中偏离正常范围的极端值
  • 检测方法:
  • 箱线图可视化: plt.boxplot() 或 sns.boxplot() 直观展示异常值分布
  • IQR 方法: 四分位距（IQR = Q3 - Q1）判定边界
  • 下界 = Q1 - 1.5 × IQR
  • 上界 = Q3 + 1.5 × IQR
  • 超出边界视为异常值
  • 处理步骤:
    •   # 1. 计算分位数
  Q1 = data[numeric_cols].quantile(0.25)
  Q3 = data[numeric_cols].quantile(0.75)
  IQR = Q3 - Q1
  
  # 2. 定义边界
  lower = Q1 - 1.5 * IQR
  upper = Q3 + 1.5 * IQR
  
  # 3. 过滤异常值（保留正常值）
  data_cleaned = data[~((data[numeric_cols] < lower) | 
                         (data[numeric_cols] > upper)).any(axis=1)]
  • 易错点:
  • ~ 表示取反，保留非异常值
  • .any(axis=1) 表示每行只要有一列异常就标记为 True
  • quantile() 只对数值列有效，需要先用 .select_dtypes() 筛选
  • 关联: 数据清洗 · 数据标准化

数据标准化

数据标准化

  • 来源章节: 2.1.3
  • 定义: 将不同量纲的数值特征缩放到统一范围，消除量纲影响，提升模型训练效果
  • MinMaxScaler（归一化）:
  • 公式: $x' = \frac{x - min}{max - min}$
  • 范围: [0, 1]
  • 用法:
    •     from sklearn.preprocessing import MinMaxScaler
    
    scaler = MinMaxScaler()
    # 只对数值列归一化
    numeric_cols = df.select_dtypes(include=['float64', 'int64']).columns
    df[numeric_cols] = scaler.fit_transform(df[numeric_cols])
  • 适用场景: 神经网络、图像处理（需要固定 [0,1] 范围）
  • StandardScaler（标准化）:
  • 公式: $z = \frac{x - \mu}{\sigma}$（转为均值 0、标准差 1）
  • 适用场景: 线性回归、逻辑回归（需要可比较的量纲）
  • 选择原则:
  • 数据分布接近正态 → StandardScaler
  • 数据有明确边界（如年龄、评分）→ MinMaxScaler
  • 神经网络通常用 MinMaxScaler
  • 易错点:
  • 归一化后必须赋值回原列：df[cols] = scaler.fit_transform(df[cols])
  • 只对数值列操作，字符串列（如 ID）跳过
  • fit_transform() 用于训练集，测试集只用 transform()（避免数据泄漏）
  • 关联: 数据清洗 · 特征工程 · select-dtypes

数据集划分

数据集划分

  • 来源章节: 2.1.3
  • 定义: 将数据按比例分为训练集和测试集，用于模型训练和评估
  • 用法:
    •   from sklearn.model_selection import train_test_split
  
  # 划分数据（训练集 80%，测试集 20%）
  X_train, X_test, y_train, y_test = train_test_split(
      X, y, 
      test_size=0.2,      # 测试集占比
      random_state=42     # 随机种子（保证可复现）
  )
  
  print(f'训练数据形状: {X_train.shape}')
  print(f'测试数据形状: {X_test.shape}')
  • 参数说明:
  • test_size：测试集比例（0.2 表示 20%，训练集自动为 80%）
  • random_state：随机种子，固定后每次划分结果相同（可复现实验）
  • stratify：分层采样参数（分类任务中保证各类别比例，本题未用）
  • 返回值顺序（易错点）:
    •   # ✅ 正确顺序：X_train, X_test, y_train, y_test
  X_train, X_test, y_train, y_test = train_test_split(X, y, ...)
  
  # ❌ 错误（X 和 y 顺序颠倒）
  X_train, X_test, y_train, y_test = train_test_split(y, X, ...)
  • 训练集 vs 测试集:
  • 训练集：用于训练模型参数
  • 测试集：用于评估模型泛化能力（模型从未见过的数据）
  • 验证集（本题未用）：用于调参（从训练集再划分或交叉验证）
  • 易错点:
  • 先做特征工程（创建特征、分离 X/y），再划分数据集
  • test_size=0.2 不是 test_size=20（是比例不是百分比）
  • 归一化在划分后分别对训练集和测试集操作（避免数据泄漏）
  • 关联: 特征工程 · 数据标准化

特征工程

特征工程

  • 来源章节: 2.1.3
  • 定义: 基于原始数据创建、选择、转换特征，提升模型性能
  • 核心操作:
  • 特征创建（Feature Creation）:
    •     # 示例：创建收入负债比特征
    df['IncomeToDebtRatio'] = df['MonthlyIncome'] / df['DebtRatio']
    
    # 示例：年龄分段
    df['AgeGroup'] = pd.cut(df['Age'], bins=[0, 30, 50, 100],

    y = df[target]                   # 目标变量
  • 特征转换: 见 数据标准化（归一化、标准化）
  • 常见衍生特征:
  • 比值特征：收入/支出、点击率、转化率
  • 交叉特征：年龄×收入、城市×职业
  • 时间特征：星期几、是否节假日、时间间隔
  • 统计特征：历史平均值、最大值、方差
  • 特征工程规范（答题卷参考）:

1. 根据业务逻辑创建衍生特征，提升模型表达能力

2. 分离特征变量 X 和目标变量 y，为模型训练做准备

3. 删除无关特征（如 ID、时间戳），避免模型过拟合

  • 易错点:
  • drop(columns=[...]) 不修改原 DataFrame，需要赋值 X = df.drop(...)
  • 创建新特征前要先清洗数据（处理缺失值、异常值）
  • 测试集的特征工程要与训练集保持一致
  • 关联: 数据标准化 · pd-cut-binning · 数据集划分
