二、任务拆解

任务①：传感器数据统计

中文要求：统计每种传感器的数据数量和平均值

翻译成 pandas：

df.groupby('SensorType')['Value'].agg(['count', 'mean'])

知识点：groupby + .agg() 一次算多个统计量（count 数量 / mean 平均值）

任务②：按位置统计温度和湿度平均值

中文要求：每个位置（Location）的温度（Temperature）和湿度（Humidity）传感器数据的平均值

翻译成 pandas：

# 1. 先筛选出温度和湿度两种传感器
temp_humidity = df[df['SensorType'].isin(['Temperature', 'Humidity'])]

# 2. 按位置 + 传感器类型分组，求平均值
temp_humidity.groupby(['Location', 'SensorType'])['Value'].mean()

新知识点：.isin([列表]) 筛选多个值（比 == 'Temperature' | == 'Humidity' 简洁）

任务③：数据清洗（本单元核心）

中文要求：

1. 标记异常值：温度 > 50 或湿度 > 100

2. 缺失值填充：前向填充（ffill），前面没有就后向填充（bfill）

3. 保存为 cleaned_sensor_data.csv

翻译成 pandas：

# 1. 标记异常值（新增一列）
df['Anomaly'] = ((df['SensorType'] == 'Temperature') & (df['Value'] > 50)) | \
                ((df['SensorType'] == 'Humidity') & (df['Value'] > 100))

# 2. 统计异常值数量
print(df['Anomaly'].sum())

# 3. 缺失值填充（虽然当前数据无缺失，但考试要写）
df['Value'] = df['Value'].fillna(method='ffill').fillna(method='bfill')

# 4. 保存清洗后的数据
df.to_csv('cleaned_sensor_data.csv', index=False)

三、新知识点详解

① .isin() —— 多值筛选
# 笨办法（写两次条件）
df[(df['SensorType'] == 'Temperature') | (df['SensorType'] == 'Humidity')]

# 简洁写法
df[df['SensorType'].isin(['Temperature', 'Humidity'])]

原理：.isin(['A', 'B']) 检查每行是否在列表里，返回布尔列。

② .fillna(method='ffill') —— 前向填充
# 假设 Value 列有缺失值：
# [10, NaN, NaN, 20, 30, NaN]

df['Value'].fillna(method='ffill')
# 结果：[10, 10, 10, 20, 30, 30]
# 每个 NaN 用它前面的值填充

df['Value'].fillna(method='bfill')
# 结果：[10, 20, 20, 20, 30, NaN]
# 每个 NaN 用它后面的值填充（最后一个 NaN 无后续值仍是 NaN）

链式填充（考试常用）：

df['Value'].fillna(method='ffill').fillna(method='bfill')
# 先前向填充，还有剩余 NaN 再后向填充

参数对照表：

method 参数含义别名
'ffill'forward fill（前向填充）'pad'
'bfill'backward fill（后向填充）'backfill'
③ 异常值标记 —— 布尔索引 + 新列赋值
# 温度 > 50 是异常
df['Anomaly'] = (df['SensorType'] == 'Temperature') & (df['Value'] > 50)
# 每行是 True（异常）或 False（正常）

# 同时标记两种异常：温度 > 50 或湿度 > 100
df['Anomaly'] = ((df['SensorType'] == 'Temperature') & (df['Value'] > 50)) | \
                ((df['SensorType'] == 'Humidity') & (df['Value'] > 100))
# ⚠️ 注意：每个条件要加括号，因为 & 优先级高于 ==

统计异常数量：

df['Anomaly'].sum()    # True=1、False=0，求和 = 异常行数
④ .to_csv() —— 保存 CSV
df.to_csv('cleaned_sensor_data.csv', index=False)

参数：

  • 第一个参数：文件名（相对路径，保存在工作目录）
  • index=False：不保存行号列（考试必加，否则会多一列 0,1,2...）

四、完整解题流程演示

import pandas as pd

# 读取数据
df = pd.read_csv('sensor_data.csv')

# 任务①：每种传感器的数据数量和平均值
task1 = df.groupby('SensorType')['Value'].agg(['count', 'mean'])
print(task1)
#                 count       mean
# Humidity         2036  50.234567
# Light            1982  49.876543
# SoilMoisture     1995  50.123456
# SoilPH           2001  49.987654
# Temperature      1986  25.345678

# 任务②：每个位置的温度和湿度平均值
temp_humidity = df[df['SensorType'].isin(['Temperature', 'Humidity'])]
task2 = temp_humidity.groupby(['Location', 'SensorType'])['Value'].mean()
print(task2)
# Location  SensorType
# Field1    Humidity       50.1
#           Temperature    25.3
# Field2    Humidity       50.5
#           Temperature    25.1
# ...

# 任务③：数据清洗
# 1. 标记异常值
df['Anomaly'] = ((df['SensorType'] == 'Temperature') & (df['Value'] > 50)) | \
                ((df['SensorType'] == 'Humidity') & (df['Value'] > 100))
print('异常值数量:', df['Anomaly'].sum())

# 2. 缺失值填充（虽然数据无缺失，但题目要求写）
df['Value'] = df['Value'].fillna(method='ffill').fillna(method='bfill')

# 3. 保存清洗后的数据
df.to_csv('cleaned_sensor_data.csv', index=False)

五、易错点（考试陷阱）

⚠️ 陷阱 1：.isin() 里要用列表
# ❌ 错误
df[df['SensorType'].isin('Temperature', 'Humidity')]  # isin() 只接受一个参数

# ✅ 正确
df[df['SensorType'].isin(['Temperature', 'Humidity'])]  # 必须用列表
⚠️ 陷阱 2：复杂条件必须加括号
# ❌ 错误（运算符优先级导致逻辑错误）
df['Anomaly'] = df['SensorType'] == 'Temperature' & df['Value'] > 50

# ✅ 正确
df['Anomaly'] = (df['SensorType'] == 'Temperature') & (df['Value'] > 50)

原因：& 的优先级高于 ==，不加括号相当于 df['SensorType'] == (wrong expression)

⚠️ 陷阱 3：.to_csv() 忘记 index=False
# ❌ 错误（多一列行号）
df.to_csv('cleaned.csv')
# 结果 CSV 第一列是 0,1,2,3...

# ✅ 正确
df.to_csv('cleaned.csv', index=False)

六、自测题

1. .isin(['A', 'B']) 和 == 'A' | == 'B' 的结果相同吗？为什么 .isin() 更安全？

2. .fillna(method='ffill').fillna(method='bfill') 为什么要链式调用两次？单独用 ffill 会留下什么情况的 NaN？

3. (df['A'] > 10) & (df['B'] < 5) 里的括号能去掉吗？为什么？

参考答案（先自测再看）

1. 结果相同，但 .isin() 更安全：

  • == 'A' | == 'B' 在 pandas 里语法错误（运算符优先级问题，需要写成 (df['col'] == 'A') | (df['col'] == 'B')）
  • .isin(['A', 'B']) 一行搞定，不会因括号漏写出错，且更易读

2. 链式调用处理首尾 NaN：

  • ffill 只能填充「有前面值」的 NaN，第一行如果是 NaN 无法填充
  • bfill 只能填充「有后面值」的 NaN，最后一行如果是 NaN 无法填充
  • 链式：ffill 填中间，bfill 补首尾，覆盖所有情况

3. 不能去括号，会逻辑错误：

  • & 优先级高于 >，不加括号相当于 df['A'] > (10 & df['B']) < 5（语义错误）
  • pandas 要求逻辑运算必须显式加括号

知识点卡片

boolean-column-assignment

boolean-column-assignment（布尔列赋值 / 异常值标记）

  • 来源章节: 1.1.2
  • 定义: 用布尔表达式创建新列，每行是 True/False，用于标记异常值、分类等
  • 用法:
    •   # 单条件标记
  df['Anomaly'] = df['Value'] > 50
  
  # 多条件标记（温度 > 50 或湿度 > 100）
  df['Anomaly'] = ((df['SensorType'] == 'Temperature') & (df['Value'] > 50)) | \
                  ((df['SensorType'] == 'Humidity') & (df['Value'] > 100))
  
  # 统计异常数量
  df['Anomaly'].sum()   # True=1、False=0，求和 = 异常行数
  • ⚠️ 易错点（考点）:
  • 复杂条件必须加括号，因为 & / | 优先级高于 == / >
  • ❌ df['A'] > 10 & df['B'] < 5 逻辑错误
  • ✅ (df['A'] > 10) & (df['B'] < 5) 正确
  • 关联: boolean-indexing · boolean-mean-ratio

drop-columns

drop-columns（删除指定列）

  • 来源章节: 1.1.2
  • 定义: 删除 DataFrame 中的指定列（无论有无缺失值）
  • 用法:
    •   df.drop(columns=['col1', 'col2'])     # 删除指定列
  df.drop(['col1', 'col2'], axis=1)     # 旧写法（axis=1 表示列）
  df.drop(index=[0, 1, 2])              # 删除指定行
  • 与 .dropna() 的区别:
  • .drop(columns=[...]) 删除 你指定的 列（主动删除）
  • .dropna() 删除 含缺失值（NaN） 的行/列（自动找 NaN）
  • .dropna() 没有 columns 参数！
  • ⚠️ 易错点:
  • ❌ df.dropna(columns=['col']) 语法错误（dropna 没有 columns 参数）
  • ✅ df.drop(columns=['col']) 删除指定列
  • ✅ df.dropna(subset=['col']) 删除该列为 NaN 的行
  • 关联: fillna-method · to-csv

fillna-method

fillna-method（缺失值填充）

  • 来源章节: 1.1.2
  • 定义: 用前面或后面的值填充 NaN（缺失值），而非固定值
  • 用法:
    •   df['Value'].fillna(method='ffill')   # 前向填充（用前面的值）
  df['Value'].fillna(method='bfill')   # 后向填充（用后面的值）
  # 链式调用（考试常用）：
  df['Value'].fillna(method='ffill').fillna(method='bfill')
  • 参数: method='ffill'（前向，别名 'pad'）/ method='bfill'（后向，别名 'backfill'）
  • ⚠️ 易错点:
  • ffill 无法填充第一行的 NaN（前面没有值）
  • bfill 无法填充最后一行的 NaN（后面没有值）
  • 链式调用可以覆盖首尾：先 ffill 填中间，再 bfill 补首尾
  • 关联: isin-filter · to-csv

isin-filter

isin-filter（多值筛选）

  • 来源章节: 1.1.2
  • 定义: 筛选某列的值在指定列表里的行 —— 比多个 == 或条件简洁
  • 用法:
    •   df[df['SensorType'].isin(['Temperature', 'Humidity'])]
  # 等价于（但更简洁）：
  df[(df['SensorType'] == 'Temperature') | (df['SensorType'] == 'Humidity')]
  • 参数: .isin([列表]) —— 必须是列表，不能直接传多个参数
  • ⚠️ 易错点:
  • ❌ .isin('A', 'B') 语法错误（isin 只接受一个参数）
  • ✅ .isin(['A', 'B']) 必须用列表包裹
  • 关联: boolean-indexing · groupby-aggregation

to-csv

to-csv（保存 CSV）

  • 来源章节: 1.1.2
  • 定义: 把 DataFrame 保存为 CSV 文件
  • 用法:
    •   df.to_csv('cleaned_sensor_data.csv', index=False)
  • 参数:
  • 第一个参数：文件名（字符串），相对路径保存在工作目录
  • index=False：考试必加，不保存行号列（否则 CSV 第一列是 0,1,2...）
  • ⚠️ 易错点:
  • 忘记 index=False 会多一列行号，导致后续读取时列数不匹配
  • 文件名要加引号（字符串）
  • 关联: pandas-read-csv · fillna-method
