二、逐项知识点与填写方法

① 读取数据与变量名
import pandas as pd
import numpy as np

data = pd.read_csv('sensor_data.csv')

data 是 DataFrame，SensorType 是传感器类型，Value 是读数，Location 是安装位置。原模板还导入了 matplotlib.pyplot，但本题三项任务不要求绘图；填写时保留已给出的导入语句。

② 传感器数量和平均值：groupby + agg
sensor_stats = data.groupby('SensorType')['Value'].agg(['count', 'mean'])

对应原模板的三个空，依次是 data.groupby、'SensorType'、agg(['count', 'mean'])。

groupby('SensorType') 将相同类型的行分在一组；['Value'] 选取读数列；agg(...) 同时计算 count 和 mean，得到两列结果。count 统计非缺失读数数量，本 CSV 没有缺失值，因此等于每种传感器的记录数。

③ 按位置统计温度和湿度：isin、双列分组与 unstack

原模板只有一行，并已给出 .mean().unstack()，完整填写后应为：

location_stats = data[data['SensorType'].isin(['Temperature', 'Humidity'])].groupby(['Location', 'SensorType'])['Value'].mean().unstack()

这行可以按顺序理解为：

1. data['SensorType'].isin(['Temperature', 'Humidity']) 生成布尔 Series，判断每行是否属于温度或湿度。

2. 外层 data[...] 保留条件成立的行，排除 Light、SoilMoisture、SoilPH。

3. groupby(['Location', 'SensorType']) 按“位置 + 类型”两个维度分组。

4. ['Value'].mean() 计算每组平均读数。

5. unstack() 将内层的 SensorType 索引展开成列，使位置为行、Humidity 和 Temperature 为列。

特别注意原始行的结构：

location_stats = data[data['SensorType'].【空1】.【空2】['Value'].mean().unstack()
  • 空 1：isin(['Temperature', 'Humidity'])]，最后的 ] 用来关闭外层的 data[...]。
  • 空 2：groupby(['Location', 'SensorType'])，前面的点已在模板中给出。

只填 isin(...) 而漏掉末尾 ] 会造成括号不匹配。只输出分组均值而省略 unstack()，虽然数值可以相同，但输出结构与原模板不一致。

④ 标记异常：np.where 与完整阈值条件
data['is_abnormal'] = np.where(
    ((data['SensorType'] == 'Temperature') & ((data['Value'] < -10) | (data['Value'] > 50))) |
    ((data['SensorType'] == 'Humidity') & ((data['Value'] < 0) | (data['Value'] > 100))),
    True, False
)

原模板三个空依次填写 np.where、data['SensorType'] == 'Temperature'、data['SensorType'] == 'Humidity'。数值阈值和 True, False 已由模板给出。

传感器类型异常条件边界值是否异常
TemperatureValue < -10 或 Value > 50-10、50 本身不是异常
HumidityValue < 0 或 Value > 1000、100 本身不是异常
其他三种类型本题没有给出异常阈值不套用温度或湿度条件

& 表示“同时满足”，| 表示“至少满足一个”，每个比较条件要加括号。不能只写 Value > 50，否则会把湿度、光照等类型的正常读数也标为异常。

np.where 将判断结果写入布尔列 is_abnormal。本题要求标记并统计异常，没有要求删除异常行、截断读数或将异常读数改成缺失值。

⑤ 统计异常数量：布尔列求和
print("异常值数量:", data['is_abnormal'].sum())

该处空填 sum()。True 按 1、False 按 0 计算，求和得到异常行数。本数据结果为 1011，全部来自温度高于 50 的记录；其他三个异常条件的数量均为 0。

⑥ 填补缺失值：先前向，再后向

ffill 使用前面的有效值填补；如果开头的缺失值没有前值可用，再用 bfill 从后面填补。

sample = pd.Series([np.nan, 10.0, np.nan, 20.0, np.nan])
filled_sample = sample.ffill().bfill()
# filled_sample.tolist() → [10.0, 10.0, 10.0, 20.0, 20.0]

当前 CSV 的 Value 列没有缺失值，但仍需完成题目要求的填充步骤。若整列全是缺失值，前后都没有有效值可用，这两种方法也无法填补。

⑦ 删除临时标记列：drop(columns=...)
cleaned_data = data.drop(columns=['is_abnormal'])

两个空分别是 data.drop、columns。drop 删除指定列，返回清洗后的 DataFrame，保存到 cleaned_data。

删除的是临时标记列，不是异常记录。导出前，cleaned_data 应仍有 10000 行和原来的 5 列。不要误用 dropna(columns=...)，它不是删除指定列的方法。

⑧ 保存 CSV：使用 cleaned_data，且不保存索引
cleaned_data.to_csv('cleaned_sensor_data.csv', index=False)

两个空分别是 cleaned_data.to_csv、index=False。index=False 防止额外写入行号列。不要导出仍含 is_abnormal 的 data。

三、原模板与本地 pandas 版本的区别

原题的两行填充框架是 data['Value'].方法(参数, inplace=True)。当前练习环境在 requirements.txt 中固定为 pandas 2.2.3，默认未启用写时复制时可按原模板填写如下；旧接口会产生弃用警告，但不等于运行错误：

# 原模板预期填写：仅供支持 method 参数且未启用写时复制的旧版 pandas 环境
data['Value'].fillna(method='ffill', inplace=True)
data['Value'].fillna(method='bfill', inplace=True)

如果改用 pandas 3.x，第一行会报 TypeError: NDFrame.fillna() got an unexpected keyword argument 'method'。pandas 3.0 已移除这个参数；启用写时复制时，对选出的单列使用 inplace=True 也不会更新原 DataFrame。

在 pandas 3.x 或启用写时复制的环境中，可用下面的兼容写法替代这两行：

data['Value'] = data['Value'].ffill().bfill()

这一行先得到填充后的 Series，再赋回 Value 列，在 pandas 2.2.3 中也可使用。它是明确的模板版本适配；当前固定版本下做填空题仍可保留原框架，其他任务的填空按上面的逐项对照完成。

以上版本区别也见 pandas 官方的 3.0 更新说明及写时复制说明。本讲义只说明适配方法，不修改你的练习笔记本或 Python 环境。

本地可运行的完整参考流程（仅缺失值填充两行做版本适配） 
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 读取数据
data = pd.read_csv('sensor_data.csv')

# 1. 传感器数据统计
sensor_stats = data.groupby('SensorType')['Value'].agg(['count', 'mean'])
print("传感器数据数量和平均值:")
print(sensor_stats)

# 2. 按位置统计温度和湿度数据
location_stats = data[data['SensorType'].isin(['Temperature', 'Humidity'])].groupby(['Location', 'SensorType'])['Value'].mean().unstack()
print("每个位置的温度和湿度数据平均值:")
print(location_stats)

# 3. 数据清洗和异常值处理
data['is_abnormal'] = np.where(
    ((data['SensorType'] == 'Temperature') & ((data['Value'] < -10) | (data['Value'] > 50))) |
    ((data['SensorType'] == 'Humidity') & ((data['Value'] < 0) | (data['Value'] > 100))),
    True, False
)
print("异常值数量:", data['is_abnormal'].sum())

# 跨版本兼容写法：替代原模板的两行旧式填充
data['Value'] = data['Value'].ffill().bfill()

cleaned_data = data.drop(columns=['is_abnormal'])
cleaned_data.to_csv('cleaned_sensor_data.csv', index=False)
print("数据清洗完成，已保存为 'cleaned_sensor_data.csv'")

六、自测题

1. sensor_stats 为什么使用 agg(['count', 'mean'])？count 统计的是行数还是非缺失值数？

2. 原模板位置统计第一处空为什么必须包括末尾的 ]？unstack() 改变了什么？

3. 温度 -10、50、51 与湿度 0、100、101 分别是否异常？

4. 为什么统计异常数用 sum()？为什么不能把所有 Value > 50 的行都标成异常？

5. 为什么要用 data.drop(columns=['is_abnormal'])？是否应该删除异常行？

6. 本地为什么使用 data['Value'] = data['Value'].ffill().bfill()？如果整列都是 NaN，会全部填好吗？

7. 应导出 data 还是 cleaned_data？index=False 有什么作用？

参考答案（先自测再看）

1. 同时计算两个统计量；count 统计 Value 的非缺失值数，本 CSV 无缺失，所以等于记录数。

2. 它关闭最外层的筛选括号；unstack 将 SensorType 从内层行索引展开为列，得到位置 × 传感器类型的二维表。

3. 温度 -10、50 正常，51 异常；湿度 0、100 正常，101 异常。

4. 布尔值 True=1、False=0，求和得到异常数；不同传感器的阈值不同，必须同时判断类型和读数。

5. 导出前删除临时标记列；原题没有要求删除异常行。

6. pandas 3.x 不支持旧式 method 参数，启用写时复制时单列原地修改也不会更新原表；兼容写法使用填充结果赋回原列。当前固定的 pandas 2.2.3 默认环境仍可按原模板填写。全空列没有有效值，仍会保留 NaN。

7. 导出 cleaned_data，避免保留临时标记列；index=False 防止写入额外行号列。

知识点卡片

boolean-column-assignment

boolean-column-assignment（布尔列赋值 / 异常值标记）

  • 来源章节: 1.1.2
  • 定义: 用布尔表达式创建新列，每行是 True/False，用于标记异常值、分类等
  • 用法:
    •   # 单条件标记
  df['Anomaly'] = df['Value'] > 50

  # 多条件标记（温度 > 50 或湿度 > 100）
  df['Anomaly'] = ((df['SensorType'] == 'Temperature') & (df['Value'] > 50)) | \
                  ((df['SensorType'] == 'Humidity') & (df['Value'] > 100))

  # 统计异常数量
  df['Anomaly'].sum()   # True=1、False=0，求和 = 异常行数
  • ⚠️ 易错点（考点）:
  • 复杂条件必须加括号，因为 & / | 优先级高于 == / >
  • ❌ df['A'] > 10 & df['B'] < 5 逻辑错误
  • ✅ (df['A'] > 10) & (df['B'] < 5) 正确
  • 关联: boolean-indexing · boolean-mean-ratio

drop-columns

drop-columns（删除指定列）

  • 来源章节: 1.1.2
  • 定义: 删除 DataFrame 中的指定列（无论有无缺失值）
  • 用法:
    •   df.drop(columns=['col1', 'col2'])     # 删除指定列
  df.drop(['col1', 'col2'], axis=1)     # 旧写法（axis=1 表示列）
  df.drop(index=[0, 1, 2])              # 删除指定行
  • 与 .dropna() 的区别:
  • .drop(columns=[...]) 删除 你指定的 列（主动删除）
  • .dropna() 删除 含缺失值（NaN） 的行/列（自动找 NaN）
  • .dropna() 没有 columns 参数！
  • ⚠️ 易错点:
  • ❌ df.dropna(columns=['col']) 语法错误（dropna 没有 columns 参数）
  • ✅ df.drop(columns=['col']) 删除指定列
  • ✅ df.dropna(subset=['col']) 删除该列为 NaN 的行
  • 关联: fillna-method · to-csv

fillna-method

fillna-method（缺失值填充）

  • 来源章节: 1.1.2
  • 定义: 用前面或后面的值填充 NaN（缺失值），而非固定值
  • 用法:
    •   df['Value'].fillna(method='ffill')   # 前向填充（用前面的值）
  df['Value'].fillna(method='bfill')   # 后向填充（用后面的值）
  # 链式调用（考试常用）：
  df['Value'].fillna(method='ffill').fillna(method='bfill')
  • 参数: method='ffill'（前向，别名 'pad'）/ method='bfill'（后向，别名 'backfill'）
  • ⚠️ 易错点:
  • ffill 无法填充第一行的 NaN（前面没有值）
  • bfill 无法填充最后一行的 NaN（后面没有值）
  • 链式调用可以覆盖首尾：先 ffill 填中间，再 bfill 补首尾
  • 关联: isin-filter · to-csv

isin-filter

isin-filter（多值筛选）

  • 来源章节: 1.1.2
  • 定义: 筛选某列的值在指定列表里的行 —— 比多个 == 或条件简洁
  • 用法:
    •   df[df['SensorType'].isin(['Temperature', 'Humidity'])]
  # 等价于（但更简洁）：
  df[(df['SensorType'] == 'Temperature') | (df['SensorType'] == 'Humidity')]
  • 参数: .isin([列表]) —— 必须是列表，不能直接传多个参数
  • ⚠️ 易错点:
  • ❌ .isin('A', 'B') 语法错误（isin 只接受一个参数）
  • ✅ .isin(['A', 'B']) 必须用列表包裹
  • 关联: boolean-indexing · groupby-aggregation
