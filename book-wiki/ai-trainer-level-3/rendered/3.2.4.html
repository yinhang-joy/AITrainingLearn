重要资源说明：本单元的模型文件与 3.2.1 的 resnet.onnx 二进制内容相同，两份 labels.txt 也完全相同。因此当前资源实际使用 1000 类通用图像分类标签，不是专用的若干类花卉标签，也不是输出花朵边界框的检测模型。

应按提供的文件完成填空，不要自行编造花卉类别表、更换模型或重新编号标签。通用标签中包含 daisy，所以仍可以对当前雏菊图片产生相应分类输出，但不能据此宣称它覆盖所有花卉。

题干一处写作 flower _test.png，实际文件名和本题参考均为没有额外空格的 flower_test.png，以资源目录为准。

二、图片如何满足模型要求

模型需要 float32、(1, 3, 224, 224)，输出为 (1, 1000)。

session = ort.InferenceSession('flower-detection.onnx')
with open('labels.txt') as f:
    labels = [line.strip() for line in f.readlines()]

image = Image.open('flower_test.png').convert('RGB')
processed_image = preprocess_image(image)
processed_image = processed_image.astype(np.float32)

本题 png 带透明通道，是 RGBA 四通道，convert('RGB') 很重要，否则数组可能不是模型需要的三个通道。

原题预处理流程：缩放到 256×256 → 中心裁剪 224×224 → 转数组、除以 255 → 使用指定 RGB 均值和标准差 → 将 HWC 转为 CHW → 增加批次维度。

  • image.size 的顺序是宽、高。
  • RGB 图片数组的 shape 是高、宽、通道。
  • np.transpose(image, (2, 0, 1)) 把通道移到前面。
  • 最后转 float32 是为了与模型声明的输入类型一致。

三、推理、类别索引和概率百分比

input_name = session.get_inputs()[0].name
output_name = session.get_outputs()[0].name
output = session.run([output_name], {input_name: processed_image})[0]
accuracy = scipy.special.softmax(output, axis=-1)
predicted_idx = np.argmax(accuracy)
prob_percentage = accuracy[0][predicted_idx] * 100
predicted_label = labels[predicted_idx]

按顺序理解每个变量：

变量含义
output模型输出的 1000 个类别分数
accuracysoftmax 后的类别概率数组，形状仍为 (1, 1000)
predicted_idx最大概率所在的类别索引
prob_percentage该类别的概率乘 100
predicted_label根据索引在标签文件中查到的名称

np.argmax 返回索引，np.max 才返回最大值。不能把最大概率当作标签下标。

原题将变量命名为 accuracy，输出也写作 Accuracy；这里实际展示的是单张图片的预测概率，不是用有标注测试集计算出的分类准确率。保留题目变量和输出形式，在答题分析里正确解释其含义。

import onnxruntime as ort
import numpy as np
import scipy.special
from PIL import Image


# 预处理图像
def preprocess_image(image, resize_size=256, crop_size=224, mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]):
    image = image.resize((resize_size, resize_size), Image.BILINEAR)
    w, h = image.size
    left = (w - crop_size) / 2
    top = (h - crop_size) / 2
    image = image.crop((left, top, left + crop_size, top + crop_size))
    image = np.array(image).astype(np.float32)
    image = image / 255.0
    image = (image - mean) / std
    image = np.transpose(image, (2, 0, 1))
    image = image.reshape((1,) + image.shape)
    return image


# 加载模型  2分
session = ort.InferenceSession('flower-detection.onnx')


# 加载类别标签 2分
with open('labels.txt') as f:
    labels = [line.strip() for line in f.readlines()]


# 获取模型输入和输出的名称
input_name = session.get_inputs()[0].name
output_name = session.get_outputs()[0].name


# 加载图片  2分
image = Image.open('flower_test.png').convert('RGB')


# 预处理图片  2分
processed_image = preprocess_image(image)


# 确保输入数据是 float32 类型
processed_image = processed_image.astype(np.float32)


# 进行图片识别  2分
output = session.run([output_name], {input_name: processed_image})[0]


# 应用 softmax 函数获取识别分类后的准确率  2分
accuracy = scipy.special.softmax(output, axis=-1)


# 获取预测的类别索引
predicted_idx =  np.argmax(accuracy)


# 获取预测的准确值（转换为百分比）
prob_percentage =  accuracy[0][predicted_idx] * 100


# 获取预测的类别标签
predicted_label = labels[predicted_idx]


# 输出预测结果，包含百分比形式的概率
print(f"Predicted class: {predicted_label}, Accuracy: {prob_percentage:.2f}%")

五、结果核验与交互方案

当前实际资源实测输出：

Predicted class: daisy, Accuracy: 96.41%

这个 96.41% 是当前图片对应类别的模型概率，不是整体准确率；不能仅凭一张图判断模型对所有花卉都可靠。

答题卷可以按以下流程设计，并写清至少三条具体交互措施：

  • 选择或拍摄花朵图片，显示预览，提示尽量聚焦单朵花、减少遮挡。
  • 用户确认图片后开始识别，展示进度，加载失败时支持重试。
  • 展示原图、类别名称和概率，明确结果为模型建议。
  • 对不确定或不支持的类别允许重新拍摄、人工确认或修改，避免强行归类。
  • 经用户确认后保存结果；保留查看原图和更正记录的入口。

当前通用分类资源的类别覆盖限制应如实说明。若要建设专门的花卉系统，需要匹配的花卉模型、标签和评估样本，这属于后续资源改进，不属于本题填空修改。
