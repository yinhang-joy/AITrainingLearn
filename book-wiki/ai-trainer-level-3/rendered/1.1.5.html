三、新知识点详解

① .dropna() —— 删除缺失值
data = data.dropna()

作用：删除包含 NaN（缺失值）的所有行

对比 1.1.2 的 .fillna()：

  • fillna()：填充缺失值（保留行，用其他值替代 NaN）
  • dropna()：删除缺失值（直接删除包含 NaN 的行）

选择原则：

  • 缺失值少 → dropna()（简单粗暴）
  • 缺失值多 → fillna()（避免丢失太多数据）
② .astype() —— 数据类型转换
data['Age'] = data['Age'].astype(int)
data['Speed'] = data['Speed'].astype(float)

作用：将列的数据类型转换为指定类型

常见类型：

类型用途示例
int整数（年龄、数量）data['Age'].astype(int)
float浮点数（速度、距离）data['Speed'].astype(float)
str字符串（ID、名称）data['VehicleID'].astype(str)

为什么要转换：CSV 读取时可能把数字识别为字符串，导致后续计算出错

③ .between() —— 范围验证（本单元核心）
data['Age'].between(18, 70)

作用：检查每个值是否在指定范围内，返回布尔列

等价写法：

# between 一行搞定
data['Age'].between(18, 70)

# 传统写法（两次比较）
(data['Age'] >= 18) & (data['Age'] <= 70)

默认行为：闭区间 [18, 70]（包含边界值）

开放区间：between(18, 70, inclusive='neither')（不包含边界）

④ 多条件筛选（复习 + 强化）
# 保留合理数据
data = data[(条件1) & (条件2) & (条件3)]

# 找出不合理数据（取反）
unreasonable = data[~(条件1) & (条件2)]

运算符：

符号含义示例
&与（且）(条件1) & (条件2)
`\`或`(条件1) \(条件2)`
~非（取反）~(条件)

⚠️ 注意：每个条件必须加括号，否则运算符优先级会导致错误

⑤ .value_counts() —— 频次统计
data['TrafficEvent'].value_counts()

作用：统计分类字段每个值的出现次数

输出示例：

Normal         450
Traffic Jam    230
Accident       180
Breakdown      140

对比 groupby().count()：

  • value_counts()：单列统计，自动排序
  • groupby().count()：多列统计，需指定分组列

五、易错点（考试陷阱）

⚠️ 陷阱 1：.between() 里忘记加括号
# ❌ 错误（运算符优先级导致逻辑错误）
data = data[data['Age'].between(18, 70) & data['Speed'].between(0, 200)]

# ✅ 正确
data = data[(data['Age'].between(18, 70)) & (data['Speed'].between(0, 200))]
⚠️ 陷阱 2：审核任务里忘记取反符号 ~
# ❌ 错误（找出的是合理数据，不是不合理数据）
unreasonable = data[(data['Age'].between(18, 70))]

# ✅ 正确
unreasonable = data[~((data['Age'].between(18, 70)))]

记忆技巧：审核任务要找「不合理」的数据 = 「不」满足条件 = ~（取反）

⚠️ 陷阱 3：年龄分箱的开放区间处理
# 题目要求：65岁以上
# ❌ 错误（bins 最后一个值写固定数字，会漏掉超出的数据）
age_bins = [18, 26, 36, 46, 56, 66, 100]

# ✅ 正确（用 np.inf 表示无穷大，包含所有大于 66 的值）
age_bins = [18, 26, 36, 46, 56, 66, np.inf]
⚠️ 陷阱 4：.astype() 转换前未清洗缺失值
# ❌ 错误（NaN 无法转换为 int，会报错）
data['Age'] = data['Age'].astype(int)
data = data.dropna()

# ✅ 正确（先删除 NaN，再转换类型）
data = data.dropna()
data['Age'] = data['Age'].astype(int)

原则：数据清洗顺序：先删除/填充缺失值 → 再转换类型

六、自测题

1. .between(18, 70) 和 (df['Age'] >= 18) & (df['Age'] <= 70) 的结果相同吗？哪个更简洁？

2. 为什么步骤②里要先 dropna() 再 .astype(int)？顺序反了会怎样?

3. 审核任务里的 ~ 符号是什么意思？为什么要用它？

4. pd.cut 的 bins=[18, 26, 36, ..., np.inf] 里的 np.inf 有什么作用？能用 1000 代替吗？

参考答案（先自测再看）

1. 结果相同，.between() 更简洁：

  • 传统写法需要两次比较 + 一次 &
  • .between() 一个方法搞定，代码更易读

2. 先删缺失值，再转类型：

  • NaN（缺失值）无法转换为 int 类型，会报错 ValueError
  • 必须先 dropna() 删除 NaN，再 astype(int) 转换

3. ~ 是取反符号（逻辑非）：

  • 审核任务要找「不合理」的数据
  • 原条件是「合理范围」，加 ~ 反转为「不在合理范围内」

4. np.inf 表示正无穷大：

  • 处理开放区间「65岁以上」（无上限）
  • 不能用 1000 代替：如果有 101 岁的数据，会被排除在外（导致数据丢失）
