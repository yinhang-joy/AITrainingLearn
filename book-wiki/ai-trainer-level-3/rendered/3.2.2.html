一、资源和任务要求

这是推理题，不是模型训练题。流程为：加载模型 → 打开图片 → 灰度化、缩放、整理形状 → 推理 → 取分数最高的数字。

模型输入要求 float32、(1, 1, 28, 28)，输出为 (1, 10)，10 个位置对应数字 0 到 9。本题没有独立的 labels 文件，不要从其他单元复制标签文件进来。

二、图片为什么要变成四维

image = Image.open('img_test.png').convert('L')
image = image.resize((28, 28))
image_array = np.array(image, dtype=np.float32)
image_array = np.expand_dims(image_array, axis=0)
image_array = np.expand_dims(image_array, axis=0)
  • convert('L')：转成单通道灰度图，不是 RGB 三通道。
  • resize((28, 28))：把空间尺寸改成模型要求的大小。
  • np.array(image, dtype=np.float32)：将 PIL 图片转成模型能接收的数值数组，并指定类型。
  • np.expand_dims(数组, axis=0)：在最前面插入一个大小为 1 的维度，不会增加新的图片内容。
操作完成后形状
灰度图转数组(28, 28)
第一次 expand_dims(axis=0)(1, 28, 28)
第二次 expand_dims(axis=0)(1, 1, 28, 28)

最后四个位置是 N、C、H、W：图片数量、通道数、高度、宽度。本题 N 和 C 都为 1。

本题原始模板没有要求除以 255，也没有 ResNet 的均值、标准差处理。先按提供的模型和模板完成，不要把其他单元的预处理混进来。

三、模型输入字典与预测结果

ort_inputs = {ort_session.get_inputs()[0].name: image_array}
ort_outs = ort_session.run(None, ort_inputs)
predicted_class = np.argmax(ort_outs[0])

run(None, ort_inputs) 中：

  • None：返回全部输出。它不是“不输入图片”，也不是不进行预测。
  • ort_inputs：输入名称与图片数组的对应字典。
  • ort_outs：输出列表，ort_outs[0] 为第一个输出张量。

np.argmax 返回最大分数的位置，而不是最大分数本身。本题一个批次只有一张图，输出形状为 (1, 10)，因此这个位置正好就是预测数字。只要输出数字，不必为找最大值额外计算 softmax。

以下参考保留原题固定代码，仅补齐填空。在本单元目录运行。

import onnxruntime
import numpy as np
from PIL import Image


# 加载ONNX模型  2分
ort_session = onnxruntime.InferenceSession('mnist.onnx')


# 加载图像 2分
image = Image.open('img_test.png').convert('L')  # 转为灰度图


#图像预处理
image = image.resize((28, 28))  # 调整大小为MNIST模型的输入尺寸2分
image_array = np.array(image, dtype=np.float32)  # 转为numpy数组2分
image_array = np.expand_dims(image_array, axis=0)  # 添加batch维度2分
image_array = np.expand_dims(image_array, axis=0)  # 添加通道维度2分


#返回模型输入列表 2分
ort_inputs = {ort_session.get_inputs()[0].name: image_array}
# 执行预测 2分
ort_outs = ort_session.run(None, ort_inputs)


# 获取预测结果 2分
predicted_class = np.argmax(ort_outs[0])


# 输出预测结果
print(f"Predicted class: {predicted_class}")

五、检查结果和答题卷思路

当前测试图片按原题流程实测输出：

Predicted class: 8

这个结果用于核对流程，不是要求直接写 predicted_class = 8。

交互流程可以按“输入 → 预览 → 识别 → 人工确认 → 保存”组织，并落实为具体操作：

  • 支持上传图片或手写输入，显示待识别区域，允许清除、重写。
  • 提示每次只输入一个清晰数字，避免多个数字、背景杂乱和裁剪不完整。
  • 将识别数字与原图并排显示，允许用户直接修改错误结果。
  • 用户确认后再写入业务系统，保留重新识别入口，避免错误自动提交。
  • 文件打不开或图像质量不合适时，提示原因和下一步操作。

当前模板只输出类别，没有计算概率。答题卷可以提出增加置信度展示的优化需求，但不要声称现有程序已经输出了置信度。

常见问题：

  • 图片仍为 RGB：数组可能多出通道维度，先检查 convert('L')。
  • 输入是 uint8：检查 dtype=np.float32。
  • 输入只有二维、三维：检查是否完成两次扩展。
  • 使用 np.max：它返回数值，不是数字类别，应使用 np.argmax。
