1.1.4 电商平台用户行为分析系统的数据采集与处理流程设计

1.1.4 讲义：电商平台用户行为分析系统的数据采集与处理流程设计

  • 数据：user_behavior_data.csv
  • 真实字段：UserID / UserName / Age / Gender / Location / LastLogin / PurchaseAmount / PurchaseCategory / ReviewScore / LoginFrequency
  • 输出：cleaned_user_behavior_data.csv、1.1.4-1.jpg、1.1.4-2.jpg、1.1.4-3.jpg
  • 考核时间：30 分钟

一、任务拆解

1. 从 user_behavior_data.csv 读取数据并显示前 5 行。

2. 删除缺失值、转换类型、过滤异常值，对购买金额和评价评分进行 Z-score 标准化。

3. 保存清洗结果，并完成购买类别、性别、年龄段三项统计。

读取 → 删除缺失值 → 类型转换 → 异常过滤
    → 标准化 → 保存 → 三项分组统计
必须使用 CSV 的精确列名。购买金额是 PurchaseAmount，评价评分是 ReviewScore，不能写成 Amount 或 Rating。

二、读取和检查数据

import pandas as pd
import numpy as np

data = pd.read_csv('user_behavior_data.csv')
print(data.head(5))
print(data.info())
print(data.isnull().sum())
  • head(5)：检查内容和列名。
  • info()：检查数据类型和非空数量。
  • isnull().sum()：统计各列缺失值。

三、数据清洗与预处理

1. 删除缺失值
data = data.dropna()

删除后要继续使用返回的新 DataFrame，不能又切回原始数据。

2. 转换数据类型
data['Age'] = data['Age'].astype(int)
data['PurchaseAmount'] = data['PurchaseAmount'].astype(float)
data['ReviewScore'] = data['ReviewScore'].astype(int)

面对未知脏数据时，可先使用 pd.to_numeric(..., errors='coerce')，再删除转换失败产生的缺失值。

3. 过滤异常值

题目代码框架采用以下规则：

data = data[
    data['Age'].between(18, 70)
    & (data['PurchaseAmount'] > 0)
    & data['ReviewScore'].between(1, 5)
]
  • 年龄：18～70 岁，包含边界；
  • 购买金额：大于 0；
  • 评价评分：1～5 分，包含边界。
4. Z-score 标准化

题目只要求标准化购买金额和评价评分，不要求标准化年龄。

data['PurchaseAmount'] = (
    data['PurchaseAmount'] - data['PurchaseAmount'].mean()
) / data['PurchaseAmount'].std()

data['ReviewScore'] = (
    data['ReviewScore'] - data['ReviewScore'].mean()
) / data['ReviewScore'].std()

公式为 z = (x - 均值) / 标准差。按照本题代码框架，标准化结果直接覆盖原列。

5. 保存清洗结果
data.to_csv('cleaned_user_behavior_data.csv', index=False)

index=False 可避免把 DataFrame 行索引写成额外一列。

四、完成三项统计任务

1. 每个购买类别的用户数
purchase_category_counts = data['PurchaseCategory'].value_counts()
print('每个购买类别的用户数:\n', purchase_category_counts)

将输出截图保存为 1.1.4-1.jpg。

2. 不同性别的平均购买金额
gender_purchase_amount_mean = data.groupby('Gender')['PurchaseAmount'].mean()
print('不同性别的平均购买金额:\n', gender_purchase_amount_mean)

题目先标准化、后统计，因此这里得到的是各性别的标准化购买金额均值。将输出截图保存为 1.1.4-2.jpg。

3. 不同年龄段的用户数
bins = [18, 26, 36, 46, 56, 66, np.inf]
labels = ['18-25', '26-35', '36-45', '46-55', '56-65', '65+']

data['AgeGroup'] = pd.cut(
    data['Age'], bins=bins, labels=labels, right=False
)

age_group_counts = data['AgeGroup'].value_counts().sort_index()
print('不同年龄段的用户数:\n', age_group_counts)

right=False 表示左闭右开，例如 [18, 26) 对应 18～25 岁。将输出截图保存为 1.1.4-3.jpg。

五、完整解题流程

import pandas as pd
import numpy as np

# 1. 数据采集
data = pd.read_csv('user_behavior_data.csv')
print(data.head(5))

# 2. 清洗与类型转换
data = data.dropna()
data['Age'] = data['Age'].astype(int)
data['PurchaseAmount'] = data['PurchaseAmount'].astype(float)
data['ReviewScore'] = data['ReviewScore'].astype(int)

# 3. 异常值处理
data = data[
    data['Age'].between(18, 70)
    & (data['PurchaseAmount'] > 0)
    & data['ReviewScore'].between(1, 5)
]

# 4. 标准化
data['PurchaseAmount'] = (
    data['PurchaseAmount'] - data['PurchaseAmount'].mean()
) / data['PurchaseAmount'].std()
data['ReviewScore'] = (
    data['ReviewScore'] - data['ReviewScore'].mean()
) / data['ReviewScore'].std()

# 5. 保存
data.to_csv('cleaned_user_behavior_data.csv', index=False)

# 6. 每个购买类别的用户数
purchase_category_counts = data['PurchaseCategory'].value_counts()
print('每个购买类别的用户数:\n', purchase_category_counts)

# 7. 不同性别的平均购买金额
gender_purchase_amount_mean = data.groupby('Gender')['PurchaseAmount'].mean()
print('不同性别的平均购买金额:\n', gender_purchase_amount_mean)

# 8. 不同年龄段的用户数
bins = [18, 26, 36, 46, 56, 66, np.inf]
labels = ['18-25', '26-35', '36-45', '46-55', '56-65', '65+']
data['AgeGroup'] = pd.cut(data['Age'], bins=bins, labels=labels, right=False)
age_group_counts = data['AgeGroup'].value_counts().sort_index()
print('不同年龄段的用户数:\n', age_group_counts)

六、易错点

1. 真实字段是 PurchaseAmount 和 ReviewScore。

2. 年龄合理范围按代码框架为 18～70 岁。

3. 只标准化 PurchaseAmount 和 ReviewScore，不要生成题目未要求的 Age_std。

4. 使用 right=False 时，边界 26 才能让第一组完整覆盖 18～25 岁。

5. 三项统计必须分别完成，不能只统计年龄段购买金额。

6. 保存 CSV 时必须设置 index=False。

知识点卡片

astype-conversion

astype-conversion（数据类型转换）

  • 来源章节: 1.1.4
  • 定义: 将 DataFrame 列转换为正确的数据类型（整型、浮点型、字符串）
  • 用法:
    •   df['Age'] = df['Age'].astype(int)      # 浮点 → 整型
  df['Amount'] = df['Amount'].astype(float)  # 字符串 → 浮点
  • 常用类型:
  • int / 'int64'：整型
  • float / 'float64'：浮点型
  • str / 'object'：字符串
  • ⚠️ 易错点:
  • 浮点转整型截断小数（不是四舍五入）：89.9 → 89
  • 四舍五入需要先 round()：df['col'].round().astype(int)
  • 转换前检查合法性：'abc'.astype(float) 会报错
  • 关联: dropna-missing-values · between-filter

between-filter

between-filter（异常值检测与过滤）

  • 来源章节: 1.1.4
  • 定义: 使用 .between() 方法检查值是否在合理区间内，过滤异常数据
  • 用法:
    •   valid = df['Age'].between(18, 80)   # 返回布尔 Series
  df_clean = df[valid]                # 保留 True 的行
  # 多条件组合：
  df[(df['Age'].between(18, 80)) & (df['Amount'].between(0, 10000))]
  • 参数:
  • left, right：左右边界
  • inclusive='both'（默认）：包含两端 [left, right]
  • inclusive='neither'：不含两端 (left, right)
  • inclusive='left' / 'right'：只含一端
  • 对比 pd.cut():
  • between() 用于过滤：保留范围内的行
  • pd.cut() 用于分类：给每行打上区间标签
  • ⚠️ 易错点: 多条件组合必须每个条件都加括号：(cond1) & (cond2)
  • 关联: boolean-indexing · pandas-cut-binning

data-read-and-view

data-read-and-view（数据读取与查看）

  • 来源章节: 1.1.4
  • 定义: 读取 CSV 文件到 DataFrame 并使用三件套查看数据概况
  • 用法:
    •   data = pd.read_csv('file.csv')
  data.head()       # 查看前 5 行
  data.info()       # 列类型、缺失值
  data.describe()   # 数值列统计
  • 三件套区别:
  • .head()：看数据长什么样（前 5 行）
  • .info()：看数据类型和缺失值
  • .describe()：看数值分布（均值、最大最小值、四分位数）
  • 易错点: .describe() 只统计数值列（int/float），字符串列不会显示
  • 关联: dropna-missing-values · astype-conversion

z-score-normalization

z-score-normalization（数据标准化）

  • 来源章节: 1.1.4
  • 定义: 使用 Z-score 公式 (x - μ) / σ 对数值型特征进行标准化处理
  • 用法:
    •   mean = df['Age'].mean()
  std = df['Age'].std()
  df['Age_std'] = (df['Age'] - mean) / std
  • 公式: z = (x - μ) / σ
  • x：原始值
  • μ：均值（mean）
  • σ：标准差（std）
  • 标准化后的特征:
  • 均值 = 0，标准差 = 1
  • z = 2 表示「比均值高 2 个标准差」
  • z = -1 表示「比均值低 1 个标准差」
  • 应用场景:

1. 机器学习特征工程（不同量纲的特征统一尺度）

2. 异常值检测（|z| > 3 通常认为是异常值）

3. 数据可视化（不同指标在同一图表对比）

  • ⚠️ 易错点:
  • 新建列保留原始数据：df['Age_std'] 而非覆盖 df['Age']
  • 标准差为 0 时会除零错误（所有值相同的列）
  • 关联: astype-conversion · groupby-aggregation
