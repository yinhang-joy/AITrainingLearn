一、资源、环境和交付物

本题与前四题的单图分类不同：一张图片中可能有多个人脸，所以模型需要输出位置框与置信度，不能只使用一次全局 argmax。

voc-model-labels.txt两行标签：BACKGROUND、face

detect_imgs_results_onnx原题运行时创建的输出目录，不是输入图片目录

本地没有预置 3.2.5.docx 模板，但题干要求提交该文件。应按题干准备人机交互优化方案，不能因为没有模板就漏交。

运行需要 onnxruntime、numpy 和 OpenCV。import cv2 对应的安装包名称是 opencv-python，不是 cv2。如果环境缺少它，应安装到 Jupyter 实际使用的解释器；例如从项目根目录执行：

包安装属于环境准备，不是题目填空。讲义没有替你修改依赖或练习文件。

二、模型输入输出和整体流程

已核对本地模型：

项目名称和形状
输入input，float32，(1, 3, 240, 320)
输出一scores，(1, 4420, 2)
输出二boxes，(1, 4420, 4)

4420 是候选框数量，不是最终检测到的人脸数；2 是背景与人脸两个类别；每个框有四个坐标值。

流程是：加载模型和标签 → 遍历 imgs → 读取并预处理 → 模型推理 → 置信度过滤和 NMS → 映射回原图坐标 → 画框保存 → 累计数量。

三、图像读取与预处理

orig_image = cv2.imread(img_path)
image = cv2.cvtColor(orig_image, cv2.COLOR_BGR2RGB)
image = cv2.resize(image, (320, 240))
image_mean = np.array([127, 127, 127])
image = (image - image_mean) / 128
image = np.transpose(image, [2, 0, 1])
image = np.expand_dims(image, axis=0)
image = image.astype(np.float32)
  • cv2.imread 返回的彩色图默认是 BGR，原题随后转换为模型使用的 RGB。
  • resize 的大小参数顺序是宽、高，所以 (320, 240) 生成数组形状 (240, 320, 3)。
  • 本模型的归一化是减 [127, 127, 127] 再除以 128，不是直接复制 ResNet 的处理参数。
  • 转置后变成 (3, 240, 320)；扩展后为 (1, 3, 240, 320)。
  • orig_image 保留原图用于画框，模型输入用另一个变量 image。

如果读取失败，orig_image 可能是 None，随后 cvtColor 会报错。先检查图片路径与文件有效性，不要把它误判为模型推理错误。

四、run 的返回值与后处理

confidences, boxes = ort_session.run(None, {input_name: image})
boxes, labels, probs = predict(
    orig_image.shape[1], orig_image.shape[0],
    confidences, boxes, threshold
)

run 的第一个参数 None 表示返回全部输出；第二个参数是“模型输入名 → 图片数组”。当前模型输出顺序为 scores、boxes，与原题左侧的两个变量对应。

原题已经提供 predict，需要理解它，而不是另写一套后处理：

  • 跳过类别 0，也就是背景。
  • 使用 probs > 0.7 筛选候选人脸框。
  • hard_nms 按置信度保留候选框，用 IoU 阈值 0.3 去掉高度重叠的重复框。
  • 将归一化坐标乘原图宽、高，转换为原图像素坐标。
  • 返回最终框、标签和置信度。工具函数实际返回保留的框与分数，不是简单的索引列表。

orig_image.shape 的前两项是高度、宽度，所以传入 predict 时先取 shape[1] 作为宽，再取 shape[0] 作为高。

boxes.shape[0] 才是后处理后留下的框数。最终 sum 统计各图片的框数量之和，不是跨图片去重后的不同人员数。

五、目录创建、绘图与原题边界

class_names 逐行读取后使用 name.strip() 去掉换行；标签顺序不可反转。os.makedirs(result_path) 创建结果目录，前面的存在性判断已由原题提供。

cv2.rectangle 在原始图像上画框；cv2.imwrite 把当前图像保存到输出目录，颜色参数按 BGR 理解。

原题有一个固定代码边界：cv2.imwrite 放在人脸框循环内部。因此同一张图有多个框时会覆盖同名结果，最后保存全部已绘制框；没有检测到人脸时，这张图片不会被保存。不要因此断定填空错误，也不要为了凑齐输出图片擅改原题。可在交互优化方案中建议对“未检出”图片也提供清楚的状态。

以下参考保留原题固定代码，仅补齐填空。请从本单元目录运行，以找到 imgs、vision 和模型；完整流程会生成检测图片。

import os
import time
import cv2
import numpy as np
import vision.utils.box_utils_numpy as box_utils
import onnxruntime as ort

# 定义预测函数，对模型输出的边界框和置信度进行后处理
def predict(width, height, confidences, boxes, prob_threshold, iou_threshold=0.3, top_k=-1):
    boxes = boxes[0]
    confidences = confidences[0]
    picked_box_probs = []
    picked_labels = []
    for class_index in range(1, confidences.shape[1]):
        probs = confidences[:, class_index]
        mask = probs > prob_threshold
        probs = probs[mask]
        if probs.shape[0] == 0:
            continue
        subset_boxes = boxes[mask, :]
        box_probs = np.concatenate([subset_boxes, probs.reshape(-1, 1)], axis=1)
        box_probs = box_utils.hard_nms(box_probs,
                                       iou_threshold=iou_threshold,
                                       top_k=top_k,
                                       )
        picked_box_probs.append(box_probs)
        picked_labels.extend([class_index] * box_probs.shape[0])
    if not picked_box_probs:
        return np.array([]), np.array([]), np.array([])
    picked_box_probs = np.concatenate(picked_box_probs)
    picked_box_probs[:, 0] *= width
    picked_box_probs[:, 1] *= height
    picked_box_probs[:, 2] *= width
    picked_box_probs[:, 3] *= height
    return picked_box_probs[:, :4].astype(np.int32), np.array(picked_labels), picked_box_probs[:, 4]

# 从标签文件中读取每一行，并去除行首尾的空白字符，得到类别名称列表 2分
class_names = [name.strip() for name in open('voc-model-labels.txt').readlines()]

# 创建 ONNX Runtime 的推理会话，用于运行模型进行推理 2分
ort_session = ort.InferenceSession('version-RFB-320.onnx')

# 获取模型输入的名称 2分
input_name = ort_session.get_inputs()[0].name

# 定义保存检测结果图像的目录路径
result_path = "./detect_imgs_results_onnx"

# 定义置信度阈值，用于筛选出置信度较高的检测结果
threshold = 0.7
# 定义存储待检测图像的目录路径
path = "imgs"
# 用于统计所有图像中检测到的目标框总数，初始化为 0
sum = 0

# 如果保存结果的目录不存在，则创建该目录 2分
if not os.path.exists(result_path):
    os.makedirs(result_path)

# 获取指定目录下的所有文件和文件夹名称列表
listdir = os.listdir(path)

# 遍历目录下的每个文件
for file_path in listdir:
    # 拼接图像文件的完整路径
    img_path = os.path.join(path, file_path)
    # 使用 OpenCV 读取图像文件 2分
    orig_image = cv2.imread(img_path)
    # 将图像从 BGR 颜色空间转换为 RGB 颜色空间（许多模型要求输入为 RGB 格式）
    image = cv2.cvtColor(orig_image, cv2.COLOR_BGR2RGB)
    # 将图像调整为 320x240 的尺寸（符合模型输入的尺寸要求） 2分
    image = cv2.resize(image, (320, 240))
    # 定义图像归一化的均值数组 2分
    image_mean = np.array([127, 127, 127])
    # 对图像进行归一化处理，减去均值并除以 128
    image = (image - image_mean) / 128
    # 将图像的维度从 (高度, 宽度, 通道数) 转换为 (通道数, 高度, 宽度)
    image = np.transpose(image, [2, 0, 1])
    # 在第一个维度上扩展一个维度，将图像变为 (1, 通道数, 高度, 宽度)，以符合模型输入的维度要求  1分
    image = np.expand_dims(image, axis=0)
    # 将图像数据类型转换为 float32 类型
    image = image.astype(np.float32)
    # 记录开始时间，用于计算模型推理的耗时
    time_time = time.time()
    # 使用 ONNX Runtime 运行模型，输入图像数据，得到模型输出的置信度和边界框  2分
    confidences, boxes = ort_session.run(None, {input_name: image})
    # 计算并打印模型推理的耗时
    print("cost time:{}".format(time.time() - time_time))
    # 调用 predict 函数对模型输出的边界框和置信度进行后处理，得到最终的边界框、类别标签和置信度
    boxes, labels, probs = predict(orig_image.shape[1], orig_image.shape[0], confidences, boxes, threshold)
    # 遍历每个检测到的目标框
    for i in range(boxes.shape[0]):
        # 获取当前目标框的坐标
        box = boxes[i, :]
        # 生成当前目标框的标签字符串，包含类别名称和置信度
        label = f"{class_names[labels[i]]}: {probs[i]:.2f}"

        # 在原始图像上绘制目标框，颜色为 (255, 255, 0)，线条粗细为 4
        cv2.rectangle(orig_image, (box[0], box[1]), (box[2], box[3]), (255, 255, 0), 4)
        # 将绘制了目标框的图像保存到结果目录中
        cv2.imwrite(os.path.join(result_path, file_path), orig_image)
    # 累加当前图像中检测到的目标框数量到总数中
    sum += boxes.shape[0]
# 打印所有图像中检测到的目标框总数
print("sum:{}".format(sum))

七、结果核验与交互优化方案

当前 imgs 中提供一张 1.jpg。使用原题阈值 0.7 和 NMS 阈值 0.3，实测得到 4 个保留框，最终输出为 sum:4。推理耗时取决于设备，不要求与你看到的示例秒数相同，也不要把数量写死。

题干要求的交互优化方案应包含界面布局和操作流程，可写为：

  • 界面左侧是图片目录选择和缩略图列表，右侧显示原图及检测框，下方显示当前图框数、处理进度和累计框数。
  • 用户选择目录并预览，确认后开始批量检测；区分处理中、已完成、读取失败、未检出等状态。
  • 用户可放大检查结果、调整阈值后重新检测、标记误检与漏检；人工确认后再导出。
  • 显示输出目录与保存结果，对覆盖同名文件给出提示，并提供失败重试或取消入口。
  • 告知图片使用目的，限制人脸图片访问，支持删除；人脸检测不等于身份识别。

提交材料：附运行结果的 3.2.5.html、自行准备的 3.2.5.docx、运行输出截图 3.2.5-1.jpg，以及 detect_imgs_results_onnx 中的检测结果图片。检查是否真正画出了框，不能只交计数截图而漏交图片。

常见问题：缺少 cv2 属于环境问题；缺少 vision 先检查工作目录和辅助文件；模型输入维度要求高 240、宽 320；零检测时不保存图片是原题的循环位置造成；修改原题阈值会影响计数，不应把别的阈值结果当作固定答案。
