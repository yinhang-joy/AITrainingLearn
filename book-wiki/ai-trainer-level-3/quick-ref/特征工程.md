# 特征工程速查

## 特征选择

```python
# 选择指定列
X = data[['feature1', 'feature2', 'feature3']]

# 排除某些列
X = data.drop(['id', 'timestamp', 'target'], axis=1)

# 选择数值列
X = data.select_dtypes(include=['number'])
```

## 数据集划分

```python
from sklearn.model_selection import train_test_split

# 基本用法
X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.2,      # 测试集占20%
    random_state=42     # 固定随机种子
)

# 带分层采样（适用于类别不平衡）
X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.2,
    stratify=y,         # 保持各类别比例
    random_state=42
)
```

### train_test_split 返回值

| 返回值 | 含义 | 用途 |
|--------|------|------|
| `X_train` | 训练集特征 | 用于 `model.fit()` |
| `X_test` | 测试集特征 | 用于 `model.predict()` |
| `y_train` | 训练集标签 | 用于 `model.fit()` |
| `y_test` | 测试集标签 | 用于评估准确率 |

## 标准化

```python
from sklearn.preprocessing import StandardScaler

# 1. 创建标准化器
scaler = StandardScaler()

# 2. 在训练集上拟合
scaler.fit(X_train)

# 3. 转换训练集和测试集
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)

# 简写（仅用于训练集）
X_train_scaled = scaler.fit_transform(X_train)
```

⚠️ **重要原则**：
- **训练集**：`fit_transform()` - 学习参数并转换
- **测试集**：`transform()` - 用训练集的参数转换
- **不能**在测试集上用 `fit_transform()`！（会泄露测试集信息）

## 特征缩放对比

| 方法 | 结果范围 | 适用场景 | 代码 |
|------|----------|----------|------|
| **StandardScaler** | 均值0，标准差1 | 数据服从正态分布 | `StandardScaler()` |
| **MinMaxScaler** | [0, 1] | 需要固定范围 | `MinMaxScaler()` |
| **RobustScaler** | 中位数0 | 有异常值 | `RobustScaler()` |

## 易错点

⚠️ **顺序问题**：
```python
# ❌ 错误顺序
X_train, X_test = train_test_split(X)
scaler.fit_transform(X)  # 在划分前标准化（数据泄露）

# ✅ 正确顺序
X_train, X_test = train_test_split(X)  # 先划分
scaler.fit_transform(X_train)          # 再标准化
```

⚠️ **测试集不能 fit**：
```python
# ❌ 错误
X_test_scaled = scaler.fit_transform(X_test)

# ✅ 正确
X_test_scaled = scaler.transform(X_test)
```
