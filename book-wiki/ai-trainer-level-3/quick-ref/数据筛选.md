# 数据筛选速查

## 布尔索引（条件筛选）

```python
# 单条件
adults = data[data['age'] >= 18]
high_score = data[data['score'] > 90]

# 多条件（与）
result = data[(data['age'] >= 18) & (data['score'] > 60)]

# 多条件（或）
result = data[(data['city'] == '北京') | (data['city'] == '上海')]

# 取反（非）
not_adult = data[~(data['age'] >= 18)]
```

⚠️ **必须用括号**：`&` 和 `|` 优先级高，不加括号会报错

## 范围筛选

```python
# between（包含边界）
data[data['age'].between(18, 60)]  # 18 <= age <= 60

# between（不包含边界）
data[data['age'].between(18, 60, inclusive='neither')]  # 18 < age < 60
```

## 成员筛选

```python
# isin（在列表中）
cities = ['北京', '上海', '深圳']
data[data['city'].isin(cities)]

# 取反（不在列表中）
data[~data['city'].isin(cities)]
```

## 字符串筛选

```python
# 包含
data[data['name'].str.contains('张')]

# 开头
data[data['name'].str.startswith('张')]

# 结尾
data[data['name'].str.endswith('峰')]
```

## 跨列比较

```python
# 两列比较
data[data['actual'] > data['expected']]

# 多列满足条件
data[(data['col1'] > data['col2']) & (data['col2'] > data['col3'])]
```

## 常用筛选模式

```python
# 非空
data[data['col'].notnull()]

# 为空
data[data['col'].isnull()]

# 不等于
data[data['status'] != 'deleted']

# 大于均值
data[data['score'] > data['score'].mean()]

# Top N
data.nlargest(10, 'score')  # 最大的10个
data.nsmallest(10, 'price')  # 最小的10个
```

## 易错点

⚠️ **and/or vs &/|**：
```python
# ❌ 错误（不能用 and/or）
data[(data['age'] > 18) and (data['score'] > 60)]

# ✅ 正确（用 & 或 |）
data[(data['age'] > 18) & (data['score'] > 60)]
```

⚠️ **比较运算符优先级**：
```python
# ❌ 错误（缺少括号）
data[data['age'] >= 18 & data['score'] > 60]

# ✅ 正确
data[(data['age'] >= 18) & (data['score'] > 60)]
```

⚠️ **布尔值比例**：
```python
# 统计满足条件的比例
ratio = (data['age'] >= 18).mean()  # True当作1，False当作0
```
