# 数据清洗速查

## 检查问题

```python
# 查看数据类型
data.dtypes

# 查看缺失值数量
data.isnull().sum()

# 查看重复行数量
data.duplicated().sum()

# 查看前几行
data.head(5)
```

## 处理缺失值

| 方法 | 用途 | 示例 |
|------|------|------|
| `dropna()` | 删除含缺失值的行 | `data.dropna()` |
| `fillna(value)` | 用指定值填充 | `data.fillna(0)` |
| `fillna(method='ffill')` | 向前填充 | `data['col'].fillna(method='ffill')` |
| `fillna(method='bfill')` | 向后填充 | `data['col'].fillna(method='bfill')` |
| `isnull()` | 返回布尔值（True=缺失） | `data[data['col'].isnull()]` |

## 处理重复值

```python
# 删除重复行（保留第一次出现）
data.drop_duplicates()

# 查看重复行
data[data.duplicated()]
```

## 处理异常值

```python
# 方法1: 删除不在范围内的行
data = data[data['age'].between(0, 120)]

# 方法2: 布尔索引
data = data[(data['price'] > 0) & (data['price'] < 10000)]

# 方法3: 转换+删除（字符串→数值）
data['col'] = pd.to_numeric(data['col'], errors='coerce')  # 异常值→NaN
data = data.dropna()  # 删除NaN行
```

## 删除列

```python
# 删除单列
data.drop('col_name', axis=1)

# 删除多列
data.drop(['col1', 'col2'], axis=1)
```

## 易错点

⚠️ **pandas 操作默认不修改原数据**，需要：
- 重新赋值：`data = data.dropna()`
- 或用 `inplace=True`：`data.dropna(inplace=True)`

⚠️ **链式赋值警告**（SettingWithCopyWarning）：
```python
# ❌ 可能有问题
data['col'][data['col'] < 0] = 0

# ✅ 推荐写法
data.loc[data['col'] < 0, 'col'] = 0
```
