# 数据聚合速查

## 分组聚合

```python
# 单列分组，单指标
data.groupby('category')['sales'].mean()

# 单列分组，多指标
data.groupby('category')['sales'].agg(['mean', 'sum', 'count'])

# 多列分组
data.groupby(['city', 'category'])['sales'].mean()

# 多列多指标
data.groupby('category').agg({
    'sales': ['mean', 'sum'],
    'quantity': 'count',
    'price': 'max'
})
```

## 常用聚合函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `mean()` | 平均值 | `df.groupby('A')['B'].mean()` |
| `sum()` | 总和 | `df.groupby('A')['B'].sum()` |
| `count()` | 计数（非空） | `df.groupby('A')['B'].count()` |
| `size()` | 计数（含空） | `df.groupby('A').size()` |
| `max()` / `min()` | 最大/最小值 | `df.groupby('A')['B'].max()` |
| `std()` | 标准差 | `df.groupby('A')['B'].std()` |
| `median()` | 中位数 | `df.groupby('A')['B'].median()` |

⚠️ **方法需要加括号**：`.mean()` 而不是 `.mean`

## 计数统计

```python
# 值计数（降序）
data['category'].value_counts()

# 值计数（升序）
data['category'].value_counts(ascending=True)

# 值计数（含比例）
data['category'].value_counts(normalize=True)

# 交叉计数
pd.crosstab(data['category'], data['region'])
```

## 透视表

```python
# 简单透视
pd.pivot_table(
    data,
    values='sales',       # 要聚合的值
    index='category',     # 行索引
    columns='region',     # 列索引
    aggfunc='mean'        # 聚合函数
)

# 多指标透视
pd.pivot_table(
    data,
    values=['sales', 'quantity'],
    index='category',
    columns='region',
    aggfunc={'sales': 'sum', 'quantity': 'count'}
)
```

## 累计统计

```python
# 累计和
data['cumsum'] = data['sales'].cumsum()

# 累计均值
data['cummean'] = data['sales'].expanding().mean()

# 移动平均（7天）
data['ma7'] = data['sales'].rolling(window=7).mean()
```

## 排名

```python
# 排名
data['rank'] = data['score'].rank()

# 排名（降序，从1开始）
data['rank'] = data['score'].rank(ascending=False, method='min')
```

## 易错点

⚠️ **groupby 返回的不是 DataFrame**：
```python
# ❌ 错误
grouped = data.groupby('category')
print(grouped)  # 只显示对象信息

# ✅ 正确（需要聚合）
result = data.groupby('category')['sales'].mean()
```

⚠️ **多列聚合需要用列表**：
```python
# ❌ 错误
data.groupby('category')['sales', 'quantity'].mean()

# ✅ 正确
data.groupby('category')[['sales', 'quantity']].mean()
```

⚠️ **mean() 需要括号**：
```python
# ❌ 错误（返回方法对象）
avg = data['sales'].mean

# ✅ 正确（执行方法）
avg = data['sales'].mean()
```
