# 数据转换速查

## 类型转换

```python
# 转换整列
data['age'] = data['age'].astype(int)
data['price'] = data['price'].astype(float)

# 强制转换（异常值→NaN）
data['col'] = pd.to_numeric(data['col'], errors='coerce')

# 批量转换多列
cols = ['col1', 'col2', 'col3']
data[cols] = data[cols].astype(float)
```

## 分箱（连续→离散）

```python
# 等宽分箱
data['age_group'] = pd.cut(
    data['age'],
    bins=[0, 18, 35, 60, 100],        # 分箱边界
    labels=['青少年', '青年', '中年', '老年'],  # 标签
    right=False                        # 左闭右开 [0,18)
)

# 等频分箱
data['score_level'] = pd.qcut(
    data['score'],
    q=4,                              # 4等分
    labels=['低', '中', '高', '极高']
)
```

## 条件赋值

```python
# 简单条件
data['is_adult'] = data['age'] >= 18

# np.where（二选一）
data['label'] = np.where(data['score'] >= 60, '及格', '不及格')

# np.select（多条件）
conditions = [
    data['score'] >= 90,
    data['score'] >= 60,
    data['score'] < 60
]
choices = ['优秀', '及格', '不及格']
data['grade'] = np.select(conditions, choices, default='未知')
```

## 虚拟变量（类别编码）

```python
# one-hot 编码
data = pd.get_dummies(data, columns=['category'])
# 结果: category_A, category_B, category_C 三列（0/1）
```

## 标准化/归一化

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

# 标准化（Z-score: 均值0，标准差1）
scaler = StandardScaler()
data[['col1', 'col2']] = scaler.fit_transform(data[['col1', 'col2']])

# 归一化（缩放到 0-1）
scaler = MinMaxScaler()
data[['col1', 'col2']] = scaler.fit_transform(data[['col1', 'col2']])
```

## 易错点

⚠️ **astype vs to_numeric**：
- `astype()` - 转换失败直接报错
- `to_numeric(errors='coerce')` - 转换失败变成 NaN

⚠️ **pd.cut 的 right 参数**：
- `right=True`（默认）→ 左开右闭 `(0, 18]`
- `right=False` → 左闭右开 `[0, 18)`

⚠️ **StandardScaler 需要传入数据**：
```python
# ❌ 错误
data[cols] = scaler.fit_transform()

# ✅ 正确
data[cols] = scaler.fit_transform(data[cols])
```
