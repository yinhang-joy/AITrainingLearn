# 数据保存速查

## CSV 文件

```python
# 基本保存
data.to_csv('output.csv')

# 不保存索引（推荐）
data.to_csv('output.csv', index=False)

# 指定编码
data.to_csv('output.csv', index=False, encoding='utf-8-sig')  # Excel友好

# 指定分隔符
data.to_csv('output.tsv', sep='\t', index=False)  # TSV格式

# 仅保存部分列
data[['col1', 'col2']].to_csv('output.csv', index=False)
```

## Excel 文件

```python
# 保存为Excel
data.to_excel('output.xlsx', index=False)

# 多个sheet
with pd.ExcelWriter('output.xlsx') as writer:
    data1.to_excel(writer, sheet_name='Sheet1', index=False)
    data2.to_excel(writer, sheet_name='Sheet2', index=False)
```

## JSON 文件

```python
# 保存为JSON
data.to_json('output.json', orient='records', force_ascii=False)

# orient 参数：
# - 'records': [{col1:val1, col2:val2}, ...]
# - 'index': {index: {col1:val1, col2:val2}}
# - 'columns': {col1: {index:val1}, col2: {...}}
```

## 常用参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `index=False` | 不保存行索引 | `to_csv(..., index=False)` |
| `encoding='utf-8-sig'` | 中文兼容Excel | `to_csv(..., encoding='utf-8-sig')` |
| `sep='\t'` | 指定分隔符 | `to_csv(..., sep='\t')` |
| `header=False` | 不保存列名 | `to_csv(..., header=False)` |
| `float_format='%.2f'` | 浮点数格式 | `to_csv(..., float_format='%.2f')` |

## 易错点

⚠️ **默认会保存索引**：
```python
# ❌ 文件中多了一列 Unnamed: 0
data.to_csv('output.csv')

# ✅ 推荐写法
data.to_csv('output.csv', index=False)
```

⚠️ **中文编码问题**：
```python
# ❌ Excel 打开中文乱码
data.to_csv('output.csv', encoding='utf-8')

# ✅ Excel 友好
data.to_csv('output.csv', encoding='utf-8-sig')
```

⚠️ **路径问题（Windows）**：
```python
# ❌ 可能出错（反斜杠）
data.to_csv('C:\Users\output.csv')

# ✅ 推荐写法
data.to_csv('C:/Users/output.csv')  # 正斜杠
data.to_csv(r'C:\Users\output.csv')  # 原始字符串
```

## 读取对应

```python
# CSV
data = pd.read_csv('input.csv')

# Excel
data = pd.read_excel('input.xlsx')
data = pd.read_excel('input.xlsx', sheet_name='Sheet1')

# JSON
data = pd.read_json('input.json', orient='records')
```
