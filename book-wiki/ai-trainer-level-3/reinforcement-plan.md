### 第二次 数值模型和 ONNX 输入

- 2.2.2、3.2.2 已通过本题核心订正；使用不同数据/字段或输入条件做独立变式，不重复按旧错误要求原题重做。
- 训练前检查 X.columns、X.dtypes；ONNX 调用前检查 shape、dtype 和模型输入元信息。
- 不看讲义补完整下表。每个调用都要说出“参数对象”和“返回值”。

| 调用 | 参数如何区分 | 返回结果 |
| --- | --- | --- |
| ModelClass(构造参数) | 迭代数、树数、随机种子等设置模型行为；不是训练样本 | 模型对象 |
| model.fit(X_train, y_train) | 训练特征和对应真实目标 | 已拟合的模型对象 |
| model.predict(X_test) | 只输入待预测特征，不传真实答案 | y_pred |
| model.score(X_test, y_test) | 输入特征和真实目标；不是只传两组 y | 分类器常用准确率；这些回归器常用 R² |
| mean_squared_error(y_test, y_pred) | 真实值在前，预测值在后 | MSE，越小越好 |
| r2_score(y_test, y_pred) | 真实值在前，预测值在后；不能随便交换 | R²，可能为负 |
| scaler.fit_transform(X_train) | 在训练特征上拟合并转换；测试集用 transform | 转换后的特征 |
| smote.fit_resample(X_train, y_train) | 只对训练集重采样，保留独立测试集 | 新 X 和新 y 两个结果 |
| session.run([output_name], {input_name: image_array}) | 输出名列表在前、输入名到数组的字典在后 | 输出数组的列表 |

原题若已把标准化写在划分前，只记录其局限；避免信息泄漏的正确次序在额外变式练习，不擅改固定代码。
