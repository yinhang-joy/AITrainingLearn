### 重点知识点回顾

**`.mean()` 方法详解：**
```python
# 错误：忘记括号
data.groupby('Gender')['Speed'].mean  # 返回方法对象，不是结果

# 正确：加括号执行
data.groupby('Gender')['Speed'].mean()  # 返回计算结果

# 多列聚合
data.groupby('Gender')[['Speed','Distance','Time']].mean()
#        Speed  Distance    Time
# Female  105.1     487.5   359.6
# Male    108.9     477.9   359.1
```
