## 新知识点详解

### dropna() — 删除缺失值
```python
data = data.dropna()  # 删除任意列有 NaN 的行
```

### astype() — 数据类型转换
```python
data['Age'] = data['Age'].astype(int)      # 转整型
data['Amount'] = data['Amount'].astype(float)  # 转浮点
```
**注意**: `astype(int)` 截断小数部分（不是四舍五入）

### Z-score 标准化
```python
data['col'] = (data['col'] - data['col'].mean()) / data['col'].std()
```
**用途**: 消除量纲影响，将不同尺度的数据转换到同一标准（均值 0，标准差 1）
