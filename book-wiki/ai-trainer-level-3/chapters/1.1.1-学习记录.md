- **问题**: 占比计算用了 `risk_counts['高风险患者'] / risk_counts`
- **原因**: Series 除以 Series 会逐元素除法，得到患者数比值而非占比
- **正确写法**: 
  ```python
  risk_counts['高风险患者'] / len(data)           # 413 / 1000 = 0.413
  risk_counts['高风险患者'] / risk_counts.sum()   # 413 / 1000 = 0.413
  (data['DaysInHospital'] > 7).mean()             # 一行写法
  ```

## 关键收获

1. **`pd.cut` 的 `right=False` 是考点** — 不加会让边界值归错区间（BMI=18.5 本应归「正常」但默认会归「偏瘦」）
2. **Series 运算的广播机制** — `Series / Series` 是逐元素除法，不是你想要的单个占比值
3. **占比计算的本质** — 「该类别数 / 总数」，总数可以是 `len(data)` 或 `risk_counts.sum()` 或 `data['col'].count()`

## 延伸理解

在和 Claude 讨论中澄清的概念：
- `value_counts()` 返回的是 **一维 Series**（不是二维数组），索引是原始列的唯一值
- 无论原始列是字符串、数字还是布尔，`value_counts()` 的结构都是一维的
- `len()` 是 Python 内置函数，`len(data)` = DataFrame 行数，`len(data['col'])` = Series 元素个数
- Python 的 DataFrame/Series 是 C# 中没有的数据结构，C# 需要用 LINQ + 集合手动实现类似功能
