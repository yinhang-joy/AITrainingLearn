## 初次遇到的问题与解决

### 1. pandas 2.0 语法变化

**问题**：讲义用的 `.fillna(method='ffill')` 在新版 pandas 已废弃

**解决**：改用 `.ffill()` / `.bfill()` 直接方法

**新旧对照**：
```python
# ❌ 旧语法（pandas < 2.0）
df['Value'].fillna(method='ffill', inplace=True)

# ✅ 新语法（pandas >= 2.0）
df['Value'] = df['Value'].ffill().bfill()
```

### 2. `.drop()` vs `.dropna()` 混淆

**问题**：题目「删除 is_abnormal 列」，错用成 `dropna(columns=...)`

**解决**：
- `.drop(columns=[...])` 删除 **指定列**
- `.dropna()` 删除 **含 NaN 的行/列**（没有 `columns` 参数）

### 3. 布尔值大小写

**问题**：`index = false` 报错 `name 'false' is not defined`

**解决**：Python 布尔值首字母大写 `True` / `False`

## 关键收获

1. **pandas 版本差异要注意** — 新版 pandas 2.0+ 废弃了很多旧语法（`method` 参数、`inplace` 警告），需要查当前版本文档
2. **`.isin()` 比多个 `|` 条件简洁** — `df[df['col'].isin(['A', 'B'])]` 比 `df[(df['col']=='A') | (df['col']=='B')]` 易读
3. **`np.where` vs 直接布尔赋值** — 结果是 True/False 时两者等价，但 np.where 更明确；结果是字符串/数字时必须用 np.where
4. **`.unstack()` 优化多层索引输出** — groupby 两列后的结果是多层索引，unstack 转成二维表格更直观
