# 人工智能训练师（三级）备考素材

「人工智能训练师（三级）」职业技能等级考试的官方训练素材与练习环境。本仓库包含全部素材（含 ONNX 模型文件），**克隆后即可离线做题**，无需再下载任何素材。

## 目录

- `练习导航.html` — **总入口**：双击打开，40 个单元卡片，每卡含任务要求/答题卷/练习/数据的链接，一键跳到各文件
- `人工智能训练师三级上网素材/` — 官方训练素材，按任务编号一个单元一个文件夹（如 `2.1.3/`）：
  - `2.1.3.html` 任务要求（原考试平台模拟界面，已并入）· `2.1.3.docx` 答题卷 · `2.1.3.ipynb` 练习 · 数据集（csv/xlsx）· ONNX 模型（3.2.x）
  - **每个单元的 ipynb 顶部已嵌入「任务要求 + 数据预览 + 答题卷」Markdown 单元格** —— 打开一个文件即可同时看到题目、数据表格与练习（由 `scripts/enrich_notebooks.py` 生成，重跑幂等；1.2.x/3.1.x/4.x 等无练习的单元为资料型笔记本）

## 新设备快速开始

1. 安装 Python 3.11+ 与 [uv](https://docs.astral.sh/uv/)（包管理器）
2. 创建虚拟环境并安装依赖：

   ```
   uv venv .venv
   uv pip install -r requirements.txt
   ```

3. 启动 Jupyter：

   - Windows：双击根目录的 `一键启动服务.bat`，自动启动 Jupyter（8891）和重置服务（8765），并打开认证入口及练习导航。重复运行会复用已有服务，关闭启动窗口不影响后台服务。
   - 只启动服务、不打开浏览器：运行 `一键启动服务.bat --no-browser`。
   - macOS/Linux：`.venv/bin/jupyter-lab`

   Windows 启动脚本只重建导航，不覆盖讲义、练习或数据；导航不保存 token。日志和重建前的导航备份保存在 `%LOCALAPPDATA%\AITraining\` 下。若端口被其他程序占用，会提示错误，不会强行关闭进程；启动失败时窗口会保留错误信息。
